## 二、快扫+深析（命令差异）

### 2.1 快扫（连续运行，信号检测）

```
□ op_index — 看指数（机械）
  ./scripts/op_index_live.sh
  → 指数异动？→ 信号

□ op_holdings — 看持仓（机械）
  astock live quote <持仓codes>
  → 持仓涨跌幅>2%？是否触发卖出规则§4.1评估？→ 信号

□ op_sector_rank — 看板块强度（机械）
  astock live block rank --limit 50
  → 概念排名中哪个方向靠前？已有涨停是什么方向？→ 信号

□ 无信号 → 不写日志，立即下一次快扫（每5分钟heartbeat一行）
□ 有信号 → 立即进入深析
```

快扫预算：≤3次工具调用 · ≤100 token · ~15-20秒

### 2.2 深析（命令差异）

深析流程（思考步骤）→ `看盘公共规范.md §二`。以下为真实看盘命令：

```
□ op_sector_members — 看板块领涨股
  astock live block members <板块代码>

□ op_multi_snapshot — 资金广度
  astock live quote <方向内标的>

□ op_stock_minute — 价格深度
  astock live minute <龙头>

□ op_holdings — 看持仓当前状态（卖出方向）
  astock live quote <持仓codes>

□ op_sector_members — 看持仓所在板块表现（卖出方向）
  astock live block members <板块代码>

□ op_multi_snapshot — 看预期相关个股表现（卖出方向）
  astock live quote <方向内标的>
```

深析预算：≤5次工具调用 · ≤500 token · 2-4分钟

## 三、Token管理

- 主对话只保留：当前轮摘要（≤200字）+ 待执行预案 + 关键决策结论
- 禁止保留：完整live block rank输出、多轮quote历史、八维扫描结果
- token 60% → 主动启动归档
- token 70% → 收尾退出，提示新开session

## 四、事件驱动留证

AI是在持续判断，不是定时打卡。有价值的变化才停下来做完整留证。

### 必须留证事件

| 触发类型 | 具体情形 | 产出文件 | 时机 |
|---------|---------|---------|------|
| 拟执行买卖 | 三维齐+锁定三件事 | HHMM_买卖_标的_思考链路.md | 日内实时 |
| 持仓异动 | 日内振幅>5%或触发§4.1评估 | HHMM_持仓异动_标的.md | 日内实时 |
| 预期阶段切换 | 持仓方向阶段变化 | HHMM_预期切换_方向.md | 日内实时 |
| 盘中新方向 | 盘前预案外方向走强且联动 | HHMM_新方向_方向.md | 日内实时 |
| 关键锚点异动 | 产业数据破位/龙头炸板/政策突发 | HHMM_锚点异动_事件.md | 日内实时 |

以上留证均为日内实时产出。收盘归档checklist A项用于检查日内是否有遗漏。

## 五、收盘归档与复盘

### 归档checklist

收盘后写入以下checklist到看盘.md，逐项执行：

```
## 收盘归档checklist
- [ ] A. §四 持仓异动验证（日内振幅>5%的持仓是否已留证）
- [ ] B. §五.3 涨停归因（逐只→方向→是否新方向）
- [ ] C. §五.3 炸板分析（为什么炸？方向还有效？）
- [ ] D. §五.3 成交额前50（异动检测→是否隐含新预期）
- [ ] E. §五.1 预期研究模式B更新全部方向（每日必做）
- [ ] F. §五.2 state.md §四更新（阶段/价格/今日变化）
- [ ] G. §五.2 state.md §一§二 + trades.md
- [ ] H. §五.4 lessons.md（如有新教训）
- [ ] I. 收盘总结
- [ ] J. 看盘文件归档
```

### 5.1 执行预期研究更新（每日必做）

**state.md §四预期追踪表中的全部方向（含持仓与观察）** 都必须每日更新，不限方向类型、不限是否有异动：
- 每个方向统一执行 `operations/预期研究.md 模式B`（B.1-B.5全流程）
- 已失效/结束的方向 → 归档到 archive/，从 state.md §四 移除

（预期研究负责更新 research 文件，真实看盘不直接写 research）

### 5.2 更新state.md

- §四：预期阶段演化、确认/兑现/失效标记
- §一§二：今日操作回顾、合规检查
- trades.md：当日有交易 → 追加交易明细（格式 → 看盘公共规范.md §五）

### 5.3 每日逐股扫描（预期来源的自下而上兜底）

- **涨停全部过一遍**：`astock query limit <YYYYMMDD>` 获取涨停列表 → 逐只归因→属于哪个方向→是否新方向
- **炸板全部过一遍**：盘中快扫已记录的炸板事件汇总 → 为什么炸？方向还有效吗？
  （astock当前不支持盘后查询炸板，依赖日内快扫/深析实时记录的炸板数据）
- **成交额前50全部过一遍**：`astock query stock --sort-by amount --limit 50` → 异动检测→是否隐含新预期
- **产出**：新方向入库state.md §四 / 已有方向更新阶段

涨停逐只归因是自下而上的兜底：概念板块排名可能遗漏分散在多个概念标签中的强势方向，只有逐只归因才能发现方向的真实强度。
