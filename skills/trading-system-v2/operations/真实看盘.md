## 二、快扫+深析分层执行

### 2.1 快扫（连续运行，信号检测）

```
□ astock live quote 持仓N只（~3s）
□ astock live block rank --limit 10（~10s）
  block rank输出含涨停数，是"≥2涨停？"信号的必要输入
□ 信号检测（10s内完成）：
  - 持仓信号：任一持仓涨跌幅>2%？触及止损/止盈？
  - 方向信号：state.md §四方向在TOP3？≥2涨停？→ 深析后立即执行预期研究.md 模式B
  - 预期信号：research/expectations方向异动（排名TOP3或≥2涨停）→ 深析后立即执行预期研究.md 模式B
  - 新方向信号：盘前未覆盖方向≥2涨停？
  - 大盘信号：指数单边异动？
□ 无信号 → 不写日志，立即下一次快扫（每5分钟heartbeat一行）
□ 有信号 → 立即进入深析
```

信号检测要求：记录数据后必须执行对应的信号判断。信号命中则进入深析，不命中则继续快扫。

快扫预算：≤2次工具调用 · ≤100 token · ~15-20秒

### 2.2 深析（信号触发，完整分析）

```
□ Step 1: 信号定向（是什么信号？分析哪个方向/标的？）
□ Step 2: 拉详细数据（live minute / live block members / query limit等）
□ Step 3: 三维确认检查
    - 规则要求 → 买卖规则.md §1.2
    - 具体检查方法 → 同盘前分析.md §3.4（资金联动+量价+概念去噪 / 价格确认 / 预期依据）
□ Step 4: 双向判断+落盘（→§五）
    - 三维齐 → 买入评估（买卖规则.md §二）
    - 预期变化 → 卖出评估（买卖规则.md §4.4）
□ Step 5: 轮末自检 + 更新state.md轮转状态
```

深析预算：≤5次工具调用 · ≤500 token · 2-4分钟

### 2.3 ②→③同轮触发

快扫检测到state.md §四已入库方向≥2涨停或排名TOP3 → **立即进入深析**做三维检查。不等下一轮。这是盘中买点的唯一实时保障。

## 三、6类轮转池

| # | 关注点 | 层级 | 数据动作 | 思考输出 |
|---|--------|------|---------|---------|
| ① | 持仓巡检 | 快扫 | live quote 持仓N只 | 涨跌幅>2%？触及止损/止盈？ |
| ② | 板块强度 | 快扫 | live block rank --limit 10 | state.md §四方向在TOP3？≥2涨停？ |
| ③ | P1候选触发 | 深析 | live quote+minute 候选股 | 三维确认齐？买点窗口打开？ |
| ④ | 涨停板异动 | 深析 | query limit + live block members | 新增涨停/炸板归因 |
| ⑤ | 大盘趋势 | 深析 | live quote 指数 | 量能/趋势是否支持操作 |
| ⑥ | 盘中新方向 | 深析 | live block rank + 跨板块归因 | 盘前未覆盖≥2涨停 → 三维评估 |

- 快扫每轮固定检查①②
- 深析按信号触发③④⑤⑥
- 三维齐但不买 = 必须在巡盘日志写明放弃理由（未记录=过程违规）

## 五、决策落盘要求

### 5.1 买/卖前必须写思考链路

每一笔买/卖在执行前必须先写 `HHMM_<动作>_<标的>_思考链路.md`：

```
- 触发时刻 HH:MM:SS
- 三维确认：资金（涨停股名+时间）/ 预期依据（催化锚）/ 价格（具体价位）
- 买前三件事：预期 / 兑现标志 / 失效标志
- 备选方案：考虑过哪些标的，为什么放弃
- 仓位与价位：买卖数量、价格
- 退出条件：兑现/失效标志
```

未写思考链路 → 不允许动账户。

### 5.2 三维齐但不买

必须在巡盘日志写★决策记录（即时写入，非事后补录）：
- 三维确认评估（各引用具体数据）
- 买入窗口状态（是否打开）
- 最终决策 + 放弃理由
- 未写入 = 过程违规

### 5.3 执行链

**买点触发**：
① 写思考链路.md → ② 检查硬拒绝 → ③ 执行交易+更新state.md+trades.md → ④ 巡盘日志追加 → ⑤ 通知用户

**卖点触发**：
① 写思考链路.md（含卖出原因）→ ② 执行交易+更新state.md+trades.md → ③ 巡盘日志追加 → ④ 通知用户

**系统硬拒绝场景**（规则直接裁决，零用户介入）：
- 买前三件事任一无法明确 → 不买
- 单股仓位破30% → 不买
- 当日累计亏损>5% → 冷静期，禁开新仓
- 盘前预案外新方向三道关通过 → 直接执行

### 5.4 轮末自检（返回快扫前全部✅）

- [ ] state.md轮转状态已更新
- [ ] ②发现强势方向 → 已同轮触发③
- [ ] 三维齐但不买 → 已写放弃理由
- [ ] 触发买/卖 → 执行链全部完成
- [ ] 巡盘日志已追加本轮记录

## 六、事件驱动留证

AI是在持续判断，不是定时打卡。有价值的变化才停下来做完整留证。

### 6.1 必须留证事件

| 触发类型 | 具体情形 | 产出文件 | 时机 |
|---------|---------|---------|------|
| 拟执行买卖 | 三维齐+锁定三件事 | HHMM_买卖_标的_思考链路.md | 日内实时 |
| 持仓异动 | 触及止损止盈/日内振幅>5% | HHMM_持仓异动_标的.md | 日内实时 |
| 预期阶段切换 | 持仓方向阶段变化 | HHMM_预期切换_方向.md | 日内实时 |
| 盘中新方向 | 盘前预案外≥2涨停且联动 | HHMM_新方向_方向.md | 日内实时 |
| 关键锚点异动 | 产业数据破位/龙头炸板/政策突发 | HHMM_锚点异动_事件.md | 日内实时 |

以上留证均为日内实时产出。收盘归档checklist A项用于检查日内是否有遗漏。

### 6.2 客观市场节点

| 节点 | 市场变化 | 是否硬性 |
|------|---------|---------|
| 09:30后~10分钟 | 连续竞价开始 | AI自主判断 |
| 11:30 上午收盘 | 半场结束 | AI自主判断 |
| 13:00 下午开盘 | 午休后情绪reset | AI自主判断 |
| **14:50 尾盘** | **不开新仓** | **硬性规则** |

### 8.0 执行预期研究更新（每日必做）

**state.md §四预期追踪表中的全部方向（含持仓与观察）** 都必须每日更新，不限方向类型、不限是否有异动：
- 每个方向统一执行 `operations/预期研究.md 模式B`（B.1-B.5全流程）
- 已失效/结束的方向 → 归档到 archive/，从 state.md §四 移除

原因：预期管理的核心是每天知道每个方向走到哪了，该归档的归档，该升级的升级。
（预期研究负责更新 research 文件，真实看盘不直接写 research）

### 8.2 更新state.md §一§二

### 8.2.1 更新trades.md
当日有交易 → 追加交易明细+更新已平仓/当前持仓汇总+账户概况

### 8.3 每日逐股扫描（预期来源的自下而上兜底）

- **涨停全部过一遍**：`astock query limit <YYYYMMDD>` 获取涨停列表 → 逐只归因→属于哪个方向→是否新方向
- **炸板全部过一遍**：盘中快扫已记录的炸板事件汇总 → 为什么炸？方向还有效吗？
  （astock当前不支持盘后查询炸板，依赖日内快扫/深析实时记录的炸板数据）
- **成交额前50全部过一遍**：`astock query stock --sort-by amount --limit 50` → 异动检测→是否隐含新预期
- **产出**：新方向入库state.md §四 / 已有方向更新阶段

涨停逐只归因是自下而上的兜底：概念板块排名可能遗漏分散在多个概念标签中的强势方向，只有逐只归因才能发现方向的真实强度。
