# 模拟看盘操作手册

> **定位**：收盘后的五阶段回放训练，用历史数据训练决策能力。
> 系统知识引用：核心框架.md（判断）、买卖规则.md（决策）、数据验证.md（数据）
> 数据源：astock历史数据 → operations/数据验证.md

---

## 一、启动序列

```
□ 读取 data/state.md → 加载持仓+现金+预期追踪
□ 读取 data/daily/YYYY-MM/DD-盘前分析.md → 提取今日催化清单(C1/C2/...)
□ 读取 system/核心框架.md → 加载判断框架
□ 读取 system/买卖规则.md → 加载决策规则
□ 获取今日涨停股明细 → operations/数据验证.md §2.1
□ 获取概念排名 → operations/数据验证.md §2.3
□ 获取T-1先行信号（昨日涨停统计）→ operations/数据验证.md §2.1
□ 将概念排名与盘前催化清单交叉核对
```

---

## 二、五阶段流程

### 阶段1：加载盘前分析

- 提取盘前分析的催化清单和预案（P1/P2/P3方向）
- 确认盘前分析对每个方向的预判：确认信号、失效条件、if-then预案

### 阶段2：开盘回放

按时间线推进（09:25→10:00→10:30→13:00→14:30→15:00），逐时观察盘面变化：

- **严格盘中视角**：只使用当时可知的信息，不用收盘后才知道的信息
- 每到一个时间节点，检查盘前预案是否被触发
- 概念去噪（三维确认前强制完成）：
  - 个股归因：每只涨停股追问"实际催化是什么？"
  - 主驱动聚合：按归因结果重新分组，每只股只计入一个方向
  - 正宗龙头验证：该方向公认龙头是否在响应？
  - 连板股检查：连续2天+涨停 → 追问独立催化源

**盘中新方向处理**：
- 出现预案未覆盖方向（≥2涨停）→ 暂停回放
- 走盘前分析.md §三评估（方向有效性筛选+三维确认）
- 记录为"盘中新方向"，标注发现时间点和评估结论

### 阶段3：买卖决策执行

当三维确认齐全时，严格执行买卖规则.md：

**买入流程**（→买卖规则.md §二）：
- 确认三维齐全（资金+预期依据+价格，每个引用具体数据）
- 执行主板筛选：方向全部标的 → 排除创业板/科创板/920xxx
- 确定买点类型和仓位
- 锁定买前三件事：预期/兑现标志/失效标志
- 估算买入价格（基于标的涨停时间和前日收盘价）

**卖出流程**（→买卖规则.md §四）：
- 对照持仓的兑现/失效信号
- 按卖出判断三步流程执行

### 阶段4：收盘评估

- 预期确认/兑现/失效了吗？对照盘前判断 vs 实际
- 盘中感知准确度：哪些信号提前预示了预期变化？
- 覆盖诊断：今天有没有在加速期才发现某个方向？→ 追问为什么盘前没扫到

### 阶段5：复盘与绩效评估

#### 5.1 复盘交易
每笔交易回顾：预期是什么？确认/兑现/失效了吗？决策合规吗？

#### 5.2 更新预期阶段
→ 核心框架.md §3.1，标注各方向阶段变化 + 触发 `operations/预期研究.md 模式B`（更新 research 文件）

#### 5.3 覆盖诊断
加速期才发现的方向 → 追问出现期/确认期在哪里，为什么盘前没扫到

#### 5.4 更新state.md §一§二
虚拟账户：持仓+现金+总资产

#### 5.5 合规检查
- [ ] 每笔交易是否对照了三维确认？
- [ ] 买入前是否锁定了三件事？
- [ ] 卖出是否基于预期逻辑而非价格？
- [ ] 是否遗漏了盘中感知的新方向？
- [ ] 复盘标准：赚钱违规=错误 / 亏钱合规=正确

---

## 三、决策规则

- 所有买卖决策严格索引 `system/买卖规则.md`
- 视角：严格盘中，禁止使用收盘后信息
- 三维确认方法同盘前分析.md §3.4

---

## 四、输出

写入 `data/daily/YYYY-MM/DD-模拟看盘.md`，按reference/每日文档模板.md格式。

输出内容包括：
- 各时间节点盘面快照
- 买卖决策明细（含三维确认数据）
- 持仓+账户更新
- 复盘与合规检查
- 覆盖诊断结论
