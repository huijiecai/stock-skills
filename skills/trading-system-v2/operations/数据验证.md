# 数据验证与astock操作指南

> **边界**：本文件定义数据获取的规范和操作方法。
> 行情数据是交易决策的基础设施，所有数据必须经astock验证，禁止凭记忆/印象。

---

## 一、核心原则

- **astock是唯一行情数据入口** — 所有行情数据（报价/K线/涨停/板块/指数）必须通过astock获取
- **禁止凭记忆引用数据** — 任何行情数据必须实时拉取验证，不能用"上次看到是..."
- **WebSearch只用于消息面** — 政策/公告/研报/外盘消息，禁止用WebSearch替代行情查询
- **禁止curl直读数据库** — 不直连ClickHouse/PostgreSQL

---

## 二、数据获取（按数据类型）

先同步，后查询。查询前必须确认数据已同步（见§2.5）。

### 2.1 市场概览数据

需要：三大指数、涨跌停统计、成交额、市场情绪。

```bash
astock query market                                    # 三大指数/涨跌停/成交额
astock query limit YYYYMMDD --exclude-st               # 指定日期涨停统计
astock query limit ladder                              # 连板天梯（当日/最近）
```

### 2.2 个股数据

需要：股票代码、报价、K线、分时。

```bash
astock query meta                                      # 股票代码搜索/验证
astock query kline 000630 --date YYYYMMDD --limit 30   # 日K线
astock query kline 600487 --freq 1m --date YYYYMMDD --limit 240  # 分钟K线
astock live quote 600519                               # 实时报价（盘中）
astock live minute 600519                              # 分时数据（盘中）
```

**注意**：指数/板块需用kline而非live quote查询。

### 2.3 板块数据

需要：概念排名、板块成分股、板块联动。

```bash
astock query block rank --date YYYYMMDD --type concept --limit 30  # 概念排名（历史）
astock live block rank --type concept --limit 30                    # 概念排名（实时）
astock live block members <板块代码> --json                         # 板块成分股（实时）
```

### 2.4 数据同步

所有查询前必须确认数据已同步。同步时机：每日盘前一次、盘后一次。

```bash
# 全市场日K同步（日常）
astock sync all --all --days 1 --skip-info --skip-finance --skip-xdxr --skip-minute

# 指定个股同步
astock sync all --code 600487,002463 --days 1 --skip-info --skip-finance --skip-xdxr

# 分钟K线同步（盘中需要时）
astock sync kline --code 603893 --freq 1m --days 1
```

**验证同步状态**：`astock stats` 或 `astock query kline <code> --limit 1`，确认最新日期。

### 2.5 实时监控

```bash
watch -n 300 './astock live quote 002407 002463 ...'
```

## 三、强制验证（引用数据前必做）

| 验证类型 | 何时执行 | 方法 | 典型错误 |
|---------|---------|------|---------|
| **代码验证** | 查询个股前 | `query meta` / WebSearch | 中船特气688626(错)→688146(对)→涨跌全反 |
| **同步验证** | 查询特定日期前 | `stats` 或 `kline --limit 1` | 用6/18数据当6/22→黄河旋风+5.34%(实际涨停) |
| **涨停验证** | 引用涨停数时 | `query limit YYYYMMDD` | 磷概念12涨停(实际4) |
| **K线验证** | 引用涨跌/连板时 | `query kline <code>` | 直接采信consecutive_days |

---

## 四、分析准确性五步法

做方向分析时，必须按以下顺序思考：

1. **预期是什么** — 必须说出具体催化（涨价/政策/业绩），不能是"这个板块在涨"
2. **资金在炒什么** — WebSearch + astock验证，禁止直接采信概念标签
3. **个股归因** — 每只涨停股追问"实际催化是什么？"，每只只归入一个方向（主驱动）
4. **正宗龙头验证** — 该方向公认的龙头是否响应？龙头不响应 = 方向不成立
5. **标的列表按产业链排序** — 直接受益→相关→不相关。禁止从涨停清单倒推标的

---

## 五、典型错误与注意事项

### 数据错误案例

| 错误类型 | 具体表现 | 后果 |
|---------|---------|------|
| 数据未同步 | 用6/18数据当6/22 | 黄河旋风+5.34%（实际涨停+9.99%） |
| 代码错误 | 中船特气688626(错)→688146(对) | 涨跌全反 |
| 涨停数凭记忆 | 磷概念12涨停 | 实际只有4只 |
| 概念标签直接归因 | 氟概念10涨停 | 实际只有3只 |

### 违反五步法的典型表现

- 多氟多挂"氟概念"→归入电子特气，但实际驱动是六氟磷酸锂（锂电池）
- 磷化工归因为磷矿石涨价，实际是磷酸铁锂价格翻倍
- 和远气体/康强电子/百合花不是电子特气却列入标的
- 中船特气（正宗龙头）不在标的列表中

### 注意事项

- **连板数据必须K线逐日验证** — `consecutive_days`是区间涨停总天数，不是连续天数
- **龙虎榜是滞后数据** — 盘后披露，不参与当日盘中判断，仅作次日参考
- **astock缺命令/字段 → 补到astock里** — 不要绕开工具自建查询
