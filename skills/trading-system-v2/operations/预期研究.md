# 预期研究操作手册

> **定位**：research/expectations/ 文件的**唯一写入者**，双模式运行。
> **核心原则**：盘前分析/真实看盘/模拟看盘只能读取和触发，不能直接修改 research 文件。
> 系统知识引用：核心框架.md（判断）、数据验证.md（数据）
> 外部工具：WebSearch（消息面）、xueqiu.com（本土催化）、astock（行情数据）

---

## 一、写权限规则

```
盘前分析/真实看盘/模拟看盘  ──检测到信号──>  触发预期研究  ──分析+更新──>  research/expectations/*.md
```

- **预期研究**是 research/expectations/ 的唯一写入者
- 其他操作文件发现需要更新 research 时，写 `→ operations/预期研究.md 模式B`
- 原因：确保每次更新都经过完整评估流程，防止 AI 随意修改预期逻辑链

---

## 二、模式A：新方向深度研究

**触发**：盘前分析/真实看盘/模拟看盘发现新方向，且对产业链/标的不熟悉。

### A.1 行业分析

按reference/行业分析模板.md格式，完成以下步骤：

1. **产业链全景**：上游→中游→下游，各环节的核心玩家和供需关系
2. **核心驱动**：什么因素驱动这个行业（政策/技术/需求/供给）
3. **A股标的映射**：各环节对应的A股上市公司，标注龙头
4. **确认/失效信号**：什么数据/事件能验证或推翻这个方向的预期

**产出**：`data/research/产业链分析/<方向>产业链分析.md`

### A.2 公司分析

按reference/公司分析模板.md格式，完成以下步骤：

1. **基础身份**：公司主营、市值、行业地位
2. **财务健康**：营收趋势、利润率、负债率
3. **业务结构**：收入构成、核心产品线、客户集中度
4. **产业链位置**：在行业分析中的定位，上下游关系

**产出**：`data/research/companies/<公司>.md`

### A.3 创建预期文件

在 `data/research/expectations/<方向>-<标的>.md` 创建文件，使用统一模板：

```markdown
# <方向名> — <核心标的>

> 状态：观察 | 阶段：出现期 | 首次识别：YYYY-MM-DD

## 一、预期概要
| 项目 | 内容 |
| 预期类型 | 持续数据型/事件节点型 |
| 核心逻辑 | 一句话 |
| 催化锚点 | 可验证的数据/事件 |
| 买入前三件事 | 预期/兑现标志/失效标志 |

## 二、核心标的
| 角色 | 标的 | 代码 | 说明 |

## 三、每日跟踪日志
| 日期 | 催化进展 | 资金面 | 价格确认 | 阶段变化 | 备注 |
|------|---------|--------|---------|---------|------|
```

**数据来源**：
- WebSearch搜索行业研报、产业新闻、公司公告/财报
- xueqiu.com搜索相关话题讨论
- 行情数据获取方法 → operations/数据验证.md

## 三、模式B：已有预期更新

**触发**：
- **每日例行**：收盘归档时，所有活跃预期方向都必须更新一次（→ 真实看盘.md §8.0）
- **事件触发**：盘前分析/真实看盘/模拟看盘检测到活跃方向有异动（催化更新/板块异动/阶段变化）

**关键**：不是简单追加一行，而是先走完整评估流程再更新。无异动时可轻量更新（确认阶段未变+行情快照）。

### B.1 加载预期文件

读取 `data/research/expectations/<方向>.md`，回顾完整逻辑链。

### B.2 拉取最新数据

- astock query 标的最新行情（→ operations/数据验证.md）
- WebSearch 搜索最新催化进展

### B.3 完整评估

对当前状态做四维评估：

1. **催化进展**：核心催化是否有新数据/事件？
2. **资金面**：板块联动、涨停数、资金流向是否有变化？
3. **价格确认**：标的是否创新高/跌破关键位？
4. **阶段判断**：当前处于五阶段的哪个阶段？是否有阶段变化？

### B.4 更新跟踪日志

在预期文件 §三"每日跟踪日志"追加一行：

```
| 日期 | 催化进展 | 资金面 | 价格确认 | 阶段变化 | 备注 |
```

### B.5 同步 state.md §四

更新 state.md §四 对应行的阶段、当前价、今日变化。
