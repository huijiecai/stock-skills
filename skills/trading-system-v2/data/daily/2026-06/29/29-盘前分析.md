#### 沪电（PCB）— 持有

- **阶段**：加速期（6/26获利回吐后）
- **三维确认**：资金✅(6/26 PCB 3涨停·广合43亿+超声2连板+贤丰2连板) + 价格✅(147.28>104.5失效线+40%) + 预期依据✅(CCL涨40%+电子布涨100%持续验证)

- **结论**：✅全部未触发·**持有**

#### 亨通（光通信）— 持有·⚠️ 失效临界

- **阶段**：加速期（6/26大幅回调·-9.91%收近最低）
- **三维确认**：资金❌(**6/26光通信实际0涨停**·astock grep验证·正帆/宏柏/新亚强标签含光通信但驱动是设备/有机硅·无一只光纤逻辑涨停) + 价格✅(110.81>89.55失效线+23.7%) + 预期依据✅(光棒涨550%·紧缺至2027未变)
- **失效条件**（全部用“+”连接·需全部触发才清仓）：
  - ①光通信涨停≤2只连续2天⚠️ **Day1已计入**(6/25仅光电股份1只+6/26为0只·6/29若继续≤2只=①触发)
  - ②破89.55❌(110.81·距失效线+23.7%·远未触发)
  - ③光纤现货价转跌❌(光棒涨550%持续·远未触发)
  - ④AI算力投资大幅放缓❌(无新数据)
- **⚠️ 诚实评估**：失效标志用“+”连接=全部触发才清仓。目前①是临界状态·但②③④均未触发=**系统上不需要清仓**。但①如果6/29触发=第一个危险信号落地·叠加-9.91%收近最低+板块0涨停=高度警惕。**不是“必须清仓”·而是“第一个红灯亮了·密切关注剩余条件”**

#### 博迁（MLCC）— 持有·⚠️ 放3倍量触板不封

- **阶段**：加速期（倒计时催化7/1·但6/26出现高位放量信号）
- **三维确认**：资金⚠️(博迁+6.95%全场唯一正收益·**但触涨停271.52未封住·成交52.57亿=6/25的3倍·换手7.64%**) + 价格✅(264>182.4失效线+45%) + 预期依据✅(村田7/1第三轮涨价10-40%倒计时2天)
- **失效条件**：MLCC连续2天无主板涨停❌ + 破182.4❌(264) + 涨价周期结束❌
