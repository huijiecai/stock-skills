## 一、产业链全景

### 产业链结构图

```
上游（材料）
  ├─ 陶瓷粉体（钛酸钡）→ 国瓷材料(300285)❌ / 三环集团(300408)❌
  ├─ 镍粉（内电极）    → 博迁新材(605376)✅ ← 持仓标的
  ├─ 离型膜/载带       → 洁美科技(002859)✅
  ├─ 聚酯电容膜        → 双星新材(002585)✅
  └─ 钨/镍金属         → 厦门钨业(600549)✅（交叉标的）
  ↓
中游（MLCC制造）← 核心价值环节
  ├─ 通用MLCC → 风华高科(000636)✅ ← 方向锚 / 三环集团(300408)❌ / 达利凯普(301566)❌
  └─ 军工MLCC → 火炬电子(603678)✅ / 振华科技(000733)✅ / 鸿远电子(603267)✅
              → 宏明电子(301682)❌ / 宏达电子(300726)❌
  ↓
设备
  └─ MLCC测试/分选 → 博杰股份(002975)✅ / 骄成超声(688392)❌
  ↓
下游（应用终端）
  ├─ AI服务器 → 村田(海外) / 风华高科(国产替代)
  ├─ 消费电子（5G手机单机1000+颗）
  └─ 汽车电子（电动化+智能化）
```

### 价值核心环节

| 环节 | 价值占比 | 技术壁垒 | 利润率 | 受益逻辑 |
|------|---------|---------|--------|---------|
| MLCC制造（中游） | ~60% | 高（配方+烧结工艺） | 25-35% | AI服务器用量×3 + 涨价直接传导 |
| 镍粉（上游） | ~15% | 极高（国内仅博迁PVD法） | 30%+ | MLCC核心原料，涨价周期受益 |
| 钛酸钡（上游） | ~10% | 高 | 20-25% | MLCC介质材料，但国瓷在创业板不可买 |

> **价值核心在中游制造**：MLCC厂商直接受益于涨价+需求扩张。但A股正宗MLCC制造商（三环集团、国瓷材料）均在创业板，主板可买龙头为风华高科。
>
> **产业链三大壁垒**：①陶瓷粉体配方（日美主导，国内仅三环/风华/国瓷掌握）②叠层印刷技术（日企2μm/1000层，国内3μm/300-500层）③共烧技术（不同材料收缩率匹配）
