## 一、产业链结构

```
第1层：最上游原材料
  铜箔 ← 铜冠铜箔（出货量第一）、诺德股份、德福科技、嘉元科技（英伟达认证）
  玻纤纱 → 玻纤布 ← 宏和科技（中国唯一超薄电子布）、中国巨石
  环氧树脂 ← 宏昌电子（英伟达链：供货胜宏/沪电/欣兴）、圣泉集团
  油墨/光刻胶 ← 广信材料（PCB光刻胶）
  药水 ← 天承科技（PCB电镀药水）
    ↓
第2层：覆铜板CCL（把铜箔+玻纤布+树脂压在一起）
  生益科技（全球第二，内资第一）
  金安国纪（内资前三，纯CCL 90%+）
  南亚新材（偏高端CCL/PP半固化片）
  华正新材（高端CCL+CBF膜，华为认证）
    ↓
第2.5层：封装基板材料（先进封装用）
  华正新材 ← CBF膜（ABF膜国产替代，通过兴森验证）
  味之素（日本）← ABF膜全球垄断95%+
    ↓
第3层：PCB制造（蚀刻出电路）
  ┌── AI GPU板卡 ──────────────┐
  │   胜宏科技（AI服务器PCB全球第一，英伟达GPU 50%+，2025净利43亿+273%）│
  │                              │
  ├── AI服务器主板 ──────────────┤
  │   广合科技（算力服务器PCB全球前三，覆盖全球前十大服务器厂8家，2025净利10.2亿+50%）│
  │                              │
  ├── 全品类+IC载板 ─────────────┤
  │   深南电路（营收最大，PCB+IC载板+电子装联全产业链，华为核心供应商）│
  │                              │
  ├── 数据中心+汽车 ─────────────┤
  │   沪电股份（数据中心+汽车PCB）│
  │                              │
  ├── FPC柔性板（苹果链）────────┤
  │   东山精密、鹏鼎控股（全球最大FPC）│
  │                              │
  └── 其他 ──────────────────────┘
      世运电路（汽车）、景旺电子（全品类）、崇达技术（通信/服务器）、迅捷兴（小批量快板）
    ↓
第3.5层：IC封装基板（芯片封装用，比普通PCB更高端）
  兴森科技（国内先行者，FCBGA，华为海思核心供应商）
  深南电路（也做IC载板）
  （台资）：欣兴电子、南亚塑胶、景硕科技
    ↓
第4层：PCB生产设备
  大族数控（大族激光子公司，激光钻孔/曝光/AOI）
  快克智能（固晶/焊接设备）
    ↓
第5层：终端应用
  AI服务器 ← 英伟达（→胜宏/沪电）/ 华为昇腾（→华正CCL→深南/广合/兴森IC载板）
  消费电子 ← 苹果（→鹏鼎/东山）
  通信设备 ← 华为、中兴（→深南/兴森/光迅）
  汽车电子 ← 特斯拉、比亚迪（→世运/沪电）
  数据中心 → 深南/沪电/胜宏/广合
```

### 关键认知

**胜宏科技 = AI GPU的"心脏"**
- 英伟达GPU 50%+、AMD 40%、LPU 55%+
- 2025净利43亿远超深南33亿和沪电38亿
- 但4/8涨7.93%未封板（龙头分歧信号）

**广合科技 = AI服务器的"骨架"**
- 不做GPU板卡，做的是整个服务器的主板
- 覆盖全球前十大服务器制造商中的8家（戴尔/HPE/联想/超微等）
- Q1 2026预告净利+58%~66%——**仍在加速**
- 是"隐形冠军"，市场关注度远低于胜宏和深南
- A+H双平台上市

**深南电路 = "全能选手"**
- PCB+IC载板+电子装联三业务并行
- 华为核心供应商+英伟达有份额
- IC载板是长期看点（国产替代）

## 七、IC封装基板（先进封装）

### ABF膜/CBF膜

ABF膜（味之素垄断95%+）是高端IC载板（FCBGA）的核心材料。CBF膜是国内对ABF膜的国产替代叫法。

| 公司 | 定位 | 进展 |
|------|------|------|
| **华正新材** | CBF膜材料商 | 通过兴森科技验证，小批量调试中 |
| **兴森科技** | IC载板制造商（用CBF膜做载板） | FCBGA国内产能最大，华为海思核心供应商 |
| **深南电路** | IC载板+PCB | 也有IC载板业务 |

### IC载板涨价预期（2026年）

BT载板（存储用）和ABF载板（CPU/GPU用）供需紧缺。受益标的：深南电路、兴森科技。

### 涨价传导路径

```

  → CCL厂商涨价（建滔+10%、MGC+30%）
    → PCB厂商涨价传导（有定价权的高端厂）或利润挤压（无定价权的低端厂）
```
