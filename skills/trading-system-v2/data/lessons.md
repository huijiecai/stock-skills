## 一、盘前准备

### L001: 盘前催化扫描方法论——必须"催化→方向"，不能"方向→催化"

- **日期**：2026-04-13（根因），3/27（首次暴露）
- **问题**：盘前分析的扫描方法是"先列已知方向，再找催化"——只能看到已知方向的催化，框架外的方向全部漏掉。3/27创新药BD数据571亿盘前可查但未覆盖→错过美诺华6天5板；4/13大摩锂供需报告盘前可查但未覆盖→龙头涨停买不到。反复重演的根本原因不是"扫描不够仔细"，是"扫描方向搞反了"。
- **修正**：
  1. 先扫催化源：过去48小时有哪些新研报/产业数据/政策/公告？（不带方向预设）
  2. 再映射方向：每个催化指向什么方向/子方向？有没有全新方向？
  3. 最后评估：对每个方向做三维确认预评估+设定买入条件
- 已同步更新交易系统盘前流程（v3.5→v3.6）

### L002: 催化扫描颗粒度要细到"子方向级"，不能停留在"板块级"

- **日期**：2026-04-13
- **问题**：盘前覆盖了"储能/电气设备"方向，但只设了"德业涨停"作为买入条件。实际核心驱动是"锂矿"子方向（大摩锂供需2026H2短缺），龙头是盛新锂能而非德业。同日基建玻纤方向也因被笼统归为"CCL同链条"而错过。
- **影响**：同一天错过两个三维确认齐全的方向。
- **修正**：盘前催化扫描从"板块级"细化到"子方向级"（如"储能"要拆为锂矿/电网/电池/光伏），对每个子方向独立做三维确认评估和龙头识别。

### L003: 市场可以多主线并行，不要默认只有一条

- **日期**：2026-03-27
- **问题**：旧思维默认"市场同一时间只有一条主线"。但3/27锂电和创新药同时爆发，各自有独立的逻辑和资金。
- **修正**：成交额2万亿以上时，市场有能力支撑2-3条并行主线。关键看各主线之间是"抢钱"关系还是"共振"关系。

## 二、盘中判断

### L004: 分歧 ≠ 退潮，判断方法是回到锚

- **日期**：2026-03-27
- **问题**：将3/26-27简单判定为"退潮期"（看涨跌家数4400跌、涨停39），实际是分歧期。华电辽能断板仅跌0.90%=典型分歧，华电能源仍8板涨停=核心还在。用市场广度指标（涨跌家数）替代了结构指标（龙头表现+板块联动），导致错过锂电再确认买点。
- **修正**：判定阶段时必须优先看结构指标（龙头+板块联动），广度指标是辅助。预期依据还在被验证→分歧，等再确认。预期依据被否定→退潮，空仓。
- **⚠️ 适用边界**：L004管的是"预期依据维度"（卖出流程Step 2），不能用它绕过"资金确认维度"（Step 3）。详见L012。

### L005: 板块内部的"分化"比"切换"更常见

- **日期**：2026-03-27
- **问题**：盘前假设电力板块会"高低切换"，实际是极端分化：新能泰山4连板，湖南发展大跌。
- **修正**：分析板块时要看内部结构——哪些在涨、哪些在跌、资金往哪个细分方向集中。

### L006: 事件催化可以验证独立行情的存在

- **日期**：2026-03-27
- **问题**：商业航天被归类为"情绪预期"，实际太原卫星发射给了真实事件催化。
- **修正**：要区分"纯概念"和"有事件验证的概念"，有事件催化的不能简单按情绪预期处理。

### L007: 缩量上涨是价格和资金的背离信号

- **日期**：2026-03-27
- **问题**：沪指+0.63%但成交额年内地量。价格涨但钱在撤，背离没被重视。
- **修正**：1天缩量可能是正常修复，连续2-3天缩量上涨=增量资金不愿进场，反弹可能乏力。放量+价格涨=真正确认。

### L008: 高开高走日往往缺乏分歧确认点

- **日期**：2026-04-01
- **问题**：市场高开高走，全天缺乏"分歧后确认"的建仓机会。
- **修正**：宁可错过也不追高。可以关注尾盘是否有分歧机会。

### L009: 外围大涨可以快速扭转情绪周期判断

- **日期**：2026-04-01
- **问题**：盘前判断"修复期→退潮边界"，但美股+2%→A股高开高走，沪指+1.46%。
- **修正**：情绪周期判断需要考虑隔夜外围因素，盘中应快速根据实际数据修正判断。

### L020: 首板核心筛选五步法——找真正主动走强+强预期驱动的公司

- **日期**：2026-05-13（首板分析实战提炼）
- **问题**：每天涨停100+只，其中大量是连板、小票、蹭概念、尾盘跟涨——如果只看成交额和涨停时间很容易误判（如中恒电气40亿成交但4次炸板尾盘回封=质量差）。需要一套系统方法论快速筛出核心。
- **方法**：
  1. **数据筛基础池**：排除连板（对比T-1）→ 排除非主板 → 成交额≥5亿
  2. **方向聚类**：按 astock query block rank 概念分组，识别共振方向（涨停数≥3+封板时间跨上午/下午）
  3. **多维度深挖**（每只候选股过四关）：
     - 预期溯源：涨的是什么预期？独立催化还是蹭概念？
     - 正宗度验证：概念交叉数+产业链位置+行业地位
     - 主动走强证据：封板时机（领涨vs跟涨）+ 封板质量（炸板次数）
     - 资金确认：成交额量级+同方向对比
  4. **瑕疵排查**：位置风险（已涨超15%？）、炸板风险（≥3次）、尾盘封板、概念噪音
  5. **综合排名**：预期强度(40%) × 主动走强(35%) × 正宗度(25%)
- **5/13实战验证**：用此方法筛出生益科技(CCL涨价+AI高端化，早盘独立领涨)和雅克科技(前驱体涨价+存储扩产，午后暴动第一枪)为TOP2核心，科士达(预期不够锋利)和节能风电(防御型无想象空间)被正确降级，中恒电气(4次炸板尾盘回封)被正确剔除。
- **已同步写入**：SKILL.md「首板核心筛选方法论」

## 三、持仓管理

### L010: 炸板次日必须查产业数据锚

- **日期**：2026-03-30
- **问题**：融捷炸板+放量23%，但如果3/31开盘前没查碳酸锂期货价格，可能错过最佳退出时机。
- **修正**：
  ```
  炸板次日操作清单：
  1. 9:00前查产业数据锚（如碳酸锂期货）
  2. 9:25集合竞价看龙头开盘价
  3. 产业数据锚破位+龙头低开→开盘即卖
  4. 产业数据锚未破+龙头平开→观察10:00前承接
  ```

### L011: 放量炸板是预警信号，不是卖出信号

- **日期**：2026-03-30
- **问题**：容易犯"炸板就卖"的错误，但炸板后的价格行为才是关键。
- **修正**：
  ```
  炸板后收盘仍+3%以上 → 分歧，持有观察
  炸板后收绿或-3%以下 → 失效，次日开盘卖
  炸板后次日低开-3%以上 → 失效确认，立即卖
  ```

### L012: 卖出判断三步流程必须完整执行——资金确认消失是独立卖出条件

- **日期**：2026-04-15
- **问题**：深南电路连涨6天后，4/15 PCB板块全线大跌（0只涨停），资金轮动到创新药（13只涨停）。但初版判断"持有不动"——理由是"预期依据(CCL涨价函+Q1业绩)不变=持有"，引用L004"分歧≠退潮"。实际上跳过了卖出流程Step 3。
- **系统卖出流程**：
  ```
  Step 1：兑现期/结束期？→ 立即卖
  Step 2：预期失效信号？→ 卖
  Step 3：资金确认还在吗？→ 板块联动消失+资金在撤 → 减仓或清仓
  ```
  Step 3是独立的卖出触发条件，不需要预期依据同时被否定。
- **修正**：
  1. 卖出判断必须三步全走，不能因Step 2的"预期依据不变"跳过Step 3
  2. 盘前预案的"持有条件"必须覆盖卖出三步的反面
  3. L004"分歧≠退潮"针对Step 2，不能用它绕过Step 3
  4. 风格切换日：旧方向资金确认崩塌+新方向三维确认完整 → 同时执行"卖旧+买新"

### L013: 标的选择必须用系统的龙头识别规则，不能用基本面分析替代

- **日期**：2026-04-15
- **问题**：创新药三维确认完整后，用自制的基本面筛选报告（"14条最大受益者+创新药收入占比"）选了恒瑞医药(+2.76%)，而不是用系统的龙头识别规则选标的。实际龙头是美诺华(+8.91%，经过分歧→再确认的领涨股)或板块涨停股（海正/哈药/双鹭等）。
- **错误根源**：和L012同类——**用自己的分析替代系统规则**。
- **修正**：
  1. 龙头识别只看市场行为（领涨性+主动性+高位性），不看基本面
  2. 打板涨停股=最强价格确认，系统明确支持
  3. "龙头买不进就不参与"——不是"买个权重替代"
  4. 不要在系统规则之外额外加流程，这会干扰系统决策

### L014: 持续数据型预期必须主动查锚

- **日期**：2026-03-27买入→3/31卖出
- **问题**：持续数据型预期（有数据锚）的退出信号清晰，但盘中必须主动查锚才能用上优势。
- **修正**：持续数据型预期的数据锚加入盯盘清单：锂电→碳酸锂期货；油气→布伦特原油；创新药→BD交易数据/临床进展。

### L015: 确认买点的持有周期通常是3-5天

- **日期**：2026-03-27买入→3/31卖出（3个交易日）
- **问题**：确认买点的本质是"吃一段确认行情"，持有超过5天可能从"确认行情"变成"博傻行情"。
- **修正**：
  ```
  确认买点：3-5天 | 首板买点：5-10天 | 回调买点：10-20天
  持有超过周期上限→即使未触发退出信号，也应减仓50%
  ```

### L016: 持仓过周末/假期需要有事件风险预案

- **日期**：2026-03-27（周五收盘）
- **问题**：融捷4连板过周末，系统没有周末事件风险预案。
- **修正**：周五收盘前，如果持仓处于高位，必须评估周末可能出现的利空。风险可控→持有；风险大且仓位重→减仓至舒适水平。

### L019: 卖出条件必须可追溯至买入预期——禁止引入无关价格线

- **日期**：2026-05-13（兆易创新清仓错误）
- **问题**：兆易创新5/6买入时锚的是"存储超级周期+美光新高"，但5/13盘前分析设了349.20清仓红线——这条线的依据是"巨量上影→Day 1分歧→Day 2铁底再破"的价格形态判断，和买入时定义的预期（存储超级周期）没有任何逻辑关系。当天存储板块午后暴动（德明利/雅克/斯达/工业富联集体涨停），预期不仅未结束反而在强化，但349.20已在开盘触发清仓，买卖依据不一致导致了错误卖出。
- **根因**：盘前分析用技术形态止损替代了系统的纯预期止损原则。系统2.4写的是"预期依据仍在验证→持有"，但实际执行时把价格线当成了卖出依据。
- **修正**：
  1. 盘前分析新增的任何卖出条件，必须能回答：**"这个条件和买入时定义的预期是什么关系？"** 回答不上来 = 不能用
  2. 纯价格线（如破XX元）、技术形态线（如巨量上影+铁底再破）不能独立作为卖出条件——它们必须和买入预期有因果链
  3. 正确示例：买入预期=存储超级周期 → 可新增"存储现货价跌破X"（直接验证预期）或"存储板块连续2天无涨停"（资金不认了）
  4. 已同步写入 trading-system.md 2.4卖出规则 + SKILL.md R7红线

## 四、数据与工具

### L017: 换手率是感知信号，不是触发条件

- **日期**：2026-03-27
- **问题**："换手率>15%就减仓"太机械，可能在预期最确认的时候卖出。
- **修正**：换手率异常→感知到筹码交换加剧→回到核心问题：预期是被确认了还是被兑现了？

### L018: 连板数据必须用astock日线验证

- **日期**：2026-04-06
- **问题**：把涨停数据的“炸板:4次”误读为“4连板”，实际“炸板”是指当天封板被打开次数，和连板天数无关。
- **修正**：连板判断 = `astock query limit ladder` 查连板天梯，或用 `astock query kline --freq daily` 验证连续N天 pct_chg ≈ +10% 且 close ≈ high。不确定的数据标“待验证”。

### L019: 盘中感知新方向——“盘前未覆盖”≠“无预期依据”，必须独立评估催化源

- **日期**：2026-06-02
- **问题**：盘中感知发现光通信/光纤方向8只涨停+亨通光电155亿天量，三维实际3/3齐（资金✅+预期✅AI算力光纤需求+价格✅），但将“盘前分析未覆盖此方向”误判为“预期依据维度缺失”（标⚠️），导致未买入。R10要求三维齐全必须行动，实际违反了此红线。
- **根因**：混淆了“盘前未预研”和“无产业催化”两个完全不同的概念。盘中感知的设计目的就是捕捉盘前未覆盖的方向。预期依据应评估产业催化是否存在（AI算力网络光纤需求+800G/1.6T升级=明确催化），而非“盘前是否已覆盖”。
- **影响**：错过长江通信(600345)13:33封板的主板买入窗口（7.6亿/主板可买）。
- **修正**：盘中感知新方向的预期依据维度，必须独立评估产业催化源（什么类型预期？锚点是什么？可追踪吗？），禁止以“盘前未覆盖”为由直接标⚠️。templates.md已明确“禁止以‘非盘前预案方向’为由跳过”。

### L021: 暴跌后次日·情景概率不应偏向恐惧·超跌反弹是统计高概率事件

- **日期**：2026-06-09
- **问题**：6/8费城-10.26%后·盘前给情景B(低开震荡)40%最高概率·给情景A(修复)仅35%。实际沪指+1.28%·142只涨停(vs6/8仅55只)·市场选择最强反弹路径。过度关注"费城第二波冲击"·忽视了"暴跌后次日反弹"的统计规律和"6/8 A股已消化第一波"的事实。
- **影响**：虽然操作纪律正确(持仓以守为主)·但情景预判偏差导致对半导体设备等超跌反弹方向完全漏扫(10+只涨停)
- **修正**：
  1. 暴跌后次日·如果当日已充分消化冲击(A股-1.7%+亚太暴跌)·次日情景概率应偏向"修复/反弹"而非继续偏向"第二波冲击"
  2. 盘前八维扫描必须增加"前日跌幅最大方向的超跌反弹可能性"维度
  3. "恐惧后的恐惧"本身就是可被定价的——当所有人都在恐惧第二波时·反弹反而更容易发生

### L022: 盘前漏扫不等于盘中可以不评估——盘中感知机制是覆盖盲区的安全网

- **日期**：2026-06-09
- **问题**：半导体设备10+只涨停在盘前完全漏扫。但盘中10:30三维确认时正确识别了"多为科创板不可买+缺独立催化锚"·未被市场热度裹挟
- **正面经验**：系统的盘中感知机制+三维确认框架+主板筛选规则(R11)+加速期不追规则·形成了一套完整的"安全网"·即使盘前覆盖不足·盘中也能正确评估不冲动
- **强化**：盘前漏扫是覆盖问题(需改进)·但盘中评估是系统能力问题(已验证有效)。L019("盘前未覆盖"≠"无预期依据")已修正了盘中评估的偏见·6/9进一步验证了盘中感知+系统规则的组合有效性

### L023: 已有持仓的强反弹日·"持有不动"就是最优策略

- **日期**：2026-06-09
- **问题**：142只涨停的强反弹日·系统未新增任何买入。可能产生"错过机会"的心理压力
- **事实**：双持仓在强反弹日均走强(亨通涨停+17.27%浮盈/沪电+17.6%浮盈)·总资产+1,098·累计+9.39%。不追涨≠错过·持仓本身就在享受反弹
- **强化**：已有持仓的强反弹日·"持有不动"就是最优策略。追涨新方向反而可能因高位接盘而亏损(如半导体设备多为20cm高位股)。同主题不叠仓(R11)+加速期不追=系统规则在强反弹日同样有效保护了账户
