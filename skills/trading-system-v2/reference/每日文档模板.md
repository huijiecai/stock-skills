# 每日文档模板

> 每个交易日产生以下文件，放在 `data/daily/YYYY-MM/` 下
> 文件名格式：DD-盘前分析.md / DD-模拟看盘.md / DD-看盘.md
> 输出格式遵循本模板，内容遵循 operations/ 对应文件
