# 公司分析标准模板（交易决策导向）

> 版本：v3.0 | 更新：2026-06-22 | 基于：交易系统 v2
> 用途：所有候选标的必须按此模板分析后才能写入知识库。缺一项 = 分析未完成。
> 核心原则：每个字段都要能回答"这和买卖有什么关系"。不是百科全书，是交易决策依据。

---

## 数据获取（astock 命令映射）

> 研究数据统一从 astock 获取，禁止依赖 WebSearch 查财务/行情数据。

| 模块 | astock 命令 | 说明 |
|------|------------|------|
| 模块1 基础身份 | `astock query info <code> --json` | F10：行业/主营/注册地 |
| 模块2 业务拆解 | `astock query info <code> --json` | 主营业务描述 |
| 模块3 财务数据 | `astock query finance <code> --json` | 营收/净利/ROE/股本 |
| 模块4 估值数据 | `astock query kline <code> --limit 30 --ma 5,10,20 --json` | 近期K线+均线 |
| 模块5 核心预期 | `astock query block members <板块代码> --json` | 同板块标的横向对比 |

### 模块5：核心预期（三维确认之"预期依据"）

> 这是模板的灵魂。必须说清楚：买这家公司的理由到底是什么？

#### 5.1 预期是什么（一句话）

> 例："MLCC涨价周期+AI服务器用量×3+村田7月第三轮涨价"
> 例："碳酸锂超级周期+现货价持续上涨+锂矿产能扩张"

#### 5.2 预期类型

| 类型 | 说明 | 退出信号特征 | 当前判定 |
|------|------|------------|---------|
| 持续数据型 | 有可追踪的量化数据（期货价/出货量/排产） | 数据见顶/破位 | □ |
| 事件节点型 | 有明确的一次性事件节点 | 事件兑现/取消 | □ |
| 实时感知型 | 无客观外部数据，依赖盘面判断 | 龙头行为/板块联动消失 | □ |

#### 5.3 预期所处生命周期阶段

| 阶段 | 定义 | 当前处于 | 判断依据 |
|------|------|---------|---------|
| 出现期 | 新预期首次出现，尚未经过市场检验 | □ 是 / □ 否 | 证据： |
| 确认期 | 预期持续性被验证，不只是一日游 | □ 是 / □ 否 | 证据： |
| 加速期 | 预期充分验证，进入主升浪 | □ 是 / □ 否 | 证据： |
| 兑现期 | 预期逻辑开始兑现，本轮定价完成 | □ 是 / □ 否 | 证据： |
| 结束期 | 预期完结，资金已离场 | □ 是 / □ 否 | 证据： |

#### 5.4 兑现标志（什么情况下说明预期在实现，该准备走）

1. **标志1**：（具体指标+时间点）例：一季报毛利率>15%
2. **标志2**：（具体指标+时间点）例：Q2营收同比+40%+
3. **标志3**：（具体指标+时间点）

#### 5.5 失效标志（什么情况下说明预期错了，该跑）

1. **标志1**：（具体指标）例：毛利率持平或下降
2. **标志2**：（具体指标）例：板块连续2天无主板涨停
3. **标志3**：（具体指标）

> ⚠️ 兑现/失效标志买入前锁定，买入后不得修改。后续持仓决策只对照这两组标志。

## 使用规范

1. **每个必填项都不能空**，确实没有数据的写"待查"并标注计划何时查
2. **每个数据都必须有来源**，不允许无来源数据进入知识库
3. **预期必须可验证**——必须有明确的兑现/失效标志，不能模糊描述
4. **风险必须具体**——不能用"市场风险""政策风险"这种万能话术
5. **分析完一家→搜索验证一遍→再写入知识库**，顺序不能乱
6. **股价/市值/PE必须带日期**——A股波动大，昨天的数据今天可能就过时了
7. **财务数据优先从 astock 获取**——`astock query finance <code> --json`，WebSearch 仅补充定性信息
8. **扩展层按方向选填**——标的属于哪条产业链就填哪组，不相关的不用填
