# 预期驱动交易系统 v2

## 一、系统定位

- **一句话**：预期驱动，三维确认决定买卖，AI全权自决
- **两种模式**：模拟看盘（盘后回放训练） / 真实看盘（盘中实时循环）
- **核心逻辑**：识别预期 → 等资金确认 → 确认后买入 → 兑现/失效卖出
- **版本**：v2.0

## 三、操作闭环流程

### 每日循环

盘前分析 → 真实看盘 → 盘后归档 → 次日盘前分析，周而复始。

闭环怎么闭的：
- 盘前分析产出预案（daily/）和更新state.md
- 真实看盘消费预案，执行买卖，产出看盘日志（daily/）+交易记录（trades.md）
- 盘后归档更新state.md（持仓/现金/预期表）+trades.md，产出逐股扫描结果
- 次日盘前分析读取state.md和昨日逐股扫描结果，开始新一轮

### 每个环节做什么

| 环节 | 做什么 | 输入 | 产出 |
|------|--------|------|------|
| 盘前分析 | 八维催化扫描+方向评估+预案+每日更新全部预期 | state.md + WebSearch + astock历史数据 | daily/盘前分析.md + state.md更新 + research/expectations/每日跟踪日志 |
| 真实看盘 | 快扫+深析循环+买卖执行 | state.md + 盘前预案 + astock实时数据 | daily/真实看盘.md + state.md+trades.md更新 |
| 盘后归档 | state全量更新+逐股扫描+交易记录同步 | 当日看盘结果 | state.md+trades.md更新 + 逐股扫描结果 |
| 模拟看盘 | 快扫+深析分钟级循环+决策训练 | state.md + 预案 + astock历史K线 | daily/模拟看盘.md |
| 预期研究 | 行业/公司深度分析（任何操作遇到未知方向时触发） | 核心框架 + 分析模板 + WebSearch | data/research/ |

### 底层支撑

- **system层**（被所有操作引用）：核心框架 + 买卖规则
- **operations/数据验证.md**（被所有操作引用）：astock数据获取方法
- **进化闭环**：操作中发现规则漏洞 → lessons.md → 盘后迭代买卖规则

**闭环说明**：盘前分析产出预案 → 真实看盘执行预案 → 盘后归档更新state → 次日盘前分析消费昨日产出，形成每日闭环。

## 四、核心逻辑速览

> 细节在 `system/核心框架.md` 和 `system/买卖规则.md`

**赚钱逻辑**：识别预期 → 等资金确认 → 确认后买入 → 兑现/失效卖出

**决策树**：
```
市场存在新预期？──否──→ 不买，等
      │是
三维确认齐全？──否──→ 不买，等
      │是
锁定三件事？──否──→ 不买，等
      │是
  执行买入（买点类型决定仓位）
```

**行动纪律**：
- 三维齐但不买 = 必须落盘写明理由
- 复盘标准：赚钱违规=错误 / 亏钱合规=正确
