# 核心框架：预期驱动交易体系

> **边界**：本文件只定义"是什么"和"怎么判断"，不定义"什么时候做"和"怎么做"。
> 盘前怎么发现预期 → operations/盘前分析.md。盘中怎么感知异动 → operations/真实看盘.md。

---

## 一、什么是预期

**预期 = 市场资金正在投票的产业方向或事件催化。**

围绕预期做交易，不是量化公式，是投资者的思维框架。每一个数值都是感知信号，不是机械触发条件。

### 1.1 核心逻辑

- **预期确认 = 买**：市场形成新预期 + 资金完成确认（三维确认）
- **预期兑现/失效 = 卖**：本轮故事讲完 或 故事被证伪

### 1.2 系统原则

- 不猜、不赌、不扛
- 低频，但确定
- 预期不问出处，确认只看资金
- 资金认可就是最好的确认力——有增量资金在进场，就有承接力

## 二、预期的来源与判断

### 2.1 预期从哪来

| 来源 | 说明 |
|------|------|
| 产业催化 | 涨价/缺货/扩产/技术突破/供应链重构 |
| 政策事件 | 产业政策/补贴落地/监管变化/国家级投资 |
| 资金异动 | 板块集体涨停/龙头连续走强/成交量异常放大 |

### 2.2 预期依据四类

判断预期本身有没有站得住脚的逻辑基础：

| 类型 | 特征 | 验证方式 |
|------|------|---------|
| **产业驱动** | 涨价/缺货/扩产/技术突破 | 期货价格、排产数据、供需报告 |
| **成长逻辑** | 业绩拐点/渗透率提升/份额扩张 | 财报数据、行业出货量、市占率 |
| **政策催化** | 产业政策/补贴/监管变化 | 政策文件、投资规模、落地节点 |
| **个股事件** | 重组/回购/业绩预告/股权激励 | 公告内容、业绩数据 |

### 2.3 确认的含义

一个预期被"确认"，意味着三件事同时成立：

- **有资金投票** — 资金真金白银地在进场（联动、量价、封板、承接）
- **有价格响应** — 价格行为验证了预期（突破、涨停、放量）
- **有可验证依据** — 预期背后的逻辑正在被数据验证（→§2.2四类）

**三者缺一=未确认。** 只有逻辑没有资金=空气；只有异动没有锚点=噪音。

### 2.4 统一判断框架（4问）

判断一个方向是否构成有效预期，必须回答四个问题：

| # | 问题 | 含义 |
|---|------|------|
| 1 | **是否有具体锚点？** | 产业数据/政策文件/业绩趋势/事件节点，不能是"感觉要涨" |
| 2 | **锚点是否可追踪？** | 有没有客观数据可以持续验证（期货价格/行业出货量/政策节点等） |
| 3 | **确认信号是否清晰？** | 什么市场行为出现时 = 可以买（如"板块≥3涨停+龙头封板"） |
| 4 | **失效信号是否明确？** | 什么条件出现时 = 预期死了（如"锚点数据破位/板块连续2天无涨停"） |

四个问题都能回答 → 有效预期，可进入评估。任一个答不上 → 继续观察，收集信息。

## 三、预期生命周期

### 3.1 五阶段模型

| 阶段 | 含义 | 判断标准 | 系统含义 |
|------|------|---------|---------|
| **出现期** | 新预期刚出现，板块首次异动 | 新催化出现，板块首次爆发（≥5只涨停） | 加入追踪，开始预研 |
| **确认期** | 分歧后资金重新选择，板块效应形成 | 前几天炸板/断板/回调后重新走强 | 等三维确认，准备买入 |
| **加速期** | 预期持续验证，股价加速上涨 | 龙头持续走强，梯队完整，依据仍在验证 | 持有，观察兑现/失效信号 |
| **兑现期** | 业绩/事件公布，本轮定价完成 | 利好正式公告，产业数据见顶 | 兑现信号→卖出 |
| **结束期** | 预期被完全消化 | 龙头A杀，板块联动消失，依据被推翻 | 失效信号→卖出 |

### 3.2 分歧 ≠ 结束

分歧是确认期内的自然阶段。核心判断锚点：**预期依据还在被验证 → 分歧；被否定 → 结束。**

| | 分歧（确认期内） | 结束（结束期） |
|---|---|---|
| 本质 | 筹码交换，资金在犹豫"要不要继续" | 资金已经放弃，在离场 |
| 龙头表现 | 震荡、断板但未大跌 | 大跌、A杀 |
| 板块联动 | 部分跟风回落但核心还在 | 全面溃散 |
| 操作含义 | **观察窗口**：看能否扛住分歧 | **空仓窗口**：等新预期出现 |

### 3.3 预期类型识别

**目的：帮助定义「兑现标志」和「失效标志」（买前三件事）**

| 类型 | 退出信号特征 | 案例 |
|------|------------|------|
| **持续数据型** | 月频或更高频率量化数据可追踪，数据见顶/破位即退出 | AI算力（光模块出货量）、锂电（碳酸锂期货） |
| **事件节点型** | 明确的一次性事件，事件兑现/取消即退出 | 商业航天（发射节点）、个股业绩（财报落地） |
| **实时感知型** | 无客观外部数据，依赖龙头行为/板块联动实时判断 | 纯连板炒作、情绪高潮 |

类型不决定仓位，仓位由买点类型决定（→买卖规则.md §2.1）。同一只股票在不同阶段可能属于不同类型。

## 四、感知信号解读

### 4.1 核心原则：信号 = 提醒注意，不是触发条件

系统中的数值（涨停数、封板率、换手率等）是**感知信号**。看到信号后的思考方向：**这对当前的预期意味着什么？**

- 某方向出现5只涨停 → "这个方向有资金进场" → 判断"这个预期值不值得交易"
- 不是"够不够触发条件"，而是"预期确认了吗？"
- **先行信号（T-1已有涨停）是加分项**（延续性更强），不是必要条件。无先行信号=当日催化驱动，同样有效

### 4.2 各信号解读指引

| 信号 | 不是 | 而是 |
|------|------|------|
| **涨停数/封板率/跌停数** | 涨停<30就不买，或>100就高潮 | 关注你监控方向的板块级数据——联动在增强还是减弱？ |
| **换手率** | >15%就卖 | 换手率显著偏离近期正常水平 → 预期是被确认了还是被兑现了？ |
| **成交额** | 缩量就危险 | 关注成交额变化和价格方向的背离——缩量上涨=增量不足，放量下跌=抛压加重 |
| **连板高度/晋级率** | 高度降低就是退潮 | 高度降低+晋级率下降=高低位切换，观察新低位核心能否接力 |
| **产业数据指标** | 期货跌=板块完蛋 | 与板块走势交叉验证：期货涨+板块涨=确认；期货跌+板块涨=脱离基本面，警惕 |

### 4.3 倒计时催化效应

- 判断延续性时，关键变量不是"历史规律"，而是"有没有新出现的独立催化倒计时"
- **倒计时催化**：即将到期的产业催化事件（涨价日/政策日/数据发布日）会打破历史规律，显著提升延续概率
- 盘前分析必须检查活跃方向是否存在"即将到期的独立催化事件"

### 4.4 关键原则

- **概念标签 ≠ 归因结论** — astock板块排名的概念标签是数据输入，不是分析结论。每只涨停股必须追问"它为什么涨停？实际催化是什么？"同一只股只归入一个方向（主驱动方向）
- **大叙事反向拆解** — 某方向≥20只涨停时，必须反向检查"跟风股"有没有自己的独立催化。剥离后重新统计：独立方向的涨停数可能是被低估的
- **连板股独立归因** — 连续2天+涨停的个股，必须追问其连续涨停的独立催化源，不能因为"大方向在爆发"就归入大方向
