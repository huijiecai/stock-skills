# 买卖规则

> **边界**：本文件定义买卖决策规则和执行纪律。预期定义 → 核心框架.md。

---

## 一、买入门槛

### 1.1 前提一：市场存在可验证的新预期

- 出现新的叙事、新的催化、或新的可验证点
- 旧故事没有更新、没有增量信息 = 不构成新的买入理由
- 违反 = 系统性错误

### 1.2 前提二：三维确认（定义→核心框架.md §2.3）

三维确认齐全 = 预期被市场验证，买入前提成立。**缺一 = 不买**，无例外。

### 1.3 前提三：锁定三件事

买入前必须明确回答并记录：

1. **预期是什么？** — 具体事件/数据/阶段（不能是"感觉要涨"）
2. **兑现标志是什么？** — 什么情况下故事讲完了（→核心框架.md §3.3 类型识别）
3. **失效标志是什么？** — 什么情况下故事被证伪了

**买前锁定，买后不改。** 之后所有持仓决策只对照这三件事评估。未定义 = 不执行。

---

## 二、买入执行

### 2.1 买点类型与仓位

仓位大小 = 当前时刻预期被资金认可的程度：

| 买点类型 | 出现时机 | 初始仓位 | 判断方法 |
|---------|---------|---------|---------|
| **确认买点**（最安全） | 分歧后资金重新入场，预期经过考验 | 3成 | 前几天炸板/断板/回调，今天重新走强 |
| **首板买点**（要快） | 新催化首板，资金第一次试探性确认 | 1-1.5成 | 新催化+首板爆发+之前没涨过 |
| **回调买点**（要准） | 预期已验证，上涨途中首次回调 | 加到3成 | 已涨一波+首次回调+预期依据未破 |

- 每个独立主题最多3成，是为了容纳意外，不是表达信心高低
- 都不是以上类型 → 不买，等
- 兑现期和结束期不设买点，加速期不设买点（加速期才发现=盘前覆盖不足）

### 2.2 龙头识别

主题确认后，**只买龙头**：

| 特征 | 说明 | 反例 |
|------|------|------|
| **领涨性** | 板块内率先发动，带动跟涨 | 等其他股涨了才跟上的补涨股 |
| **主动性** | 涨幅/涨速超越同类，有独立上涨动能 | 板块涨时垫底，板块内无超额 |
| **高位性** | 本轮行情中处于板块内相对高位 | 低位横盘、落后补涨的 |

- 大盘共振（大盘涨+板块涨）是更强的资金确认信号
- **龙头买不进（一字板排不到）= 不参与本次机会**，等下一次

### 2.3 执行时机

原则：资金确认在哪里发生，就在哪里买。不等、不提前、不追。

| 确认形式 | 买入时机 |
|---------|---------|
| 竞价阶段已显示强势 | 竞价/开盘即入 |
| 盘中半路放量突破/联动走强 | 突破时买入 |
| 只有涨停封板才能完成确认 | 涨停排板买入 |
| 一字板（无法以合理价格买入） | 放弃 |

### 2.4 系统确认 = 必须行动

三维齐 + 有买点窗口 + 退出条件清晰 → **必须执行**。不执行 = 与违反买入门槛同等严重的系统性错误。

### 2.5 信息不足 = 默认不操作

- 信息不足 = 三维确认的**维度数据缺失**（如无法获取板块联动数据、无法验证预期依据）
- 不是没找到完美数据——三维数据均可获取 = 信息充足，必须行动
- 不确定是否充足 → 默认不操作，记录为"信息不足"

## 三、持仓管理

### 3.1 建仓与加减仓

- **首次建仓**：50-70%目标仓位
- **加仓条件**：预期依据继续验证 + 价格创新高
- **减仓**：部分兑现减30-50%，完全兑现清仓

### 3.2 龙头切换：回归原始预期

老龙头断板、新股接力时，**不问"龙头换没换"，只问买入时的预期**：

| 买入时的预期 | 老龙头断板时怎么判断 |
|-------------|-------------------|
| 龙头加速/情绪高潮本身就是预期 | 龙头力竭 = 预期兑现 → 走 |
| 板块/产业级预期 | 龙头调整但催化未兑现 → 预期仍在，减仓或持有 |
| 确认期再次走强 | 板块整体预期还在吗？联动还在吗？在则持有 |

判断锚点：回到买前锁定的三件事。龙头是观察预期状态的窗口，不是持仓的理由。

### 3.3 卖出后新信号：重新评估

卖出后出现更强的资金确认信号 → 重新评估是否形成了新的独立预期：
- 新信号 = 新的预期内容 → 按新预期重走买入流程
- 重新定义三件事（新的兑现/失效标志）
- 原来的卖出是正确的，新的买入是独立决策

## 四、卖出规则

### 4.1 纯预期止损（不设价格止损）

- 预期依据仍在验证 → 持有，无论价格涨跌
- 非预期原因暴跌但依据未被否定 → 持有
- 依据被否定/预期兑现/进入结束期 → 按卖出规则执行

不设价格止损的原因：买入门槛（三维确认+锁定三件事）就是最重要的风控线。价格止损会在分歧期将仓位洗出去。入场越严格，预期止损越可靠。

### 4.2 兑现信号 → 走

本轮故事讲完了：
- 利好正式公告（利好出尽）
- 产业数据见顶（如碳酸锂价格开始回落且持续）
- 预期逻辑被市场充分定价（后续无增量资金）
- 所有能讲的逻辑都被讲完了

### 4.3 失效信号 → 立即走，不分批

故事被证伪了：
- 新题材崛起吸血，老题材被抽血
- 龙头断板后持续大跌（不是震荡）
- 板块联动性消失（只剩孤票）
- 预期依据被新事件推翻（政策转向/行业利空/供需逆转）
- 产业数据破位（期货跌破关键支撑）

### 4.4 卖出判断三步流程

```
第一步：当前预期处于哪个阶段？（→核心框架.md §3.1）
  → 兑现期/结束期 → 卖
第二步：是否有预期失效信号？
  → 有 → 卖
第三步：资金确认还在吗？
  → 联动消失+资金在撤 → 减仓或清仓
  → 联动还在+价格未破位 → 持有观察
```

### 4.5 常见错误

**把分歧当失效**：分歧时龙头断板、换手率升高、跟风回落——看起来像失效，实际可能是再确认前的正常筹码交换。判断方法：预期依据还在被验证 → 分歧，等再确认。预期依据被否定 → 失效，走人。（→核心框架.md §3.2）

**盘前红线脱离买入预期**：买入锚的是产业预期，但盘前临时设定的卖出红线却盯价格形态——两条逻辑不在一根链上。新增的任何卖出条件必须能回答："这个条件和买入时定义的预期是什么关系？"回答不上来 = 不能用。

**不因大盘打折仓位**：三维确认满足 = 买点成立，不因市场整体涨跌打折。

### 4.6 不机械执行

系统是框架，不是公式。三维确认是定性判断，不是打勾清单。同一个信号在不同预期背景下含义不同——回到核心问题：**这对当前的预期意味着什么？**

### 4.7 盘中感知 ≠ 追涨

盘中发现异动方向 → 用统一标准快速评估：有预期依据、有资金响应、有价格确认 → 达标则执行。这不是追涨，是对盘中新预期的正常响应。区别在于：追涨是看到涨了才想买；盘中感知是看到资金确认后按规则执行。

## 五、组合规则

### 5.1 同主题不叠仓

同一个预期主题，无论触发多少观察角度，都只算一个机会，最多3成。

### 5.2 多主题并发

不同主题是独立机会，各自最多3成，总仓位自然叠加。已有仓位时出现新机会 → 评估现有持仓预期状态，按卖出规则减仓腾出资金。

### 5.3 产业链相关性约束

不同主题但同属一个大产业链（如AI硬件链下的MLCC/PCB/光通信），合并计入"链条总仓位"。**链条总仓位>6成时，不再加仓链条内任何标的。**

| 判定 | 处理 |
|------|------|
| 主题分属不同产业链（锂电+创新药） | 各自独立，各最多3成 |
| 主题同属一个产业链（MLCC+PCB+光通信） | 合并计链条仓位，>6成不加仓 |
| 链条内出现完全独立的催化主线 | 可破例加仓1成，须写明独立催化源理由 |

### 5.4 单主题只做龙头

同一主题内只买一只股票。龙头买不进 = 不参与本次机会。

## 六、执行纪律

### 6.1 系统说买就买，说卖就卖

不给自己加额外门槛或条件。三维确认齐全 = 买点成立，不编"再等等"。

### 6.2 不在确认买点上犹豫

犹豫 = 给自己加条件 = 脱离系统 = 变成随意交易。

### 6.3 复盘标准：合规 ≠ 赚钱

- 赚钱但不符合系统 = 错误
- 亏钱但符合系统 = 正确
- 核心指标：系统执行合规率

### 6.4 系统迭代流程（仅盘后）

- **触发**：盘后复盘发现规则漏洞/歧义/过时
- **步骤**：定位根因 → 修改对应系统文件 → 验证无连带影响 → 记录到data/lessons.md
- **禁止盘中改系统**
