# 预期研究操作手册

> **定位**：research/expectations/ 文件的**唯一写入者**，双模式运行。
> **核心原则**：盘前分析/真实看盘/模拟看盘只能读取和触发，不能直接修改 research 文件。
> 系统知识引用：核心框架.md（判断）、数据验证.md（数据）
> 外部工具：WebSearch（消息面）、xueqiu.com（本土催化）、astock（行情数据）

---

## 一、写权限规则

```
盘前分析/真实看盘/模拟看盘  ──检测到信号──>  触发预期研究  ──分析+更新──>  research/expectations/*.md
```

- **预期研究**是 research/expectations/ 的唯一写入者
- 其他操作文件发现需要更新 research 时，写 `→ operations/预期研究.md 模式B`
- 原因：确保每次更新都经过完整评估流程，防止 AI 随意修改预期逻辑链

## 二、Mode A：预期研究

回答一个问题：**这个方向凭什么走出这种行情？**

**触发**：任何方向的行情表现引起关注时执行，包括但不限于：
1. 板块涨幅排名前列
2. 板块内多只涨停
3. 板块内多只涨幅≥5%
4. 市场弱但某方向逆势走强
5. 单只个股巨量异动
6. 龙头股连板（连续涨停）
7. 板块成交额突然放大
8. 政策/事件催化后相关板块反应
9. 用户主动要求研究

以上是常见信号，不是完整清单。核心判断：这个方向是不是比别的方向更值得关注？是 → 做。

触发后执行 A.1-A.3。

### A.1 归因：为什么涨？

- astock 返回的是原始板块/概念分类（如"POE胶膜""复合铜箔""医药外包"），需归因到真实的预期方向
- 用 WebSearch 搜索当前催化：东方财富/同花顺/财联社等财经媒体的板块异动解读
- 用 xueqiu.com 搜索相关话题讨论、产业逻辑
- 用淘股吧（taoguba.com.cn）搜索短线资金对该方向的看法和情绪
- 回答：**这个方向的预期是什么？核心催化是什么？**

#### 统一归因法：从点看到面

所有新异动只写四行：

```text
具体事件：正在交易的公告、数据、政策或事件节点是什么？
最短传导链：事件 → 哪个产品/订单/价格 → 哪一层公司先受益？
联动验证：按这条链预先列出的直接受益池是否同步走强？
结论：公司级、子行业级、终端需求级，或归因未决。
```

搜索顺序固定为“公司公告/年报 → 行业数据/政策 → 财经媒体/专业讨论”，搜索只用于验证链条，不用于事后给上涨股票找理由。同一事件可以保留多个归因假设，但每个假设都必须先建立完整受益池，再用行情验证。池内标的只分为直接受益、销量受益、相邻题材、成本受压四类；无法说明传导关系的标的不进入可执行池。

涨价类事件必须确认：涨的是哪个产品、谁直接卖、谁因销量增加受益、谁只是相邻题材、谁可能承担成本；不能把一种原料的涨价直接外推到另一种原料或下游公司。

单只个股巨量异动时，按以下顺序执行：

```
搜索该股为什么上涨
→ 从公告、新闻、财经媒体、雪球等信息中找到市场正在交易的具体预期
→ 根据预期列出关联股票
→ 查询关联股票当时表现
→ 按最短传导链建立的核心关联股成片同步上涨：归因成立
→ 只有该股上涨：继续搜索；仍无合理解释则归因不成立、不交易
```

❗ **催化源搜索要求**：必须用WebSearch搜索今天爆发的**具体催化源**（业绩公告？涨价数据？政策事件？），不可停留在方向标签，不可假设催化与之前相同而不搜索。

**归因穿透要求**：禁止用方向标签代替催化分析。"PCB涨停"是标签，"覆铜板涨价周期+中报业绩兑现"才是催化。"半导体大涨"是标签，"DRAM Q2涨58-63%+华天预增231-275%"才是催化。

### A.2 验证：直接受益标的与资金确认

**第一步：识别直接受益标的**

基于A.1的最短传导链，列出可执行受益池：
- 该标的主营业务是否处在已验证的传导链上？
- 直接销售催化产品，或因下游需求增加而产生可验证的销量/订单增长，都可进入；相邻题材和成本受压者不能进入
- 不是“属于这个板块”，而是“这个催化发生 → 该标的价格、销量、订单或毛利沿明确链条改善”
- 仿制药企不是创新药BD出海的直接受益者；CXO才是
- 这份名单就是§2.2的“直接受益名单”，不在名单内的股票不会被买入

**第二步：在直接受益标的中，验证资金确认**

- 用 astock 拉取直接受益标的的行情（→ operations/数据验证.md）
- 核心受益个股是否有表现（涨停/放量/突破）？
- 多只同步走强（资金广度）？龙头走出来（价格深度）？
- **列出所有直接受益标的**，逐只标注：与催化的关系/涨幅/成交额/是否涨停/连板数
  → 在直接受益标的中，满足领涨性/主动性/高位性的标注为龙头候选
  → 多只满足=多只龙头候选，全部列入预期文件§二核心标的表
- 回答：**资金在用真金白银确认这个预期吗？**
- “多只同步走强”指核心关联股成片上涨，不要求每一只股票100%上涨，也不设置固定股票数量门槛。

### A.3 结论与产出

综合 A.1 和 A.2，回答：

1. **预期是什么** — 具体的催化/叙事
2. **兑现标志** — 什么情况下故事讲完了（利好落地/数据见顶）
3. **失效标志** — 什么情况下故事被证伪了（催化取消/龙头A杀/联动消失）

**预期成立** → 在 `data/research/expectations/<方向>.md` 创建预期文件：

```markdown
# <方向名>

> 状态：观察 | 阶段：出现期 | 首次识别：YYYY-MM-DD

## 一、预期概要
| 项目 | 内容 |
| 预期类型 | 持续数据型/事件节点型/实时感知型 |
| 核心逻辑 | 一句话 |
| 催化锚点 | 可验证的数据/事件 |
| 买入前三件事 | 预期/兑现标志/失效标志 |

## 二、直接受益标的
| 标的 | 代码 | 与预期的关系 | 龙头候选 |

## 三、每日跟踪日志
| 日期 | 催化进展 | 资金面 | 价格确认 | 阶段变化 | 备注 |
|------|---------|--------|---------|---------|------|
```

**预期不成立** → 无输出，记录原因后返回。

深度行业分析（→ `data/research/产业链分析/`）和公司分析（→ `data/research/companies/`）按需展开，不是每次 Mode A 的必选产出。

**数据来源**：WebSearch（消息面）、xueqiu.com（本土催化）、astock（行情数据 → operations/数据验证.md）

## 三、模式B：已有预期更新

**触发**：
- **每日例行**：收盘更新时，state.md §四预期追踪表中的全部方向（含持仓与观察）都必须更新一次（→ 真实看盘.md §8.0）
- **事件触发**：盘前分析/真实看盘/模拟看盘检测到活跃方向有异动（催化更新/板块异动/阶段变化）

**关键**：不是简单追加一行，而是先走完整评估流程（B.1-B.5）再更新。所有方向统一流程，不做轻量/完整分级。

### B.1 加载预期文件

读取 `data/research/expectations/<方向>.md`，回顾完整逻辑链。

### B.2 拉取最新数据

- astock query 标的最新行情（→ operations/数据验证.md）
- WebSearch 搜索最新催化进展

### B.3 完整评估

对当前状态做四维评估：

1. **催化进展**：核心催化是否有新数据/事件？
2. **资金面**：板块联动、涨停数、资金流向是否有变化？
3. **价格确认**：标的是否创新高/跌破关键位？
4. **阶段判断**：当前处于五阶段的哪个阶段？是否有阶段变化？

### B.4 更新跟踪日志

在预期文件 §三"每日跟踪日志"追加一行：

```
| 日期 | 催化进展 | 资金面 | 价格确认 | 阶段变化 | 备注 |
```

### B.5 同步 state.md §四

更新 state.md §四 对应行的阶段、当前价、今日变化。
