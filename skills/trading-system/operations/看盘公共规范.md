## 二、深析与决策落盘

### 买入方向

```
□ 思考：板块为什么强？
  对照盘前分析，预期确定了吗？还是新方向？
  → 新方向且不在§四：先触发预期研究Mode A（→ 预期研究.md §二）
□ 看板块领涨股（机械取数）
  → 领涨个股是哪些？
□ 思考：领涨的是预期内核心个股吗？
  是 → 继续
  不是 → 第一天？主升期？重新分析预期？
□ 看资金广度（机械取数）
  → 多只同步走强？
□ 看价格深度（机械取数）
  → 放量突破？
□ 买入评估（→ 买卖规则.md §一§二）
  读取买卖规则.md，逐项检查：§1.0预期已入库→§1.1可验证预期→§1.2三维确认→§1.3锁定三件事→§2.1买点类型→§2.2龙头识别→§2.3执行时机
  全部通过 → 写思考链路 → 执行
  任一不通过 → 记录原因 → 返回快扫
```

### 卖出方向

```
□ 看持仓当前状态（机械取数）
□ 看持仓所在板块表现（机械取数）
  → 板块还在走强吗？
□ 看预期相关个股表现（机械取数）
  → 同方向其他标的走势如何？
□ 卖出评估（→ 买卖规则.md §四）
  读取买卖规则.md，走§4.1三步流程：
  第一步：预期处于哪个阶段？（→ 核心框架.md §3.1）
  第二步：是否有失效信号？（→ §4.3）
  第三步：资金确认还在吗？（联动消失+资金在撤→减仓/清仓）
  → 卖 → 写思考链路 → 执行
  → 不卖 → 返回快扫
```

### 思考链路格式

执行前必须先写 `HHMM_<动作>_<标的>_思考链路.md`：

```
- 触发时刻 HH:MM
- 买入/卖出评估结果（买卖规则逐项检查结论）
- 备选方案：考虑过哪些标的，为什么放弃
- 仓位与价位：买卖数量、价格
```

未写思考链路 → 不允许动账户。

### 执行链

**买点触发**：
① 写思考链路.md → ② 检查买卖规则.md全部条件 → ③ 执行交易+更新trades.md → ④ 运行audit_account.py → ⑤ 用脚本输出更新state.md §二 → ⑥ 巡盘日志追加 → ⑦ 通知用户

**卖点触发**：
① 写思考链路.md（含卖出原因）→ ② 执行交易+更新trades.md → ③ 运行audit_account.py → ④ 用脚本输出更新state.md §二 → ⑤ 巡盘日志追加 → ⑥ 通知用户

**禁止操作**（买卖规则未通过=不执行，无需用户介入）：
- 买卖规则§1.0-§1.3任一不满足 → 不买
- 买卖规则§4.1判定不卖 → 不卖

## 四-B、账户精算规则（硬性）

> **背景**：AI手动计算现金/总资产屡次出错（遗漏历史交易利润、历史偏差混入当日盈亏等）。自2026-07-13起，账户数据必须由脚本精算，禁止手动计算。

### 执行链

```
交易执行 → ①更新trades.md追加交易行 → ②运行audit_account.py → ③用脚本输出填state.md §二
```

### 硬性规则

1. **trades.md先于state.md**：每笔交易执行后，必须先在trades.md追加交易行，再运行脚本
2. **脚本唯一真相源**：state.md §二的现金、总资产、已实现盈亏必须从`python3 scripts/audit_account.py`输出复制，禁止手动计算
3. **当日盈亏计算**：当日盈亏 = 当日收盘总资产 - 上一交易日收盘总资产（两者必须使用相同的偏差修正基准）
4. **偏差修正不混入当日盈亏**：历史遗留偏差（如¥3,729）是存量调整，不是当日损益。当日盈亏只反映持仓市值变化+当日交易盈亏
5. **新增收盘价**：脚本默认使用state.md中记录的收盘价。如需计算其他日期，用`--close 代码=价格`参数指定

### 脚本用法

```bash
# 标准用法（计算到最新交易，用默认收盘价）
python3 scripts/audit_account.py

# 指定收盘价（如有多个持仓）
python3 scripts/audit_account.py --close 002185=24.13,000938=35.44
```

### state.md §二填写模板

```
- 现金：¥<脚本输出"修正后现金">
- 持仓市值：¥<脚本输出"持仓市值">（<名称><数量>股@<收盘价>·收盘价）
- 总资产：¥<脚本输出"总资产">（累计+¥<盈利>，+<百分比>%）·当日盈亏±¥<差额>（±<百分比>%）
- 持仓浮盈：¥<脚本输出"浮盈">（<名称>：均价X.XX→X.XX·±X%）
- 已实现盈亏：+¥<脚本输出"已实现盈亏">（→ trades.md 已平仓汇总）
- 初始资金：¥100,000（2026-03-26起）
- 冷静期：否 / 是（当日累计亏损>5%，禁止开新仓）
```

## 七、收盘逐股扫描

收盘后对全市场逐股扫描，是预期来源的自下而上兜底：概念板块排名可能遗漏分散在多个概念标签中的强势方向，只有逐只归因才能发现方向的真实强度。

- **涨停全部过一遍**：`astock query limit <YYYYMMDD> --exclude-st` → 逐只归因→属于哪个方向→是否新方向
- **炸板全部过一遍**：盘中快扫已记录的炸板事件汇总 → 为什么炸？方向还有效吗？
  （astock当前不支持盘后查询炸板，依赖日内快扫/深析实时记录的炸板数据）
- **成交额前50全部过一遍**：`astock query stock --sort-by amount --limit 50` → 异动检测→是否隐含新预期
- **产出**：新方向入库state.md §四 / 已有方向更新阶段
