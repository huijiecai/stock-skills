## 二、深析与决策落盘

### 信号处理优先级

当多个信号同时出现时，按以下顺序处理：

```
① 持仓紧急信号（持仓跌停/急跌>5%）→ 立即处理
② 异动候选归因/买入方向深析（含Mode A）→ 完整执行，不可中断
③ 持仓常规巡检（涨幅>2%的§4.1评估）→ 在②完成后处理
④ 其他方向快扫信号 → 继续快扫循环
```

Mode A属于②：一旦异动候选完成方向归因，或某方向行情表现引起关注，必须完整执行Mode A后才能处理③④。
持仓常规巡检（非紧急）排在Mode A之后——持仓等几分钟不会出大事，但错过买点窗口不可逆。

### 买入方向

```
□ 信号入口判定
  ├── 无方向异动候选 → 只标记“先导候选”，禁止称龙头、禁止直接买入
  │   → 搜索公司公告、行业新闻、财经媒体、雪球等信息
  │   → 找出市场正在交易的具体预期，不能只写方向标签
  │   → 根据预期列出关联股票，并查询它们当时的表现
  │   → 核心关联股成片同步上涨：归因正确，进入Mode A后续流程
  │   → 只有候选上涨：继续搜索；仍无合理解释则判定孤立异动，不交易
  └── 已知板块走强 → 验证实际催化，并建立/读取直接受益标的池
□ 这个方向凭什么走出这种行情？
  判断：该方向在§四活跃预期中吗？
  ├── 在§四 → 跳过Mode A，直接进入□在已验证的关联股票中确认方向龙头
  └── 不在§四（已淘汰/从未入库）→ 执行Mode A（→ 预期研究.md §二）
      Mode A产出决定后续路径：
      · 预期不成立 → 记录原因 → 返回快扫（不进入下方步骤）
      · 预期成立 → 创建预期文件 → 进入□在已验证的关联股票中确认方向龙头
      注意：没有"盘后评估"这个选项。Mode A在此处完成，不延后。
□ 在已验证的关联股票中确认方向龙头
  → 领涨性：谁最早突破/最早到+5%/最早涨停？
  → 主动性：谁的涨速和成交额显著领先同类？
  → 最先发动、涨幅最强、成交最主动 → 方向龙头
  → 其他同步走强 → 跟随/次核心
□ 看资金广度（机械取数）
  → 多只同步走强？
□ 看价格深度（机械取数）
  → 放量突破？
□ 可交易性检查（只能放在识别之后）
  → 龙头是否属于允许板块？一手金额/仓位是否可执行？
  → 龙头不可执行：保留其龙头身份，依次评估直接受益池第二、第三名
  → 不得因为龙头不可买而跳过方向分析，或改买非直接受益股票
□ 买入评估（→ 买卖规则.md §一§二）
  读取买卖规则.md，逐项检查：§1.0预期已入库→§1.1可验证预期→§1.2三维确认→§1.3锁定三件事→§2.1买点类型→§2.2标的选择→§2.3执行时机→§2.4账户级排序
  §1.2三维确认：若Mode A已执行，直接引用A.2结论，不得重新降级。方向在§四（跳过Mode A）时，用深析机械取数判断。
  单个机会全部通过 → 写明风险因子和交易后仓位 → 执行
  多个机会同时通过 → 比较预期新鲜度/确认质量/龙头质量/买点质量/共同风险因子 → 最多执行排序前2名
  排序落后或共同风险因子已达6成 → 记录合规放弃理由，不执行
  任一不通过 → 记录原因 → 返回快扫
```

### 卖出方向

```
□ 看持仓当前状态（机械取数）
□ 看持仓所在板块表现（机械取数）
  → 板块还在走强吗？
□ 看预期相关个股表现（机械取数）
  → 同方向其他标的走势如何？
□ 卖出评估（→ 买卖规则.md §四）
  读取买卖规则.md，走§4.1双出口流程：
  出口A：预期是否兑现/结束/被否定？→ 是则清仓
  出口B：无论出口A是否触发，都检查买入时的资金确认是否仍在
  → ≥2个交易失效信号+资金撤退确认：首日减仓30-50%（按买卖规则§3.1整手约束执行），次日未恢复或三维整体消失则清仓
  → 交易退出但预期未结束：预期文件保留并降级观察
  → 卖 → 写思考链路 → 执行
  → 不卖 → 返回快扫
```

### 思考链路格式

执行前必须先写 `HHMM_<动作>_<标的>_思考链路.md`：

```
- 触发时刻 HH:MM
- 买入/卖出评估结果（买卖规则逐项检查结论）
- 龙头候选清单：预期文件§二直接受益标的名单内，满足领涨性/主动性/高位性的标的，逐只标注数据（涨幅/成交额/涨停与否）和可买入性
- 买入时记录账户级排序、共同风险因子、交易前后该因子仓位；卖出时分别记录出口A和出口B结论
- 若由无方向异动触发：记录搜索到的具体预期、信息来源、关联股票当时表现，以及归因成立/不成立和龙头结论
- 仓位与价位：买卖数量、价格
```

未写思考链路 → 不允许动账户。

### 执行链

**买点触发**：
① 写思考链路.md → ② 检查买卖规则.md全部条件 → ③ 执行交易+更新trades.md → ④ 运行audit_account.py → ⑤ 用脚本输出更新state.md §二 → ⑥ 巡盘日志追加 → ⑦ 通知用户

**卖点触发**：
① 写思考链路.md（含卖出原因）→ ② 执行交易+更新trades.md → ③ 运行audit_account.py → ④ 用脚本输出更新state.md §二 → ⑤ 巡盘日志追加 → ⑥ 通知用户

**禁止操作**（买卖规则未通过=不执行，无需用户介入）：
- 买卖规则§1.0-§1.3任一不满足 → 不买
- 买卖规则§4.1判定不卖 → 不卖

## 四-B、账户精算规则（硬性）

> **背景**：AI手动计算现金/总资产屡次出错（遗漏历史交易利润、历史偏差混入当日盈亏等）。自2026-07-13起，账户数据必须由脚本精算，禁止手动计算。

### 执行链

```
交易执行 → ①更新trades.md追加交易行 → ②运行audit_account.py → ③用脚本输出填state.md §二
```

### 硬性规则

1. **trades.md先于state.md**：每笔交易执行后，必须先在trades.md追加交易行，再运行脚本
2. **脚本唯一真相源**：state.md §二的现金、总资产、已实现盈亏必须从`python3 scripts/audit_account.py`输出复制，禁止手动计算
3. **当日盈亏计算**：当日盈亏 = 当日收盘总资产 - 上一交易日收盘总资产（两者必须使用相同的偏差修正基准）
4. **偏差修正不混入当日盈亏**：历史遗留偏差（如¥3,729）是存量调整，不是当日损益。当日盈亏只反映持仓市值变化+当日交易盈亏
5. **新增收盘价**：脚本默认使用state.md中记录的收盘价。如需计算其他日期，用`--close 代码=价格`参数指定

### 脚本用法

```bash
# 标准用法（计算到最新交易，用默认收盘价）
python3 scripts/audit_account.py

# 指定收盘价（如有多个持仓）
python3 scripts/audit_account.py --close 002185=24.13,000938=35.44
```

### state.md §二填写模板

```
- 现金：¥<脚本输出"修正后现金">
- 持仓市值：¥<脚本输出"持仓市值">（<名称><数量>股@<收盘价>·收盘价）
- 总资产：¥<脚本输出"总资产">（累计+¥<盈利>，+<百分比>%）·当日盈亏±¥<差额>（±<百分比>%）
- 持仓浮盈：¥<脚本输出"浮盈">（<名称>：均价X.XX→X.XX·±X%）
- 已实现盈亏：+¥<脚本输出"已实现盈亏">（→ trades.md 已平仓汇总）
- 初始资金：¥100,000（2026-03-26起）
- 冷静期：否 / 是（当日累计亏损>5%，禁止开新仓）
```

## 七、收盘逐股扫描

收盘后对全市场逐股扫描，是预期来源的自下而上兜底：概念板块排名可能遗漏分散在多个概念标签中的强势方向，只有逐只归因才能发现方向的真实强度。

- **涨停全部过一遍**：`astock query limit <YYYYMMDD> --exclude-st` → 逐只归因→属于哪个方向→是否新方向
- **炸板全部过一遍**：盘中快扫已记录的炸板事件汇总 → 为什么炸？方向还有效吗？
  （astock当前不支持盘后查询炸板，依赖日内快扫/深析实时记录的炸板数据）
- **成交额前50全部过一遍**：`astock query stock --sort-by amount --limit 50` → 异动检测→是否隐含新预期
- **产出**：新方向入库state.md §四 / 已有方向更新阶段
