# 盘前分析操作手册

> **定位**：每日盘前的完整工作流，从信息收集到输出预案。
> 系统知识引用：核心框架.md（判断）、买卖规则.md（评估）、数据验证.md（数据）
> 外部工具：WebSearch（消息面）、xueqiu.com（本土催化）、astock（行情数据）

---

## 一、启动序列（开始盘前分析前必做）

```
□ 读取 data/state.md → 加载持仓+现金+预期追踪+运行状态
□ 读取 data/state.md §四 → 了解当前活跃预期（方向/阶段/锚点/失效信号）
□ 读取 data/research/expectations/ 下活跃预期文件 → 加载每个方向的完整逻辑链
□ 读取 system/核心框架.md → 加载判断框架
□ 读取 system/买卖规则.md → 加载买卖门槛
□ 获取昨日市场数据（三大指数/涨跌停/成交额/涨停分布）→ operations/数据验证.md
```

## 二、催化扫描（9:00前）

### 2.1 核心原则：催化 → 方向（不是方向 → 催化）

先无预设扫描催化源，再映射到方向。不带方向预设地搜，避免只看到已知方向。

- 过去48小时有哪些新研报、产业数据、政策文件、重大公告？
- 雪球（xueqiu.com）热门话题和活跃方向讨论

### 2.2 八维覆盖（强制，不可省略任何维度）

| # | 扫描维度 | 搜索方法 |
|---|---------|---------|
| 1 | **美股/外围市场** | 三大指数收盘+重点个股(特斯拉/英伟达等)+商品期货(+4%以上品种) |
| 2 | **A股晚间重要公告** | 搜索"X月X日晚间重要公告"获取全量公告 |
| 3 | **个股业绩公告** | 一季报/年报超预期+不及预期，特别关注持仓股和龙头股 |
| 4 | **活跃产业链纵深搜索** | 对state.md中活跃方向逐一做上/中/下游拆分搜索 |
| 5 | **行业事件/峰会/政策** | 近期行业峰会、产业政策、技术突破、海外基建 |
| 6 | **监管动态** | 立案/处罚/退市警示 |
| 7 | **公司行为** | 减持/增持/回购/定增/股权激励 |
| 8 | **盯盘股专项** | 持仓股+关注股逐一搜索最新公告和业绩 |

**消息来源优先级**：路透/彭博 > 财联社/华尔街见闻 > 雪球 > 新浪/东财 > WebSearch全量搜索

每条催化必须标注来源。即使某维度无重要消息也要标注"无"。

### 2.3 产业链纵深搜索方法（维度4展开）

对state.md中每个活跃方向，不能只搜一个泛关键词，必须拆成上游/中游/下游各自搜索：

- 每个方向至少3个独立query
- 同时搜索雪球同名话题（xueqiu.com/k?q=[关键词]）获取本土催化

示例：
- 半导体 → 搜"半导体封装材料 涨价" + "电子特气 供应" + "中芯国际 产能"
- 锂电 → 搜"碳酸锂 期货" + "锂矿 减产" + "电池 排产"
- 电网 → 搜"电网 投资 万亿" + "特高压 中标" + "海外电网 建设"

### 2.4 催化→方向映射（强制产出表格）

**禁止只罗列催化不映射**。每个催化必须映射到方向，产出以下表格：

| 催化 | 指向方向 | 是活跃预期? | 催化强度 | 明日影响 |
|------|---------|-----------|---------|----------|
| <具体催化> | <方向/子方向/市场整体> | ✅活跃/❌未覆盖/❌已清仓 | ⭐⭐⭐政策级/⭐⭐直接/⭐间接/⭐不相关 | <对明天交易的具体影响> |

- 产业催化 > 政策催化 > 个股催化 > 情绪催化
- 注意子方向级拆分（如"储能"拆为"锂矿/电网/电池/光伏"分别评估）
- 催化强度必须分级，不能全部标"重要"
- "明日影响"列禁止填"重点监控"等模糊表述·必须具体到操作

### 2.5 催化→活跃预期交叉（强制产出表格）

**禁止跳过此步**。每个活跃预期必须逐一检查本轮是否有新增催化：

| 活跃预期 | 本轮新增催化 | 预期变化 | Mode B执行 |
|---------|-------------|---------|----------|
| <方向> | <无/具体催化> | <预期依据加强/减弱/不变/资金确认变化> | ✅已更新/❌待更新 |

**新方向Mode A触发判断**（同样强制产出表格）：

| 候选新方向 | 触发条件检查 | 结论 |
|-----------|-------------|------|
| <方向> | <催化+资金广度检查> | ✅触发Mode A/❌不触发/⚠️边界状态（明日益中验证） |

催化扫描结果与活跃预期交叉：
- 有催化更新的方向 → 立即执行 `operations/预期研究.md` 模式B
- 发现强势方向且不在 state.md §四中 → 立即执行 `operations/预期研究.md` 模式A（触发条件见该文件§二）

### 2.6 消化昨日盘后逐股扫描结果（强制产出表格）

真实看盘.md §5.3产出：昨日涨停/炸板/成交额前50的逐只归因结果

| 方向 | 涨停数 | 是否活跃预期 | 明日关注 |
|------|--------|-------------|----------|
| <方向> | <数量> | ✅活跃/❌新方向/❌非受益 | <具体关注点> |

- 哪些涨停股归入了已有方向？→ 确认方向资金面
- 哪些归入了新方向？→ 进入§三评估
- 哪些炸板股方向仍有效？→ 更新预期阶段

### 2.7 更新全部预期（必做·进入§三前必须完成）

基于§2.1-2.6的扫描结果，对 state.md §四中全部方向逐一执行预期研究模式B（B.1-B.5）：

- **更新**：已有方向追加当日跟踪日志（催化进展/资金面/价格确认/阶段变化）
- **新增**：§2.5中触发的Mode A方向，创建预期文件+录入state.md §四
- **删除**：失效信号全部满足的方向 → 直接删除预期文件，从 state.md §四移除

完成后 state.md §四和全部 expectations 文件已是最新状态，§三基于此评估。

### 2.8 明日场景推演（强制产出·为交易做准备）

**这是盘前分析的核心产出**——基于催化推演明天可能发生的场景，每个场景配套具体操作策略：

```
场景A：<描述>（概率X%）
- 市场表现：<预期走势>
- 操作：<具体动作>

场景B：<描述>（概率X%）
- ...
```

- 至少推演3个场景（最可能/次要/小概率）
- 每个场景必须配套操作策略·不能只描述不策略
- 概率之和不需要等于100%·但主要场景必须覆盖

## 三、方向评估（含三维确认检查）

对§二产出的每个候选方向，逐一执行以下步骤：

### 3.1 预研过滤

- **主板限制**：只做 000/001/002/003/600/601/603/605 开头的标的
- **研究基础**：必须对方向做过研究（正宗度+产业链位置+市值），未研究过的方向先标注"待研究"

### 3.2 方向有效性筛选

对每个方向回答四个问题（分别对应核心框架.md §2.2依据四类、§3.1五阶段、§2.3确认含义、买卖规则.md §1.3锁定三件事）：

1. 有具体锚点？（产业数据/政策文件/业绩趋势/事件节点）
2. 锚点可追踪？（有客观数据可持续验证）
3. 确认信号清晰？（什么市场行为=可以买）
4. 失效信号明确？（什么条件=预期死了）

四个都答不上 → 放入观察列表，不进预案。

### 3.3 标注预期阶段

→ 核心框架.md §3.1（五阶段模型）

判断每个方向当前处于出现期/确认期/加速期/兑现期/结束期。

### 3.4 三维确认检查

| 维度 | 检查方法 |
|------|---------|
| **资金确认** | 联动（板块内多股联动，非孤票）+ 量价（成交量相对日常偏离）+ 概念去噪三步法（归因→聚合→龙头验证）|
| **价格确认** | 突破关键位/涨停板封住/半路放量突破/回踩关键位企稳 |
| **预期依据** | 判断属于哪类（→核心框架.md §2.2），对应数据是否在验证逻辑 |

三维缺一 = 标注"待确认"，不进买入预案。

### 3.5 预设确认信号和失效条件

对每个方向预设：
- **改主意条件**：什么信号出现时，放弃/改变对该方向的判断？
- **预期失效条件**：出现X情况 → 立刻离场（基于预期逻辑，非价格止损线）

### 3.6 预设盘中新方向关注条件

什么情况下关注一个盘前未覆盖的新方向？
- 示例：创新药板块3只以上涨停 + 有权重股异动

## 四、交易预案

### 4.1 if-then预案

对每个通过§三评估的方向，制定具体预案：

```
if [预期确认信号出现] → 买 [标的]，[仓位]（→买卖规则.md §2.1）
if [预期失效信号出现] → 卖 [标的]，清仓
```

### 4.2 周五持仓评估（仅限高位持仓）

如果持仓处于高位（如连续板），评估周末可能出现的消息对预期的影响：
- 风险可控 → 继续持有
- 风险较大 → 减仓至舒适水平
- 周五对新方向买入无额外限制，三维确认齐全=执行
