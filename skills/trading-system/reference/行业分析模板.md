# [产业链名称]产业链分析（交易决策导向）

> 版本：v2.0 | 更新：2026-06-20 | 基于：预期驱动交易法则 v3.10
> 用途：tracker 中某个预期方向的产业链纵深展开，回答"这条链值不值得关注？正宗标的是谁？"
> 核心原则：不是行业白皮书，是交易决策依据。每个章节都要能回答"这和买卖有什么关系"。

---

## 三层关联

```
tracker.md（发现预期）
  └── 本文档（理解产业链：哪些环节受益？正宗标的是谁？）
       └── knowledge/companies/（落实到标的：能不能买？买点是什么？）
```

| 层级 | 文件 | 回答的问题 |
|------|------|----------|
| 预期层 | `expectations/tracker.md` 中的【条目名】 | 预期是什么？阶段？4问框架 |
| 产业链层 | 本文档 | 这条链怎么赚钱？正宗标的是谁？确认/失效信号？ |
| 标的层 | `knowledge/companies/xxx.md` | 这家公司能不能买？买多少？什么时候卖？ |

> ⚠️ 本文档是 tracker 预期的深度补充。tracker 发现预期 → 本文档展开产业链 → 公司分析落实到标的。

## 三、A股标的全景

> 回答：买谁？正宗标的是谁？龙头怎么识别？

### ⚠️ 标的来源方法论（强制）

> **禁止直接拿板块成分股当产业链全景。** 板块成分股是"概念标签"分类，不是"产业链"分类。MLCC概念板块26只成分股中12只不在MLCC链上（分销商/不同技术路线/关联弱）。
>
> 构建步骤：
> 1. **WebSearch 查产业链结构** — 上游材料/中游制造/设备/下游应用，各环节的核心公司
> 2. **astock 查概念板块成分股做交叉** — `astock query block members <板块代码> --json`
> 3. **逐个验证主营业务是否在链上** — `astock query info <code>` 查主营，排除蹭概念
> 4. **排除非本链标的** — 列入排除表，说明排除理由

### 筛选规则

- ✅ 主板可买：000xxx / 002xxx / 600xxx / 601xxx / 603xxx / 605xxx
- ❌ 不可买：创业板(300/301) / 科创板(688) / 北交所(920)
- 排序逻辑：正宗度（概念交叉数×产业链位置）× 主动走强（封板时间×成交额）

## 使用规范

1. **每个预期方向至少有一份产业链分析**——tracker 活跃预期必须有对应文档
2. **文档随交易迭代**——盘后复盘时该方向发生重大变化，回写更新本文档
3. **标的来源必须从产业链逻辑出发**——禁止直接拿板块成分股当全景（板块成分股仅作交叉验证）
4. **必须列出非本链排除表**——每个排除标的说明排除理由
5. **必须填写汇总统计表**——一眼看出这个方向有几个能买的
6. **标的全景必须标注板块**（✅主板/❌创业板/科创板）——不可买的明确排除
7. **龙头识别必须引用具体数据**——封板时间/成交额/涨幅，不能写"感觉是龙头"
8. **确认/失效信号必须和 tracker 一致**——两个文档不能矛盾
9. **公司分析链接必须有效**——标的全景表中引用的 knowledge/companies/ 文件必须存在
