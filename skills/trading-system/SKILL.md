# 预期驱动交易系统

> 这是一个**预期驱动**的交易系统。所有操作围绕预期展开，目标是账户盈利。
> 系统规则文件：`system/trading-system.md`（v3.10）
> 模板文件：`system/templates.md`（v3.10）

---

## 一、系统核心逻辑

### 1.1 什么是预期

预期 = 市场资金正在投票的产业方向/事件催化。预期不问出处，确认只看资金。

### 1.2 怎么赚钱

1. **提前识别预期**（tracker前置预研，不等消息出来才反应）
2. **等资金确认**（三维确认：资金+预期依据+价格，三个维度都齐全=确定性足够）
3. **确认后买入**（确定性换利润，三维齐全=必须行动）
4. **预期兑现或失效时卖出**（不贪、不扛）

核心目标：**账户盈利**。确定性高=买，确定性没了=卖。

### 1.3 预期生命周期（5阶段）

| 阶段 | 含义 | 操作指引 |
|------|------|---------|
| **出现期** | 新催化出现，少量资金试探 | 记入tracker，开始预研标的 |
| **确认期** | 资金开始确认（涨停数增加+龙头封板） | 可参与买入（首板/确认买点） |
| **加速期** | 大量跟风资金涌入，板块涨停爆发 | 持有为主。加速期才发现=覆盖不足，不追入 |
| **兑现期** | 预期开始兑现（利好落地/数据验证） | 准备卖出，不贪最后一段 |
| **结束期** | 预期失效（资金撤离/催化被证伪） | 清仓走人，不留幻想 |

### 1.4 统一判断框架（4个问题）

判断一个方向是否构成有效预期，必须回答：

1. **是否有具体锚点？** — 产业数据/政策文件/业绩趋势/事件节点，不能是"感觉要涨"
2. **锚点是否可追踪？** — 有没有客观数据持续验证（期货价格/行业出货量/政策节点）
3. **确认信号是否清晰？** — 什么市场行为出现时=可以买（如"板块≥3涨停+龙头封板"）
4. **失效信号是否明确？** — 什么条件出现时=预期死了（如"锚点数据破位/板块连续2天无涨停"）

四个都能回答→加入活跃预期。任一答不上→放观察列表，继续收集。

### 1.5 核心决策树

```
发现预期 → 三维确认评估
  ├─ 齐全 + 有买入窗口 + 退出信号清晰 → 买入（必须行动）
  ├─ 不齐 → 记录，下一天再评估
  └─ 齐全但无买入窗口 → 记录，等下一个买点
```

### 1.6 行动纪律

**系统说买就买，说卖就卖。** 三维确认齐全=买点成立。

以下**全部不是**"不操作"的合法理由：
- "盘前没覆盖" — R3已明确允许盘中感知
- "tracker没预研" — R8路径B已允许
- "今天是周五" — 周五无额外买入限制
- "方向太强可能见顶" — 这是猜测，不是系统判断
- "再等等看" — 犹豫=脱离系统=变成随意交易

**偏向不操作 = 系统性错误，和违规操作同等严重。**

## 二、关键判断原则

### 2.1 感知信号 ≠ 硬门槛

系统中的数值（涨停数、封板率、先行信号等）是**感知信号**——提醒你注意，不是触发条件。

看到信号后的思考方向：**这对当前的预期意味着什么？**

- 某方向出现5只涨停 → 信号告诉你"这个方向有资金进场" → 你要判断"这个预期值不值得交易"
- 不是"够不够触发条件"，而是"预期确认了吗？"
- **先行信号（T-1已有涨停）是加分项**（预期延续性更强），**不是必要条件**。无先行信号=当日催化驱动，同样有效

### 2.2 概念标签 ≠ 归因结论

concepts.json的标签是数据输入，不是分析结论。每只涨停股必须追问"它为什么涨停？实际催化是什么？"

- 标签说"华为"，但实际催化可能是"MLCC涨价" → 归因到MLCC，不是华为
- **同一只股只归入一个方向**（它的主驱动方向）

### 2.3 大叙事反向拆解

当某方向≥20只涨停时，其他方向的股票容易被吸进去当"跟风"。必须反向检查：
- 这些"跟风股"有没有自己的独立催化？→ 如果有，它们是独立方向
- 剥离后重新统计：独立方向的涨停数可能是被低估的

### 2.4 连板股独立归因

连续2天+涨停的个股，必须追问其**连续涨停的独立催化源**（涨价/订单/技术突破等）。
- 不能因为"大方向在爆发"就把它归入大方向
- 归因结果须单独记录于tracker，作为后续盘前催化扫描的起点

## 三、红线规则（违反任何一条 = 系统性错误）

### R1：没有明确预期，不买

随手单 = 没有预期的单 = 亏损的根源。

### R2：三维确认缺一维，不买

资金、价格、预期依据三个维度都要看。每个维度必须引用具体数据（个股名称+价格+涨停时间+催化源），禁止模糊判断。

| 维度 | 正确写法 | 错误写法 |
|------|---------|---------|
| 资金确认 | ✅ 美利云09:35+达实09:44+超讯09:50=3只涨停 | ❌ "多只涨停" |
| 预期依据 | ✅ 盘前C10工信部先进计算+东数西算国策 | ❌ "缺明确催化锚" |
| 价格确认 | ✅ 宏景289元+20cm+41.6亿=高价大成交龙头 | ❌ "低价/中小盘分散" |

### R3：预期失效，必走

不扛单，不抱幻想，不"再看看"。

### R4：预期兑现，必走

不贪最后一段，不因为涨了就觉得还能涨。

### R5：不因市场整体数据打折仓位

一个方向资金确认了，它就有承接力。不看大盘涨停数多少来决定买不买。

### R6：不机械执行

任何指标都只是感知信号，回到核心问题：预期确认了吗？兑现了吗？失效了吗？

### R7：盘中感知不是盘中追涨

发现新预期 ≠ 立刻买。评估、验证、等确认。但如果确认齐全 → 必须执行。

### R8：买前必须定义三件事

预期是什么、兑现标志、失效标志——买入前锁定，买入后不改。没有定义这三件事，不执行买入。

### R9：信息不足，默认不操作

三维确认中任何一维信息不清晰，标记为"观察"。
**但**："信息不足"指维度数据缺失，不是"没找到完美数据"。三维确认所需数据均可从现有数据源获取=信息充足，必须行动。

### R10：系统确认 = 必须行动（反向红线）

当以下条件**同时满足**时，**必须执行买入**：
1. 三维确认齐全（资金✅+预期依据✅+价格✅，每个引用具体数据）
2. 有可执行的买入窗口（标的未封死、未跌停）
3. 退出信号清晰（能回答"什么情况下走"）

违反本条 = 和违反R1-R9同等严重的系统性错误。

### R11：预期必须前置研究

预期必须有研究基础。两条路径地位平等：
- **路径A（盘前预研）**：盘前分析识别方向 → tracker完成标的预研 → 盘中监控资金确认 → 买入
- **路径B（盘中感知）**：盘中发现新方向 → 三维确认齐全 → 主板筛选 → 买入 → 当日盘后补入tracker

两条路径都是系统的正常操作通道。路径B不是"例外"。
- tracker中标的预研必须包含：正宗度理由、产业链位置、市值量级
- 只能买主板：000xxx、002xxx、600xxx、601xxx、603xxx、605xxx。创业板(300/301)和科创板(688)不可买

## 四、每日任务检查清单

> 每个交易日执行以下4个任务，按顺序完成。

### 任务A：盘前分析（9:00前完成）

```
□ 读取 expectations/tracker.md → 了解活跃预期（阶段+锚点+预研标的）
□ 读取 account/portfolio.md → 了解当前持仓+止损止盈红线
□ 读取 system/templates.md → 获取八维扫描规范+输出模板
□ 读取前一日的涨停数据 limit-up-YYYYMM(DD-1).json → 先行信号参考
□ 八维催化扫描（按templates.md规范，8个维度逐一搜索并记录）
  - 每个活跃方向做产业链纵深搜索（上游/中游/下游各搜）
  - 雪球(xueqiu.com)作为必搜本土催化来源
  - 消息来源优先级：路透/彭博 > 财联社 > 雪球 > 新浪/东财 > search_web
□ 候选预期方向评估（每个方向做统一判断框架4问）
□ 标注预期阶段（出现期/确认期/加速期/兑现期/结束期）
□ 制定交易预案（if-then+买点+仓位+止损止盈线）
□ 盘中感知准备（什么条件下关注新方向+监控方向承接力观察点）
□ 周五持仓评估（仅对高位持仓评估周末风险，不影响新买入决策）
□ 输出文件：daily/YYYY-MM-DD/盘前分析.md（按templates.md模板格式）
```

### 任务B：模拟看盘（盘后15:00后完成）

#### 阶段一：数据准备

```
□ 读取 expectations/tracker.md → 当前跟踪的所有预期及核心标的
□ 读取 data/limit_list/limit-up-YYYYMMDD.json → 全部涨停股明细
□ 读取 data/limit_list/limit-up-concepts-YYYYMMDD/concepts.json → 概念排名TOP15
□ 读取 data/limit_list/limit-up-YYYYMM(DD-1).json → T-1先行信号
□ 读取 daily/YYYY-MM-DD/盘前分析.md → 催化清单(C1/C2/...)
□ 将概念排名与催化清单交叉核对
```

#### 阶段二：数据核验

```
□ 步骤1：概念排名TOP15表（从concepts.json）
□ 步骤2：核心涨停股明细表（代码/名称/收盘价/涨幅/成交额/涨停时间/所属概念）
□ ★ 步骤2.5：概念去噪（三维确认前强制完成，不可跳过）：
  □ 个股预期归因：每只涨停股追问"实际催化是什么？"（不是concept标签）
  □ 主驱动聚合：按归因结果重新分组，每只股只计入一个方向
  □ 正宗龙头验证：该方向公认龙头是否在响应？
  □ 连板股检查：连续2天+涨停 → 追问独立催化源，不能被大方向吸收
  □ 大叙事反向检查：≥20只涨停方向 → 剥离有独立产业链逻辑的个股
  □ 归因涨停数替代原始概念计数（三维确认使用归因后的数据）
□ 步骤3：先行信号核查表（T-1涨停与今日方向重叠）
□ 步骤4：盘前催化交叉核对表
```

#### 阶段三：盘中分析（严格盘中视角）

```
□ 按时间线推进（09:25→10:00→10:30→13:00→14:30→15:00）
□ 只使用当时可知的信息，不用收盘后才知道的信息
□ 10:30三维确认重评（每个方向必须填表，引用具体数据点）
□ ★ 10:30盘中感知新方向评估：
  □ 扫描≥2只涨停的非预案方向
  □ 逐个执行L038三维确认（资金+预期依据+价格）
  □ 快速评估3问：①什么类型预期？②退出信号清晰？③和当前计划什么关系？
□ 13:30三维确认重评（不可复制上午结论，标注vs上午变化）
□ ★ 13:30盘中感知新方向再评估：
  □ 10:30偏弱的新方向若资金大增 → 必须重新判断三维是否已齐
  □ 扫描13:30时新增的≥2只涨停方向
□ ★ 买入窗口校验（如三维齐全）：
  □ 确认完成时刻是否处于标的的有效买入窗口内
  □ 标的封板后打开次数≥1 / 未封死 = 有窗口
  □ 标的已封死无打开 = 无窗口 → 换下一个候选
```

#### 阶段四：买入决策（如三维齐全）

```
□ 确认三维齐全（资金✅+预期依据✅+价格✅，每个引用数据）
□ 执行主板筛选：列出方向全部标的 → 标记板块 → 排除创业板/科创板/920xxx
□ 主板标的排序：概念交叉数 × 成交额 × 涨停时间早晚
□ 计算买入时间：感知触发时间 + 15分钟确认 + 筛选时间
□ 计算买入价格：基于该标的涨停时间和前日收盘价合理估算（见五.2）
□ 锁定买前三件事：预期是什么 / 兑现标志 / 失效标志
□ 确定买点类型和仓位（见五.1）
```

#### 阶段五：账户更新

```
□ 模拟看盘.md：操作明细 + 持仓明细 + 账户总览（数字必须一致）
□ portfolio.md：账户状态 + 当前持仓 + 交易记录 + 每日快照 + 信号统计
□ 交叉验证：两个文件的数字必须完全一致（买入价/数量/现金/总资产）
```

### 任务C：持仓管理（每日盘前+盘后对现有持仓评估）

```
□ 每只持仓检查：
  □ 预期阶段是否变化？（出现→确认→加速→兑现→结束）
  □ 锚点数据是否更新？（产业价格/政策进展/业绩数据）
  □ 买入预期是否仍然成立？
□ 卖出信号评估：
  □ 预期兑现？（利好已落地/数据已验证）→ 准备卖出
  □ 预期失效？（催化被证伪/板块连续2天无涨停）→ 立即清仓
  □ 预期仍在确认期/加速期？→ 持有，不动
□ 盘前红线验证：止损价/止盈条件是否触及
□ 加仓信号：预期更强确认+回调到支撑位 → 可加仓（同主题加到3成）
□ 周五持仓评估（如适用）：仅对高位持仓评估周末风险，不影响新买入
```

### 任务D：盘后复盘（盘后15:00后完成）

□ 盘前判断回顾：哪些对了？哪些错了？为什么？
□ 盘中感知复盘：发现了什么？遗漏了什么？评估准确吗？
□ 覆盖诊断：今天在加速期才发现的方向 → 追问出现期/确认期在哪里、为什么盘前没扫到
□ 经验教训：提取2-3条写入 lessons/learned.md
□ 更新tracker：
  □ 更新预期阶段（确认→加速/兑现→结束等）
  □ 补充盘中感知发现的新方向
  □ 更新锚点数据
□ 更新portfolio.md：交易记录+持仓+盈亏
□ 信号记录.md：按templates.md模板填写

## 五、买入执行参考

### 5.1 仓位规则

- **买点类型决定仓位**（不是预期强度）：
  - 首板买点 = 1-1.5成
  - 确认买点 = 3成
  - 回调买点 = 加到3成
- **同主题不叠仓**：同一方向最多3成
- **多主题并发**：各自独立3成
- **单主题只做一只龙头**

### 5.2 买入价格估算

基于涨停时间和前日收盘价估算。买入时刻在标的涨停前，价格在前日收盘×(1+涨幅)区间内。

**示例**：某股前日收盘100元，涨停价110元。09:50涨停，AI在09:40买入（当时涨幅约7-8%），估算价≈107-108元。

**买入时间推算**：感知触发时间 + 15分钟三维确认 + 主板筛选时间。必须从涨停时间链倒推，不能随意写。

## 七、首板核心筛选方法论

> 每天涨停数据出来后，快速筛出"主动走强+强预期驱动"的核心公司。
> 适用：盘后复盘、盘前方向确认、确认点后的方向扫描。

### 第一步：数据筛基础池

```
□ 读取当日 limit-up-YYYYMMDD.json
□ 读取前日 limit-up-YYYYMM(DD-1).json → 标记连板（两日均出现=连板，排除）
□ 主板筛选：排除 300xxx/301xxx/688xxx/920xxx
□ 成交额门槛：amount ≥ 5亿
```

### 第二步：方向聚类

```
□ 读取 concepts.json → 获取每个涨停股的概念标签
□ 按概念交叉分组：同一大方向的涨停股归为一类
□ 识别共振方向：涨停数≥3 + 封板时间跨上午/下午 = 全天强势
□ 初步识别领涨股：同方向中最早封板 + 最大成交额
```

### 第三步：多维度深挖（每个候选股必过四关）

**A. 预期溯源**
- 涨的是什么预期？（产业/业绩/政策/事件）
- 预期独立还是蹭的？（有自己的催化 vs 跟着板块涨）
- 预期可验证吗？（有产业数据锚/业绩/订单公告）

**B. 正宗度验证**
- 概念交叉数：concepts.json中出现在几个概念下？≥3 = 高正宗度
- 产业链位置：上游材料/设备 > 中游制造 > 下游应用
- 行业地位：国内TOP3？唯一供应商？
- 排除蹭概念：主营和方向关联度<30% → 剔除

**C. 主动走强证据**
- 封板时机：早于同方向=领涨，晚于=跟涨
- 封板质量：open_times=0最干净；≥3分歧大
- 尾盘才封板（14:00后）→ 主动性差

**D. 资金确认**
- 成交额：>30亿=机构级；10-30亿=游资+机构；<10亿=游资
- 同方向排名：成交额排第几？
- 独立放量：近5日均量 vs 涨停日成交额倍数

### 第四步：瑕疵排查

```
□ 位置风险：近5日已涨超15%？→ 加速段首板，买点性质不同
□ 炸板风险：open_times≥3 → 资金分歧大
□ 概念噪音：标签虽多但多是蹭的（主营收入占比<20%）
□ 尾盘封板：14:00后才封 → 次日溢价不确定
```

### 第五步：综合排名

| 维度 | 权重 | 评分标准 |
|------|------|---------|
| 预期强度 | 40% | 独立产业逻辑+可验证=3；有催化不独立=2；纯跟涨=1 |
| 主动走强 | 35% | 早盘领涨+0炸板=3；早盘跟涨=2；午后跟涨=1 |
| 正宗度 | 25% | 4+概念交叉+核心环节=3；2-3概念=2；1概念=1 |
