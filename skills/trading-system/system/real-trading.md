# 真实看盘循环模式 v2.0

> 适用：2026-06-15 起每个交易日的盘中实战。
>
> 与模拟看盘区别：模拟看盘是**事后回放**（一次性五阶段闭环），真实看盘是**盘中实时滚动**（主动循环巡盘 4 小时直到收盘）。
>
> **规则不变**：本文档**只定义执行模式**，不新增交易规则。所有买卖判断的源头都是 `system/trading-system.md`：三维确认（§2.1）+ L038 路径B（§零之二）+ R8 买前三件事（§2.1）+ 红线（§五）。`templates.md` 的盘前分析模板两种模式共用，真实看盘的巡盘/思考链路模板见本文档§五。

---

## 一、本质定位

### 1.1 与模拟看盘的对照

| 维度 | 模拟看盘（≤6/12） | 真实看盘（≥6/15） |
|---|---|---|
| 触发 | 收盘后一次性启动 | 用户说"开始看盘"启动循环 |
| 数据源 | `astock query kline --date YYYYMMDD --freq 1m` | `astock live quote/minute/tick/block` 直连 TDX |
| 视角 | 事后回放（已知收盘结果） | 严格盘中（只用当时已发生的信息） |
| 监控范围 | astock query kline 全市场 | TDX 全市场任意股票 |
| 涨停时间 | 无（需估算） | `live block members` 实时观察 |
| 决策 | 写入"模拟看盘.md" | AI 自主拍板执行（虚拟账户） |
| 文档结构 | 单文件五阶段 | 按节点切片 + 思考链路全程 |

### 1.2 责任与权限

虚拟账户视为 **AI 自有账户**，AI **自负盈亏、自主决策**。买/卖/加仓/减仓由 AI 自行拍板，但必须严格走完三道关：

```
trading-system.md §2.1 三维确认（资金确认 + 价格确认 + 预期依据）
          + §零之二 L038 路径B（盘中感知 → 统一判断框架）
          + §2.1 买前三件事锁定（预期 / 兑现标志 / 失效标志）
          + §五 纪律红线 R1-R11
```

任一不达标 → **必须放弃**，哪怕看着像机会。决策不达标的"机会"= 系统性错误，与违规操作同等严重。

## 二、触发与退出协议

### 2.1 启动

用户输入触发词 → AI 进入循环巡盘模式：
- "开始看盘" / "开始" / "看盘" / "盯盘"
- 启动后立即执行【启动序列】（见 §三）

### 2.2 中途暂停

AI 在以下情况主动暂停循环、等用户回应：
- token 用量达 70% → 主动收尾归档
- 用户输入"停" / "暂停" / "等等" / "你别看了"

> 注：§5.3 硬拒绝场景（R8不清/仓位破线/亏损冷静期）**不暂停循环**，AI直接裁决不买并继续下一轮巡盘。

### 2.3 退出

- 收盘 15:00 → 自动进入收盘归档流程（见 §九）
- 用户主动叫停 → 立即归档当前状态
- 节点 14:50 后不再开新仓（仅做卖出/止损操作）

### 2.4 续看

中途暂停后用户说"继续" → AI 执行恢复序列：
1. 读 `当前状态.md` → 获取持仓+轮转状态+冷静期状态
2. 读 `system/real-trading.md` §四§五 → 重新加载执行规则（防止上下文丢失后规则遗忘）
3. 按 当前状态.md 中“深析覆盖”字段确认是否需补做③④⑤⑥
4. 主对话确认：“已恢复，快扫持续+深析状态：X，持仓状态：Y”

> 续看必须重新加载规则文件，不能只读状态文件。上下文丢失=规则丢失。

## 四、循环巡盘机制

### 4.1 关注点轮转池（6 类）

①②是快扫层的固定扫描项，③④⑤⑥是深析层按信号触发的分析项。

| 关注点 | 层级 | 数据动作 | 思考输出 |
|---|---|---|---|
| ① 持仓巡检 | 快扫 | live quote 持仓 N 只 | 涨跌幅>2%？触及止损/止盈？ |
| ② 板块强度 | 快扫 | live block rank --limit 10 | tracker方向在TOP3？≥2涨停？ |
| ③ P1 候选触发 | 深析 | live quote + live minute 候选股 | 三维确认是否齐？买点窗口是否打开？ |
| ④ 涨停板异动 | 深析 | query limit list + live block members | 新增涨停 / 炸板分析归因 |
| ⑤ 大盘趋势 | 深析 | live quote 指数 + live minute 上证 | 量能/趋势是否支持当前操作 |
| ⑥ 盘中新方向 | 深析 | live block rank + 跨板块归因 | 盘前未覆盖但≥2 涨停的方向 → L038 评估 |

**②→③ 同轮触发**：快扫检测到 tracker已入库方向≥2涨停或排名TOP3 → 立即进入深析层做③三维检查。这是盘中买点的唯一实时保障。

**三维齐但不买 = 必须落盘**：深析层三维确认齐全但最终不买（无窗口/集中度/红线），必须在巡盘日志中写明放弃理由。未记录 = 过程违规。

### 4.2 分层执行模型（快扫 + 深析）

> **核心思路**：人看盘是“余光扫屏幕+异动才细看”，不是“每30秒做一次完整分析”。AI也一样。

#### 第一层：快扫（连续运行，信号检测）

```
□ 1. astock live quote 持仓 N 只（~3s）
□ 2. astock live block rank --limit 10（~10s）
□ 3. 信号检测（10s内完成，不写MD不更新状态）：
   - 持仓信号：任一持仓涨跌幅>2%？触及止损/止盈？板块排名骤降？
   - 方向信号：tracker已入库方向在TOP3？≥2涨停？
   - 新方向信号：盘前未覆盖方向≥2涨停？
   - 大盘信号：指数单边异动？
□ 4. 无信号 → 不写日志，立即开始下一次快扫。每5分钟写1行heartbeat（"快扫持续·无信号"）
□ 5. 有信号 → 立即进入第二层深析
```

快扫预算：≤2次工具调用 · ≤100 token · ~15-20秒（API调用时间为自然间隔，无需人工等待）

#### 第二层：深析（信号触发，完整分析）

```
□ Step 1: 信号定向（是什么信号？分析哪个方向/标的？）
   - 持仓信号 → 持仓深析（止损/止盈/预期切换评估）
   - 方向信号 → 三维检查（§4.1 ③的完整流程）
   - 新方向信号 → L038评估（§4.1 ⑥的完整流程）
   - 大盘信号 → 大盘趋势评估（§4.1 ⑤）
□ Step 2: 拉详细数据（live minute / live block members / query limit 等）
□ Step 3: 主线程思考（不超过 200 字）
   - 三维确认是否齐？
   - 买点窗口是否打开？
   - 是否触发买/卖/加仓/调止损？
□ Step 4: 落盘（同§4.2深析落盘规则，含执行链）
□ Step 5: 轮末自检 + 更新当前状态.md轮转状态
```

深析预算：≤5次工具调用 · ≤500 token · 2-4分钟

#### 快扫与深析的关系

| 维度 | 快扫 | 深析 |
|---|---|---|
| 频率 | 连续运行（扫完即下一轮） | 信号触发时 |
| 工具调用 | ≤2次（quote+block rank） | ≤5次（按需拉详细数据） |
| token | ≤100 | ≤500 |
| 落盘 | heartbeat每5分钟1行 | 完整MD（思考链路/异动/新方向等） |
| 状态更新 | 不更新当前状态.md | 必须更新轮转状态 |
| 目的 | 不漏信号 | 深度分析+执行 |

**轮转池覆盖**：快扫每轮都看①持仓+②板块，深析按轮转顺序补充③④⑤⑥。即：
- 快扫发现方向信号 → 深析做③三维检查
- 快扫发现持仓信号 → 深析做①持仓深析
- 无信号时段 → 快扫持续运行，③④⑤⑥暂不触发（没信号时做了也没意义）
- 每轮快扫仍然检查②板块强度，满足“②→③同轮触发”条件

#### ②→③ 同轮触发（在快扫层实现）

快扫检测到 tracker已入库方向≥2涨停 或 排名TOP3 → **立即进入深析层**做③三维检查。不等下一轮快扫。这是盘中买点的唯一实时保障。

#### 三维齐但不买 = 必须落盘

深析层三维确认齐全但最终不买（无窗口/集中度/红线），必须在巡盘日志中写明放弃理由。未记录 = 过程违规。

#### 深析落盘规则（Step 4 详细）

深析Step 4根据结果分三条路径：

**路径A：仅观察**
→ 追加到巡盘日志.md（1行结论）

**路径B：三维齐但不买**
→ 巡盘日志写入★决策记录（即时写入，非事后补录），包含完整链路：
  - 三维确认评估（资金✅+预期✅+价格✅，各引用具体数据）
  - R10结论（必须行动 vs 放弃）
  - 买入窗口状态（是否打开）
  - 退出信号清晰度
  - 最终决策（放弃）+ 理由（窗口/集中度/红线）
  - 代价估算（如果买入会赚/亏多少）
  - 反思（放弃是否正确）
  未写入★决策记录 = 过程违规

**路径C：买点触发 → 执行链（按顺序，不可跳步）：**
  ① 写 HHMM_<买入>_<标的>_思考链路.md（§5.4 全字段）
  ② 检查 §5.3 硬拒绝场景（R8不清=不买/仓位破线=不买/亏损冷静期/新方向三道关通过=执行）
  ③ 执行交易：更新 portfolio.md（新增持仓+交易记录+账户快照）
  ④ 更新 当前状态.md（新增持仓行+重置轮转状态+更新候选清单）
  ⑤ 巡盘日志追加买入行（时间+标的+价位+理由）
  ⑥ 主对话通知用户：买入已执行，含关键信息摘要

**路径D：卖点触发 → 执行链（止损/止盈/预期失效，同结构）：**
  ① 写 HHMM_<卖出>_<标的>_思考链路.md（§5.4 全字段 + 卖出原因：预期兑现/失效/止损）
  ② 执行交易：更新 portfolio.md（减少/清仓持仓+交易记录+账户快照）
  ③ 更新 当前状态.md（移除/减少持仓行+重置轮转状态）
  ④ 巡盘日志追加卖出行（时间+标的+价位+卖出原因）
  ⑤ 主对话通知用户：卖出已执行，含关键信息摘要

#### 深析Step 5：轮末自检

**自检清单（全部为✅才能返回快扫层，任一❌必须补完）：**
- [ ] 当前状态.md轮转状态已更新（快扫覆盖/深析覆盖）
- [ ] 如果②发现了强势方向→已同轮触发③三维检查
- [ ] 如果三维齐但不买→巡盘日志已写明放弃理由
- [ ] 如果触发了买/卖→执行链全部步骤已完成（思考链路/portfolio/当前状态/巡盘日志）
- [ ] 巡盘日志已追加本轮记录

### 4.3 选轮策略（信号驱动）

- **基础节奏**：快扫连续运行（扫完即下一轮），深析由信号触发
- **事件插队**：快扫发现信号 → 立即进入深析，不等当前快扫完成
- **②触发③**：快扫发现tracker方向≥2涨停 → 深析立即做③，不等下一轮
- **客观节点提示**：靠近 §六.2 的市场分水岭时（开盘/午休/收盘前）AI 自主判断是否需要综合快照

### 4.4 预算

| 层级 | 工具调用 | token | 时间 |
|---|---|---|---|
| 快扫 | ≤2次 | ≤100 | ≤30秒 |
| 深析 | ≤5次 | ≤500 | 2-4分钟 |

## 五、决策边界

### 5.1 系统自洽原则

**交易系统是唯一的决策源。** 三维+L038+R8全部通过=执行，任一不通过=放弃。不存在“问用户”的出口。

这是AI自己的账户，AI自负盈亏。从模拟看盘积累经验，到真实看盘验证系统，到最终真正为交易负责——系统的自洽性是根本。

### 5.2 AI自决的全部动作

所有买/卖/加仓/减仓/调止损，AI走完三道关后**直接执行**并落 portfolio.md：

- 买入（符合三维 + L038 + R8 + 主板筛选）
- 卖出（止损触发 / 止盈触发 / 预期失效）
- 加仓（同主题加到 3 成上限内）
- 减仓（持仓预期降级但未失效）
- 调整止损位（移动止损 / 锁利位上移）

### 5.3 系统硬拒绝场景（不是“问用户”，是直接不买）

以下场景由系统规则直接裁决，无需用户介入：

1. **R8红线不清晰**：买前三件事（预期/兑现标志/失效标志）任一无法明确 → **不买**，记入巡盘日志
2. **单股仓位破 30%**（含已有 + 拟买入） → **不买**，集中度硬约束
3. **当日累计亏损 > 5%**（基于昨日总资产） → **冷静期**，当日禁止开新仓，仅允许止损卖出
4. **盘前预案外的全新方向**：三道关通过=系统认可，直接执行，无需打招呼

### 5.4 决策落盘强制要求

每一笔买/卖在执行前必须先写"思考链路.md"，包含：

```
- 触发时刻 HH:MM:SS
- 三维确认：资金（涨停股名+时间）/ 预期依据（盘前/盘中催化锚）/ 价格（具体价位）
- L038：趋势确认（分时图态势）
- 买前三件事：预期 / 兑现标志 / 失效标志
- 备选方案：考虑过哪些其他标的，为什么放弃
- 仓位与价位：买/卖数量、价格、止损位
- 退出条件：什么情况下走（兑现/失效/止损）
```

未写思考链路 → 不允许动账户。

## 六、关键时刻的留证（事件驱动，非定时任务）

> AI 是在**持续判断**，不是 cron 打卡。**有价值的变化/判断才停下来做完整留证**，时间本身不是触发器。

### 6.1 必须主动留证的事件（事件来了就停轮）

下列任一情形出现 → 按 §4.2 Step 4 对应执行链处理（买/卖执行链已内置留证步骤），不允许只一句口头带过：

| 触发类型 | 具体情形 | 对应执行链 |
|---|---|---|
| **拟执行买卖** | 三维齐 + L038 通过 + R8 锁定 → §4.2 Step4 买点/卖点执行链 | `HHMM_<动作>_<标的>_思考链路.md` |
| **持仓异动** | 单股触及预设止损/止盈位 / 单股日内振幅 >5% | `HHMM_持仓异动_<标的>.md` |
| **预期阶段切换** | 持仓方向从加速期→兑现期 / 出现期→确认期 / 任一阶段→结束期 | `HHMM_预期切换_<方向>.md` |
| **盘中新方向** | 盘前预案外的方向 ≥2 涨停且联动可见 | `HHMM_新方向_<方向>.md` |
| **关键锚点异动** | 产业数据破位 / 龙头炸板 / 政策突发 / 大盘单边异动 | `HHMM_锚点异动_<事件>.md` |

### 6.2 客观市场节点（自然分水岭，AI 自主判断是否快照）

A 股市场结构本身有几个客观节点，市场状态会发生本质变化。**AI 在这些时刻应主动判断"现在值不值得做综合快照"**——通常值得做，但**不是必须**：

| 节点 | 市场结构变化 | AI 应判断的要点 |
|---|---|---|
| 09:30 后 ~10 分钟内 | 集合竞价过去，连续竞价开始 | 高低开偏离盘前预案多少？if-then 是否已有触发？ |
| 11:30 上午收盘 | 半场结束 | 持仓/板块强弱/盘前 P1-P3 命中率值得整理一次 |
| 13:00 下午开盘 | 午休后情绪 reset | 上午悬念是否被验证？下午策略需要调整吗？ |
| **14:50 尾盘** | **硬性规则边界（不开新仓）** | 仅卖出/止损可执行，禁开新仓 |

**只有 14:50 是硬性规则**（来自 §五 红线），其余三个是 AI 自主判断的自然停顿点——值得停就停，没什么变化就跳过。

### 6.3 单纯观察 → 巡盘日志一行追加

深析层不构成 §6.1 任一事件的常规观察 → 直接追加到 `daily/YYYY-MM/DD/盘中观察/巡盘日志.md` 一行（含时间 + 一句结论）即可。快扫层不写日志，仅每5分钟heartbeat一行。

**避免“为写而写”**：没有判断价值的快照不写，AI 不是定时任务执行器。

### 6.4 收盘自检（最终兜底，非主力机制）

> 盘中实时保障靠 §4.1 快扫+深析 + ②→③同轮触发，收盘自检只是最后一道防线。

收盘后写收盘快照前，快速自检：

1. 今日 6 类轮转池是否全部执行过？③④ 是否被跳过？
2. 今日 TOP3 板块中 tracker 已入库方向是否均已做三维检查？
3. 所有三维齐全但未执行买入的方向是否已在巡盘日志中写明放弃理由？

未通过 → 补录到巡盘日志。但注意：盘后补救无法挽回盘中买点，这仅是复盘质量保障。

## 八、token 与上下文管理

### 8.1 上下文洁癖原则

主对话**只保留**：
- 当前轮次摘要（≤ 200 字）
- 待执行预案 / 下一关注点
- 关键决策的最终结论

主对话**禁止保留**：
- 完整的 live block rank 输出（50 行表格）
- 多轮 quote 历史数据
- 八维催化扫描的搜索结果

详细全部进 MD 文件。

### 8.2 上限保护

- token 用量 60% → 主动启动归档（写当前状态.md + 巡盘日志.md）
- token 用量 70% → 收尾退出，提示用户"建议新开 session 继续"
- 单轮 token 产出 > 800 → 强制截断转 MD

### 8.3 sub-agent 落盘策略

详细分析（如八维催化、归因复盘）调用 sub-agent 完成 → sub-agent 写完 MD 退出 → 主线程只接收"已写入 X.md"摘要。

> 注意：当前 Search subagent 是只读的，写文件需主线程 SearchReplace/Write。所以"sub-agent 落盘"实际是**主线程一次性发起多个并行 Write/SearchReplace 操作**实现"落盘不阻塞思考"。

## 九、收盘归档流程（15:00 后）

```
□ 1. 拉收盘 live quote 持仓 N 只 → 锁定收盘价
□ 2. 写当日 portfolio.md 最终版（交易记录 + 持仓 + 现金 + 总资产 + 当日盈亏）

□ 4. 写 daily/YYYY-MM/DD/收盘复盘.md
   - 今日各预期方向实际表现 vs 盘前判断

   - 盘中感知复盘：发现了什么？遗漏了什么？
   - 经验教训：≥2 条写入 lessons/learned.md
□ 5. 更新 expectations/tracker.md：预期阶段调整
□ 6. 写 daily/YYYY-MM/DD/次日预案.md → 滚到次日盘前分析的种子
```

## 十、与现有规则的关系

### 10.1 复用而非新增

| 现有文件 | 真实看盘如何使用 |
|---|---|
| `system/trading-system.md` | **唯一规则源头**：三维确认 §2.1 / L038 路径B §零之二 / R8 §2.1 / 八维催化 §三盘前 / 纪律红线 §五 全部直接适用 |

- **深析**：信号触发后的完整分析，含三维检查+执行链+落盘+自检
- **思考链路.md**：每笔决策前的强制留证文档
- **当前状态.md**：实时滚动的"AI 在干啥"快照
