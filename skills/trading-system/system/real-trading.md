# 真实看盘循环模式 v1.0

> 适用：2026-06-15 起每个交易日的盘中实战。
>
> 与模拟看盘区别：模拟看盘是**事后回放**（一次性五阶段闭环），真实看盘是**盘中实时滚动**（主动循环巡盘 4 小时直到收盘）。
>
> **规则不变**：本文档**只定义执行模式**，不新增交易规则。所有买卖判断的源头都是 `system/trading-system.md`：三维确认（§2.1）+ L038 路径B（§零之二）+ R8 买前三件事（§2.1）+ 红线（§五）。`templates.md` 是**模拟看盘专用模板**，真实看盘不依赖它。

---

## 一、本质定位

### 1.1 与模拟看盘的对照

| 维度 | 模拟看盘（≤6/12） | 真实看盘（≥6/15） |
|---|---|---|
| 触发 | 收盘后一次性启动 | 用户说"开始看盘"启动循环 |
| 数据源 | `astock query kline --date YYYYMMDD --freq 1m` | `astock live quote/minute/tick/block` 直连 TDX |
| 视角 | 事后回放（已知收盘结果） | 严格盘中（只用当时已发生的信息） |
| 监控范围 | 受 295 只 kline_minute 限制 | TDX 全市场任意股票 |
| 涨停时间 | 无（需估算） | `live block members` 实时观察 |
| 决策 | 写入"模拟看盘.md" | AI 自主拍板执行（虚拟账户） |
| 文档结构 | 单文件五阶段 | 按节点切片 + 思考链路全程 |

### 1.2 责任与权限

虚拟账户视为 **AI 自有账户**，AI **自负盈亏、自主决策**。买/卖/加仓/减仓由 AI 自行拍板，但必须严格走完三道关：

```
trading-system.md §2.1 三维确认（资金确认 + 价格确认 + 预期依据）
          + §零之二 L038 路径B（盘中感知 → 统一判断框架）
          + §2.1 买前三件事锁定（预期 / 兑现标志 / 失效标志）
          + §五 纪律红线 R1-R9
```

任一不达标 → **必须放弃**，哪怕看着像机会。决策不达标的"机会"= 系统性错误，与违规操作同等严重。

## 二、触发与退出协议

### 2.1 启动

用户输入触发词 → AI 进入循环巡盘模式：
- "开始看盘" / "开始" / "看盘" / "盯盘"
- 启动后立即执行【启动序列】（见 §三）

### 2.2 中途暂停

AI 在以下情况主动暂停循环、等用户回应：
- 触发**兜底场景**（见 §五）
- token 用量达 70% → 主动收尾归档
- 用户输入"停" / "暂停" / "等等" / "你别看了"

### 2.3 退出

- 收盘 15:00 → 自动进入收盘归档流程（见 §九）
- 用户主动叫停 → 立即归档当前状态
- 节点 14:50 后不再开新仓（仅做卖出/止损操作）

### 2.4 续看

中途暂停后用户说"继续" → AI 读 `当前状态.md` 恢复循环。

## 三、启动序列（说"开始"后立即做）

```
□ 1. 读 daily/YYYY-MM/DD/盘前分析.md → 加载今日预案（P1/P2/P3 方向 + 八维催化清单 + 持仓应对）
□ 2. 读 expectations/tracker.md → 加载活跃预期阶段
□ 3. 读 account/portfolio.md → 加载持仓状态 + 止损止盈位
□ 4. 调 astock live quote 拉持仓 3 只现状 → 与 portfolio 对照
□ 5. 调 astock live block rank → 板块强度初步快照
□ 6. 写入 daily/YYYY-MM/DD/盘中观察/0930_启动快照.md
□ 7. 主对话仅留 1-3 行摘要：今日盘前主线 + 持仓状态 + 第一个关注点
□ 8. 进入循环巡盘（§四）
```

## 四、循环巡盘机制

### 4.1 关注点轮转池（6 类）

每一轮巡盘聚焦**1 个**关注点，按下表轮转。**强制时点优先**（§六）。

| 关注点 | 数据动作 | 思考输出 |
|---|---|---|
| ① 持仓巡检 | live quote 持仓 3 只 | 是否触发止损/止盈/锁利？预期阶段是否变化？ |
| ② 板块强度 | live block rank --limit 20 | TOP10 vs 盘前 P1/P2 命中？板块强弱切换信号？ |
| ③ P1 候选触发 | live quote + live minute 候选股 | 三维确认是否齐？买点窗口是否打开？ |
| ④ 涨停板异动 | query limit list（盘中可调） + live block members | 新增涨停 / 炸板分析归因 |
| ⑤ 大盘趋势 | live quote 上证/深成/创业（指数） + live minute 上证 | 量能/趋势是否支持当前操作 |
| ⑥ 盘中新方向 | live block rank + 跨板块归因 | 盘前未覆盖但≥2 涨停的方向 → L038 评估 |

### 4.2 单轮标准 5 步（每轮 1-3 分钟）

```
□ Step 1: 选关注点（按 4.3 选轮策略）
□ Step 2: 拉数据（最少调用，避免过载）
□ Step 3: 主线程思考（不超过 200 字）
   - 当前发生了什么？
   - 对预期意味着什么？
   - 是否触发任一动作（买/卖/加仓/调止损）？
□ Step 4: 落盘（用 sub-agent / SearchReplace 写入对应 MD）
   - 触发动作 → daily/YYYY-MM/DD/盘中观察/HHMM_<动作>_思考链路.md
   - 仅观察 → 追加到 daily/YYYY-MM/DD/盘中观察/巡盘日志.md
□ Step 5: 主对话仅留 1-2 行摘要 + 下一轮关注点
```

### 4.3 选轮策略（事件驱动，非定时任务）

- **基础节奏**：按轮转池顺序 ①→②→③→④→⑤→⑥→① 滚动循环
- **事件插队**（优先于轮转）：出现 §六.1 任一事件 → 立即停下当前轮、转去做完整留证
- **客观节点提示**：靠近 §六.2 的市场分水岭时（开盘/午休/收盘前）AI 自主判断是否需要综合快照——**不是打卡，是值得停下来时就停**

### 4.4 单轮预算

- 数据调用：≤ 5 次工具调用
- token 产出：≤ 500 token（详细分析进 MD，不污染主上下文）
- 时间：1-3 分钟（live block rank 单次 ~10s，prefer 复用）

## 五、决策边界（关键）

### 5.1 AI 自决的动作

下列动作不需要询问用户，AI 走完三道关后**直接执行**并落 portfolio.md：

- 买入（符合三维 + L038 + R8 + 主板筛选）
- 卖出（止损触发 / 止盈触发 / 预期失效）
- 加仓（同主题加到 3 成上限内）
- 减仓（持仓预期降级但未失效）
- 调整止损位（移动止损 / 锁利位上移）

### 5.2 必须暂停问用户的兜底场景

仅 4 种，**禁止扩大**：

1. **违反 R8 红线**：买前三件事（预期是什么/兑现标志/失效标志）任一无法明确 → 暂停问用户
2. **单股仓位即将突破 30%**（含已有仓位 + 拟买入）→ 暂停问用户
3. **当日累计亏损 > 5%**（基于昨日总资产）→ 暂停问用户，进入冷静期
4. **盘前预案外的全新方向**（路径 B 盘中感知）首次发现 → 至少打招呼后再走三道关

### 5.3 决策落盘强制要求

每一笔买/卖在执行前必须先写"思考链路.md"，包含：

```
- 触发时刻 HH:MM:SS
- 三维确认：资金（涨停股名+时间）/ 预期依据（盘前/盘中催化锚）/ 价格（具体价位）
- L038：趋势确认（分时图态势）
- 买前三件事：预期 / 兑现标志 / 失效标志
- 备选方案：考虑过哪些其他标的，为什么放弃
- 仓位与价位：买/卖数量、价格、止损位
- 退出条件：什么情况下走（兑现/失效/止损）
```

未写思考链路 → 不允许动账户。

## 六、关键时刻的留证（事件驱动，非定时任务）

> AI 是在**持续判断**，不是 cron 打卡。**有价值的变化/判断才停下来做完整留证**，时间本身不是触发器。

### 6.1 必须主动留证的事件（事件来了就停轮）

下列任一情形出现 → 暂停当前轮巡盘，做完整快照（拉数据 + 思考 + 写 MD），不允许只一句口头带过：

| 触发类型 | 具体情形 | 留证文件 |
|---|---|---|
| **拟执行买卖** | 三维齐 + L038 通过 + R8 锁定 → **执行前必写** | `HHMM_<动作>_<标的>_思考链路.md` |
| **持仓异动** | 单股触及预设止损/止盈位 / 单股日内振幅 >5% | `HHMM_持仓异动_<标的>.md` |
| **预期阶段切换** | 持仓方向从加速期→兑现期 / 出现期→确认期 / 任一阶段→结束期 | `HHMM_预期切换_<方向>.md` |
| **盘中新方向** | 盘前预案外的方向 ≥2 涨停且联动可见 | `HHMM_新方向_<方向>.md` |
| **关键锚点异动** | 产业数据破位 / 龙头炸板 / 政策突发 / 大盘单边异动 | `HHMM_锚点异动_<事件>.md` |

### 6.2 客观市场节点（自然分水岭，AI 自主判断是否快照）

A 股市场结构本身有几个客观节点，市场状态会发生本质变化。**AI 在这些时刻应主动判断"现在值不值得做综合快照"**——通常值得做，但**不是必须**：

| 节点 | 市场结构变化 | AI 应判断的要点 |
|---|---|---|
| 09:30 后 ~10 分钟内 | 集合竞价过去，连续竞价开始 | 高低开偏离盘前预案多少？if-then 是否已有触发？ |
| 11:30 上午收盘 | 半场结束 | 持仓/板块强弱/盘前 P1-P3 命中率值得整理一次 |
| 13:00 下午开盘 | 午休后情绪 reset | 上午悬念是否被验证？下午策略需要调整吗？ |
| **14:50 尾盘** | **硬性规则边界（不开新仓）** | 仅卖出/止损可执行，禁开新仓 |

**只有 14:50 是硬性规则**（来自 §五 红线），其余三个是 AI 自主判断的自然停顿点——值得停就停，没什么变化就跳过。

### 6.3 单纯观察 → 巡盘日志一行追加

不构成 §6.1 任一事件的常规观察 → 直接追加到 `daily/YYYY-MM/DD/盘中观察/巡盘日志.md` 一行（含时间 + 一句结论）即可。

**避免"为写而写"**：没有判断价值的快照不写，AI 不是定时任务执行器。

## 七、MD 文件结构

```
daily/YYYY-MM/DD/
├── 盘前分析.md                   # 盘前已就绪
├── 盘中观察/
│   ├── 巡盘日志.md                # 每轮观察追加（仅观察、无动作）
│   ├── HHMM_启动快照.md             # 启动序列产出（一次）
│   ├── HHMM_半场快照.md             # AI 主动发起：上午收盘/下午开盘等自然节点（按需）
│   ├── HHMM_持仓异动_<标的>.md      # 触及止损止盈/振幅 >5%
│   ├── HHMM_预期切换_<方向>.md      # 阶段切换
│   ├── HHMM_新方向_<方向>.md        # 盘中感知新方向 ≥2 涨停
│   ├── HHMM_锚点异动_<事件>.md      # 产业数据/龙头炸板/政策突发
│   ├── HHMM_<买/卖/加/减/止损>_<标的>_思考链路.md   # 执行前必写

├── portfolio.md                   # 账户实时状态（每节点更新）
└── 收盘复盘.md                    # 15:00 后归档
```

## 八、token 与上下文管理

### 8.1 上下文洁癖原则

主对话**只保留**：
- 当前轮次摘要（≤ 200 字）
- 待执行预案 / 下一关注点
- 关键决策的最终结论

主对话**禁止保留**：
- 完整的 live block rank 输出（50 行表格）
- 多轮 quote 历史数据
- 八维催化扫描的搜索结果

详细全部进 MD 文件。

### 8.2 上限保护

- token 用量 60% → 主动启动归档（写当前状态.md + 巡盘日志.md）
- token 用量 70% → 收尾退出，提示用户"建议新开 session 继续"
- 单轮 token 产出 > 800 → 强制截断转 MD

### 8.3 sub-agent 落盘策略

详细分析（如八维催化、归因复盘）调用 sub-agent 完成 → sub-agent 写完 MD 退出 → 主线程只接收"已写入 X.md"摘要。

> 注意：当前 Search subagent 是只读的，写文件需主线程 SearchReplace/Write。所以"sub-agent 落盘"实际是**主线程一次性发起多个并行 Write/SearchReplace 操作**实现"落盘不阻塞思考"。

## 九、收盘归档流程（15:00 后）

```
□ 1. 拉收盘 live quote 持仓 3 只 → 锁定收盘价
□ 2. 写当日 portfolio.md 最终版（交易记录 + 持仓 + 现金 + 总资产 + 当日盈亏）
□ 3. 等收盘后 limit-up 数据可用 → 调 astock query limit list 拉今日全部涨停
□ 4. 写 daily/YYYY-MM/DD/收盘复盘.md
   - 今日各预期方向实际表现 vs 盘前判断
   - 盘中决策回顾：买/卖/加仓/止损 → 是对是错？
   - 盘中感知复盘：发现了什么？遗漏了什么？
   - 经验教训：≥2 条写入 lessons/learned.md
□ 5. 更新 expectations/tracker.md：预期阶段调整
□ 6. 写 daily/YYYY-MM/DD/次日预案.md → 滚到次日盘前分析的种子
```

## 十、与现有规则的关系

### 10.1 复用而非新增

| 现有文件 | 真实看盘如何使用 |
|---|---|
| `system/trading-system.md` | **唯一规则源头**：三维确认 §2.1 / L038 路径B §零之二 / R8 §2.1 / 八维催化 §三盘前 / 纪律红线 §五 全部直接适用 |
| `system/templates.md` | **模拟看盘专用执行模板，真实看盘不复用**（避免事后回放节奏污染盘中实战） |
| `expectations/tracker.md` | 启动序列读取，盘中观察期间不写（避免污染），收盘归档时统一更新 |
| `account/portfolio.md` | 实时更新（每笔成交 + 节点快照） |
| `lessons/learned.md` | 收盘复盘补充 |

### 10.2 唯一新增的概念

- **轮次（round）**：单次"拉数据→思考→落盘"循环
- **关注点（focus）**：一轮聚焦的 1 个观察对象（6 类轮转池）
- **思考链路.md**：每笔决策前的强制留证文档
- **当前状态.md**：实时滚动的"AI 在干啥"快照
