# 交易系统：预期驱动交易法则 v3.10

> 预期驱动交易法则：围绕预期做交易，资金确认决定能不能做。不猜、不赌、不扛。低频，但确定。
> v3.10 核心升级：盘前催化扫描从泛关键词升级为产业链级纵深搜索（八维覆盖+向上游/中游/下游拆分），新增雪球（xueqiu.com）作为必搜本土催化来源，消除"只有一个词就结束"导致的上游材料/海外基建/细分涨价等催化漏扫。
> v3.9 核心升级：引入预期追踪面板（expectations/tracker.md），将预期发现从反应式（消息出现后才形成预期）升级为前置式（提前识别+预研标的，盘中只等资金确认）。</new_str>

---

## 零、核心原则

**预期 = 市场资金正在投票的方向。**

围绕预期做交易，不是量化公式，是投资者的思维框架。形态只是确认预期的载体。每一个数值都是感知信号，不是机械触发条件。

**核心逻辑**:
- **预期确认 = 买**：市场形成新预期 + 资金完成确认（三维确认）
- **预期兑现/失效 = 卖**：本轮故事讲完 或 故事被证伪

**系统原则**:
- 不猜、不赌、不扛
- 低频，但确定
- 预期不问出处，确认只看资金
- 资金认可就是最好的确认力——一个方向有增量资金在进场，它就有承接力

## 零之二、预期发现与追踪机制（v3.9新增）

> **核心理念**：盘前把研究做透，盘中只等资金扣扳机。
> **持久化文件**：`expectations/tracker.md`

### 为什么需要预期追踪

旧模式（反应式）：`隔夜消息出现 → 盘前扫描 → 形成预期 → 盘中等三维确认 → 买入`
- 问题：预期发现与买入决策在同一日内完成。等"发现预期→确认→执行"跑完，股价已走高。

新模式（前置式）：`持续信息收集 → 预期追踪面板 → 提前预研标的 → 盘中等资金确认 → 买入`
- 优势：预期提前识别，标的提前研究，盘中唯一要做的事就是确认资金进场。

### 预期发现的双路径

| 路径 | 时机 | 触发条件 | 处理方式 |
|------|------|---------|---------|
| **路径A：盘前前置** | 盘前信息收集（每日） | 产业数据/政策/业绩/事件等催化信号出现 | 加入 tracker → 预研核心标的 → 持续跟踪锚点 → 等资金确认 |
| **路径B：盘中感知** | 盘中实时（L038） | 某方向多只涨停，不在盘前预案中（有先行信号=延续性更强，无先行信号=当日催化驱动，同样有效） | 15分钟用统一框架评估 → 确认后加入 tracker → 条件允许则买入 |

### 统一预期判断框架

> 盘前和盘中共用同一套判断标准，不分彼此。

判断一个方向是否构成有效预期，必须回答四个问题：

1. **是否有具体锚点？** — 产业数据/政策文件/业绩趋势/事件节点，不能是"感觉要涨"
2. **锚点是否可追踪？** — 有没有客观数据可以持续验证（期货价格/行业出货量/政策节点等）
3. **确认信号是否清晰？** — 什么市场行为出现时 = 可以买（如"板块≥3涨停+龙头封板"）
4. **失效信号是否明确？** — 什么条件出现时 = 预期死了（如"锚点数据破位/板块连续2天无涨停"）

四个问题都能回答 → 加入活跃预期。任一个答不上 → 放入观察列表，继续收集信息。

### 预期生命周期与 tracker 更新规则

```
出现期 → 确认期 → 加速期 → 兑现期 → 结束期
  ↑         ↑         ↑
 tracker   tracker   持有      走人     归档
 记录      预研标的
```

| 更新时机 | 操作内容 |
|---------|---------|
| **每日盘前** | ①更新所有活跃预期的关键锚点最新数据；②扫描新催化，识别新预期方向；③标记"接近确认"的预期 |
| **每日盘后** | ①根据当日市场表现更新预期阶段（确认→加速/兑现→结束等）；②盘中感知发现的新方向补充入 tracker |

### 盘中只等资金确认

盘前已完成：预期识别 + 标的预研 + 确认/失效信号定义。
盘中只需监控：预研标的的资金确认信号（三维确认中的"资金确认"+部分"价格确认"）。
- 资金确认触发 → 买入预研的核心标的
- 资金确认未触发 → 继续观察，不买
- 盘中发现新方向 → 用统一判断框架快速评估 → 达标则执行

# 第一部分：判断标准

> 本部分只提供决策所需的判断结果，不涉及任何买卖决策

## 一、预期阶段判断

**只回答：当前预期处于哪个阶段？**

### 阶段流程图

```
出现期 → 确认期 → 加速期 → 兑现期 → 结束期
  ↑          ↑          ↑
 可参与    可参与     持有        走人      不参与
```

| 阶段 | 含义 | 判断标准 |
|------|------|---------|
| **出现期** | 新预期刚出现，板块刚开始异动 | 新催化出现，板块首次爆发(≥5只涨停) |
| **确认期** | 分歧后资金重新选择，板块效应形成 | 前几天炸板/断板/回调，今天重新走强 |
| **加速期** | 预期持续验证，股价加速上涨 | 龙头持续走强，梯队完整，预期依据仍在验证 |
| **兑现期** | 业绩/事件公布，本轮定价完成 | 利好正式公告，产业数据见顶 |
| **结束期** | 预期被完全消化 | 龙头A杀，板块联动消失，预期依据被推翻 |

### 分歧 ≠ 结束

分歧是确认期内的自然阶段。判断方法：

| | 分歧（确认期内） | 结束（结束期） |
|---|---|---|
| 本质 | 筹码交换，资金在"要不要继续"上犹豫 | 资金已经放弃，在离场 |
| 龙头表现 | 震荡、断板但未大跌 | 大跌、A杀 |
| 板块联动 | 部分跟风回落但核心还在 | 全面溃散 |
| 操作意义 | **观察窗口**：看能否扛住分歧 | **空仓窗口**：等待新预期出现 |

**判断锚点**：预期依据还在被验证 → 分歧，等再确认。预期依据开始被否定 → 结束，走人。

**实战验证**：3/26看起来像退潮(超4400跌、涨停39)，但电力龙头华电辽能断板仅跌0.90% → 分歧。锂电分歧后重新确认(4连板+8只涨停)。简单判定退潮→空仓，错过了锂电再确认买点。

### 预期类型识别

**目的：帮助你在买入前定义「兑现标志」和「失效标志」（买前三件事的第2、3条）**

| 类型 | 退出信号特征 | 案例 |
|------|------------|------|
| **持续数据型** | 月频或更高频率量化数据可追踪，数据见顶/破位即退出 | AI算力（光模块出货量/云厂商资本开支）、锂电（碳酸锂期货） |
| **事件节点型** | 明确的一次性事件节点，事件兑现/取消即退出 | 商业航天（发射/组网节点）、个股业绩（财报落地） |
| **实时感知型** | 无客观外部数据，依赖龙头行为/板块联动实时判断 | 纯连板炒作、情绪高潮 |

**使用方法**：
- 识别类型 → 在买前三件事里写清楚具体的兑现/失效条件
- 类型不决定仓位，仓位由买点类型决定（见2.2）
- 同一只股票在不同阶段可能属于不同类型（如德明利季报=事件节点型，存储景气周期=持续数据型）

# 第二部分：买卖决策

> 两种触发路径，进入同一条决策链：
> - **路径1（预案触发）**：盘前已识别方向 → 盘中等确认触发 → 进入决策链
> - **路径2（盘中发现）**：盘中发现异动 → 快速评估（详见第四节）→ 确认有效后进入决策链

## 二、买卖决策

### 2.1 进场前提

**只回答：什么情况下才有资格买？**

#### 前提一：市场形成新预期

- 出现新的叙事、新的催化或新的可验证点
- 旧故事没有更新、没有增量信息 = 不构成新的买入理由
- 每次评估必问：**这个预期的确认信号是什么？**

#### 前提二：资金完成确认（三维确认）

1. **资金确认** — 资金真金白银地在投票（**以盘中可观察为准**：联动、量价、封板与承接等）
   - 板块内多股联动（不是孤票）
   - 成交量变化（注意：不是看绝对值，是看相对于该股/板块日常水平的偏离）
   - **龙虎榜**（盘后披露）：**不参与**当日盘中是否「已确认」的判断，仅作**盘后复盘**与**次日预案**参考，滞后一天属正常
   - **⚡ 概念去噪三步法（v3.7新增）**：
     - **第一步：个股预期归因** — 每只涨停股必须思考「这只股为什么涨停？实际催化是什么？」，而非简单看它挂了哪些概念标签。一只股可能挂了华为+半导体+5G三个标签，但实际驱动它涨停的可能只是半导体周期反转
     - **第二步：主驱动聚合** — 按归因结果将涨停股归入其主驱动方向，每只股只计入一个方向。消除「同一只股被多个概念重复计数」导致的方向膨胀
     - **第三步：正宗龙头验证** — 判断一个方向是否真正有资金确认，不看概念标签计数，看该方向公认的正宗龙头是否响应。正宗龙头不响应=方向不成立，不管标签涨停数多高
     - **4/27教训**：华为概念标签11只涨停，看似「最大方向」，但逐只归因后发现全是蹭概念（PCB/OLED/半导体各自的逻辑），正宗华为龙头（拓维信息等）很弱 → 华为方向资金面实际不达标

2. **价格确认** — 价格行为验证了预期
   - 突破关键位置（前高、平台、均线）
   - 涨停板封住（最强确认）
   - 半路放量突破（中等确认）
   - 回踩关键位企稳（低吸确认）

3. **预期依据** — 预期背后的逻辑在被验证
   - 产业周期类：相关商品期货/排产数据/价格指数在验证逻辑
   - 成长产业类：订单数据/出货量/资本开支/业绩增速在验证逻辑
   - 政策事件类：政策文件/投资规模/落地节点在验证逻辑
   - 个股业绩类：财报数据/业绩预告/公告事件在验证逻辑

**三个维度中，预期依据常被漏看：** 许多人只看量价。当你的**核心预期**要靠某类数据来验证时，这类数据若与故事**反向**，就不能只靠图形说「已经确认」——例如产业逻辑说碳酸锂要涨，但期货价格在跌，则无论K线多好看，**预期依据这一维都未对齐**，不算真正确认。

**缺一则不买**：只有逻辑没有资金认 = 空气；只有异动没有预期锚点 = 噪音。

#### 买入前必须锁定的三件事（强制）

在执行任何买入操作前，必须明确回答并记录以下三个问题：

1. **预期是什么？** — 具体事件/数据/阶段（不能是"感觉要涨"）
2. **预期兑现的标志是什么？** — 什么情况下故事讲完了，该走
3. **预期失效的标志是什么？** — 什么情况下故事被证伪了，该走

**买入前锁定，买入后不得修改。** 之后所有持仓决策只对照这三件事评估——不看龙头换没换，不看涨了多少，不看市场整体。

缺少这三件事的定义 = 预期不清晰 = 不执行买入。

#### 关于市场整体环境

系统不做"市场整体好不好"的前置判断。原因：
- 一个板块退潮时，另一个板块可能正在走主升（4/2油气退潮但医药主升）
- 市场整体涨跌数、涨停数是结果不是条件——某个方向资金确认了，它自然就承接得住
- **资金的确认力是板块级的，不是市场级的**

唯一例外：**系统性恐慌**（千股跌停、流动性危机）——盘中自然能感知到，不需要独立门槛。

### 2.2 买入决策

**只回答：确认能买之后，买什么类型、买多少、买哪只、什么时候下单？**

#### 买点类型与仓位

**仓位大小 = 当前时刻预期被资金认可的程度**

| 买点类型 | 出现时机 | 初始仓位 | 风险 | 实例 |
|---------|---------|---------|------|------|
| **确认买点**（最安全） | 分歧后资金重新入场，预期经过考验 | 3成 | 最低 | 3/27锂电 |
| **首板买点**（要快） | 新催化首板，资金第一次试探性确认 | 1-1.5成 | 中等 | 4/1创新药 |
| **回调买点**（要准） | 预期已验证，上涨途中首次回调 | 加到3成 | 较高 | 锂电主升回调 |

**说明**：
- 每个独立主题最多3成，是为了容纳意外，不是表达信心高低
- 三维确认满足才能进，不因市场整体涨跌打折

#### 如何快速判断买点类型

- **确认买点** → 看"有没有吵过架"：前几天炸板/断板/回调，今天重新走强 = 确认买点
- **首板买点** → 看"是不是第一次"：新催化+首板爆发+之前没涨过 = 首板买点
- **回调买点** → 看"趋势还在不在"：已经涨了一波+首次回调+预期依据未破 = 回调买点
- **都不是** → 不买，等

#### 买哪只：龙头识别

主题确认后，**只买一只——龙头**。龙头的判断标准：

| 特征 | 说明 | 反例（这些不是龙头） |
|------|------|------|
| **领涨性** | 板块内率先发动，带动其他个股跟涨 | 等其他股涨了才跟上的补涨股 |
| **主动性** | 板块内涨幅/涨速超越同类，有独立上涨动能 | 板块整体涨时涨幅垫底，板块内无超额表现 |
| **高位性** | 本轮行情中处于板块内相对高位 | 低位横盘、本轮行情落后补涨的 |

**关于大盘共振**：大盘上涨 + 板块上涨 = 资金在多个层面同时做多，是**更强的资金确认信号**，不是被动跟涨。龙头的主动性参照系是**板块内其他股票**，而非大盘。

龙头买不进（一字板排不到），就不参与本次机会，等下一次确认信号。

#### 买点执行时机

**原则：资金确认在哪里发生，就在哪里买。不等、不提前、不追。**

| 确认形式 | 买入时机 |
|---------|---------|
| 竞价阶段已显示强势（强势开盘 + 板块联动） | 竞价/开盘即入 |
| 盘中半路放量突破 / 联动走强 | 突破时买入，不等收盘确认 |
| 只有涨停封板才能完成确认（如确认龙头地位） | 涨停排板买入 |
| 一字板（全天无法以合理价格买入） | 放弃，排不到板就不参与本次机会 |

#### 买点判断流程

```
第一步：有没有新预期？三维确认满足了吗？（见2.1）
  → 缺任何一维 → 不买，等
  → 齐全 → 第二步
第二步：是什么买点类型？
  → 确认买点 → 3成
  → 首板买点 → 1-1.5成
  → 回调买点 → 加到3成
  → 都不是 → 不买，等
```

#### 核心原则

1. **确认买点是首选**——经过分歧测试的确认最可靠，优先等确认买点
2. **首板买点要快**——出现期首板稍纵即逝，但必须三维确认齐全才能上
3. **回调买点要准**——回调可能是结束期的开始，必须确认预期依据未破才能进
4. **三维确认是底线**——必须资金+价格+预期依据齐全，不可缺少
5. **兑现期和结束期不买**——本轮故事讲完了，等下一轮
6. **加速期不设买点**——加速期才发现这个方向，是盘前覆盖不足，不追入

### 2.3 持仓管理

**只回答：买完之后怎么管？**

#### 建仓与加减仓规则

- **首次建仓**：50-70%目标仓位
- **加仓条件**：预期依据继续验证 + 价格创新高
- **减仓**：部分兑现减30-50%，完全兑现清仓

#### 龙头切换：回归原始预期

老龙头断板、新股接力时，**不问"龙头换没换"，只问"买入时的预期"**：

| 买入时的预期 | 老龙头断板时怎么判断 |
|-------------|-------------------|
| 龙头加速/情绪高潮本身就是预期 | 龙头力竭 = 预期兑现 → 走 |
| 板块/产业级预期（如业绩落地、产业数据持续验证） | 龙头调整但催化未兑现 → 预期仍在，减仓或持有均可 |
| 确认期再次走强 | 问：板块整体预期还在吗？联动还在吗？在则持有，否则走 |

**判断锚点**：回到买入前锁定的三件事——预期是什么？兑现了吗？失效了吗？龙头是观察预期状态的窗口，不是持仓的理由。

#### 卖出后的新信号处理

卖出后如果出现更强的资金确认信号，**重新评估是否形成了新的独立预期**，而不是追悔卖早了：

- 新信号代表新的预期内容（不是原来预期的延续）→ 按新预期重新走一遍买入流程
- 重新买入必须重新定义三件事（新的兑现标志和失效标志）
- 原来的卖出是正确的，新的买入是独立决策，两者不挂钩

**实例**：3-11卖出德明利（季报落地=预期兑现，正确）→ 3-13大盘跌0.8%但德明利涨停 = 市场在验证新预期（存储景气周期），可以重新评估买入机会，这不是"卖早了"，是两笔独立的交易。

### 2.4 卖出规则

**只回答：什么情况下卖？**

#### 止损原则：纯预期止损

系统采用**纯预期止损**，不设价格止损线：

- **预期依据仍在验证** → 持有，无论价格涨跌多少
- **非预期原因暴跌**（市场恐慌、外部利空），但预期依据未被否定 → 持有
- **预期依据被否定 / 预期兑现 / 阶段进入结束期** → 按下方卖出规则执行

**为什么不设价格止损：** 买入门槛（三维确认 + 买前锁定三件事）已经是最重要的风控线。价格止损会在分歧期将仓位洗出去，破坏系统逻辑。入场越严格，预期止损越可靠。

**系统性恐慌例外**（千股跌停、流动性危机）：所有板块承接力消失，此时预期本身的兑现/失效判断同样适用，盘中感知自然处理。

#### 卖出的底层逻辑

**每次评估必问：什么情况会被证伪？**
- 产业趋势：价格/数据逆转
- 叙事/消息：分歧后资金不回来了
- 任何方向：市场放弃了这个方向

**证伪就是系统的卖点。**

#### 统一规则

- **预期在**（逻辑仍成立、未被充分定价）：持有，按确定性调节仓位
- **本轮预期兑现**（业绩/事件/数据把故事讲完）：**走**，不因"下一季可能更好"赖在仓位里
- **兑现之后**：空仓等待，新预期形成且资金确认后再进场

#### 预期兑现信号（本轮故事讲完了）

- 利好正式公告（利好出尽）
- 产业数据见顶（如碳酸锂价格开始回落且持续）
- 预期逻辑被市场充分定价（后续无增量资金）
- 所有能讲的逻辑都被讲完了，没有新的增量信息

**操作**：本轮兑现即走

#### 预期失效信号（故事被证伪了）

- 市场选择了另一个方向（新题材崛起，老题材被抽血）
- 龙头股走弱（断板后持续大跌，不是震荡）
- 板块联动性消失（跟风股不跟了，只剩龙头孤票）
- 预期依据被新事件推翻（政策转向、行业利空、供需格局逆转）
- **产业数据破位**（如碳酸锂期货跌破关键支撑）

**操作**：立即走，不分批

#### 卖出判断流程

```
第一步：当前预期处于哪个阶段？
  → 兑现期/结束期 → 立即卖
第二步：是否有预期失效信号？
  → 有 → 卖
第三步：资金确认还在吗？
  → 板块联动消失 + 资金在撤 → 减仓或清仓
  → 板块联动还在 + 价格未破位 → 持有观察
```

#### 容易犯的错：把分歧当失效

分歧时龙头可能断板、换手率升高、跟风回落——这看起来像失效，但实际上可能是再确认前的正常筹码交换。

**判断方法**：回到确认信号。预期依据还在被验证 → 分歧，等再确认。预期依据开始被否定 → 失效，走人。

#### 容易犯的错：盘前红线脱离买入预期

买入时锚的是产业预期（如"存储超级周期"），但后续盘前分析中临时设定的卖出红线可能盯的是价格形态（如"破349.20"）——两条逻辑不在一根链上。

**判断方法**：盘前分析新增的任何卖出条件，必须能回答：**"这个条件和买入时定义的预期是什么关系？"** 回答不上来 = 不能用。

| 买入预期 | 可以新增的条件 | 不能新增的条件 |
|---------|-------------|-------------|
| 存储超级周期 | 存储现货价跌破X（直接验证预期） | 破349.20（纯价格形态，和预期无关） |
| 存储超级周期 | 存储板块连续2天无涨停（资金不认了） | 巨量上影+铁底再破（技术形态判断） |
| 碳酸锂涨价周期 | 碳酸锂期货<191000（产业数据锚破位） | 天齐跌破XX元（纯价格线） |

> **5/13实战教训**：兆易创新买入锚的是"存储超级周期+美光新高"，5/13盘前却设了349.20红线（依据巨量上影的Day 2兑现模式）。当天存储板块午后暴动（德明利/雅克/斯达/工业富联涨停）——预期不仅未结束，反而在强化。但349.20已在开盘触发清仓，买卖依据不一致导致了错误卖出。

### 2.5 组合规则

**只回答：多个机会并存时，怎么管总仓位？**

#### 同一主题不叠仓

同一个预期主题，无论它同时触发了多少观察角度（产业数据 + 板块联动 + 个股涨停），都只算**一个机会，一次定仓（3成）**：

```
锂电涨价周期（主题A）
  └─ 锂电板块联动（同一主题的信号）
       └─ 天齐锂业涨停（同一主题的执行标的）
```

同一主题 → 3成，不叠加。

#### 多主题并发：各自独立定仓

不同主题是独立的机会，各自定仓（最多3成），互不影响，总仓位自然叠加：

| 场景 | 处理 |
|------|------|
| 锂电 + 创新药同时确认 | 各自最多3成 → 总仓位最多6成 |
| 任意两个独立主题同时确认 | 各自最多3成 → 总仓位最多6成 |
| 已有仓位时出现新机会 | 评估现有持仓预期状态——预期已兑现/失效则按卖出规则减仓，腾出资金参与新机会 |

**核心原则：仓位管理是分担风险，不是逃避机会。** 市场资金确认了预期，就买入，不因总仓位高低打折。

#### 产业链相关性约束（v3.10新增·6/18实战教训）

「多主题并发」隐含一个前提：**主题之间相互独立**。但不同主题若同属一个大产业链（如 AI 硬件链下的 MLCC / PCB / 光通信），它们的涨跌高度相关——一旦该产业链整体退潮，多仓同时承压，组合分散失效。

**规则：不同主题但属同一大产业链，合并计入"链条总仓位"。链条总仓位超过 6 成时，不再加仓该链条内任何标的。**

| 判定 | 处理 |
|------|------|
| 主题分属不同大产业链（如锂电 + 创新药） | 视为独立·各自最多3成·总仓位最多6成 |
| 主题同属一个大产业链（如 MLCC + PCB + 光通信 均属 AI 硬件链） | **合并计链条仓位**·该链条总仓位 >6 成 → 不再加仓链条内任何标的 |
| 链条内出现完全独立的催化主线（与既有持仓催化源不同） | 可破例加仓1成·须盘前/盘中写明"独立催化源"理由 |

> **6/18 实战教训**：三持仓（亨通光通信 + 沪电PCB + 博迁MLCC）全压 AI 硬件链，盘中博迁涨停触发加仓冲动，被"R8集中度"拦下——决策对但规则名用错（R8实为买前三件事锁定）。本条款正式将"组合相关性"纳入系统，填补该 gap。判定"同属一链"的核心标准：**是否存在共同的宏观催化源**（AI算力投资 / 商品超级周期 / 政策补贴等）。


#### 单主题只做核心

同一主题内，**只买一只股票（龙头）**，仓位集中：
- 低频交易，只做核心，不分散买跟风股
- 龙头买不进（一字板排不到），就不参与本次机会，等下一次确认信号

## 三、每日流程

### 盘前（9:00 前）

- **全市场催化扫描（催化→方向，不是方向→催化）**：
  1. **先无预设扫描催化源**：过去48小时有哪些新发布的研报、产业数据、政策文件、重大公告？（不带方向预设地扫）
  2. **再对活跃产业链做纵深搜索（🔥v3.10新增）**：从 tracker 提取当前活跃预期方向，每个方向拆成「上游材料+中游制造+下游需求」各自搜索产业链新闻（涨价/缺货/扩产/订单/海外基建等），每个方向至少3个独立query
  3. **雪球情报**（🔥v3.10新增必搜）：搜索 xueqiu.com/k?q=[活跃方向关键词]，获取A股本土催化+散户共识+博主分析
  4. 再映射方向：每个催化指向哪个方向/子方向？有没有指向当前未覆盖的全新方向？
  5. 最后评估：对每个发现的方向做三维确认预评估
  - ❌ 错误做法1："我在看CCL和储能，有什么新催化？"——只能看到已知方向，框架外的方向全部漏掉
  - ❌ 错误做法2：搜一个"半导体"就结束——漏掉"住友电木封装材料涨价""氢氟化酸涨价""硫供应锐减"等产业链上游催化
  - ✅ 正确做法："大摩发了什么报告？财联社有什么新数据？半导体封装材料有什么动态？氢氟化酸价格怎么样？雪球上在讨论什么半导体催化？"
  - 4/13教训：大摩4/10发布锂供需报告、人民日报3/16发"锂市超级周期"——这些催化盘前可查到，但因为用"方向→催化"扫描，锂矿方向完全没进入视野
  - 5/14教训：盘前分析漏掉"住友电木封装材料涨价""氢氟化酸涨价""硫供应锐减""加拿大万亿美元电网投资""中芯国际Q2收入"——因仅用泛方向关键词搜索，未做产业链纵深搜索+雪球互补
- 梳理今日候选预期方向（产业 > 政策 > 个股 > 情绪），**注意子方向级拆分**（如"储能"要拆为"锂矿/电网/电池/光伏"分别评估）
- 对每个方向回答两个问题：确认信号是什么？（资金+价格+预期依据）什么情况下会证伪？
- **对每个方向预设"改主意条件"**：什么信号出现时，我会放弃/改变对某个方向的判断？
- **预设"盘中新方向关注条件"**：什么情况下我会关注一个盘前未覆盖的新方向？（如：创新药板块3只以上涨停+有权重股异动）
- 制定交易预案：如果A预期被确认→买X，如果B预期被确认→买Y
- 预设每个方向的**预期失效条件**（而非价格止损线）：如果出现X情况，我立刻离场
- **周五持仓管理**（仅限持仓评估，不影响新买入决策）：如果现有持仓处于高位（如连续板），评估周末可能出现的消息对持仓预期的影响。风险可控→继续持有；风险较大→可减仓至舒适水平。周五对新方向买入无任何额外限制，三维确认齐全=执行。

### 盘中（9:30 - 15:00）

- 执行计划内的交易。如有计划外异动，按第四节「盘中异动处理」流程评估
- 每笔交易前过检查清单：预期是什么？三维确认了吗（资金+价格+预期依据）？确定性有多高？仓位匹配吗？
- 注意感知信号：换手率、成交量、板块联动的变化
- 感知信号出现时 → 回到核心问题：预期状态变了吗？阶段判断还对吗？
- **盘中感知触发时**：按第四节「触发后的快速评估」流程
- **记录盘中发现**：即使不操作，也要记录盘中的新预期/新异动，纳入盘后复盘

### 盘后（15:00 后）

- 复盘今日交易：每笔交易的预期是什么？确认/兑现/失效了吗？
- 更新各方向预期阶段判断：从哪个阶段进入了哪个阶段？
- 记录感知信号的准确度：哪些信号提前预示了预期变化？
- **复盘盘中感知**：今天有没有遗漏的盘中异动？盘中感知的评估是否准确？
- **覆盖诊断**：今天有没有在加速期才发现某个方向？如果有，追问它的出现期/确认期在哪里，为什么盘前没有扫到——这是下次盘前扫描需要改进的地方，不是加速期追入的理由
- 调整明日计划
- **更新虚拟账户**：记录今日交易、持仓、盈亏

## 四、盘中异动处理

**只回答：出现意外怎么办？**

### 为什么需要盘中感知？

盘前预案是基于**昨天的信息**形成的。但市场每天都在变化——
- 可能出现盘前完全没预料到的新方向（3月27日的创新药）
- 可能出现盘前未预期到的个股异动（3月27日新能泰山一字板）
- 可能盘前的判断在开盘就被证伪（3月27日退潮预期被开盘数据推翻）

**盘中感知的目的不是推翻预案，而是发现预案没覆盖到的东西。**

### 三个触发条件

当以下任一情况出现时，从"执行预案"切换到"重新思考"：

| 触发 | 具体表现 | 实例 |
|------|---------|------|
| **意料外的板块异动** | 某方向突然出现2-3只以上涨停/一字板，且该方向不在盘前预案中 | 3月27日创新药板块多只20cm涨停，盘前完全未覆盖 |
| **确认信号突变** | 产业数据（期货价格）突破/跌破关键位，或突发政策/事件 | 碳酸锂期货单日涨6%突破16万；突发的产业政策 |
| **板块承接力突变** | 监控方向的资金确认信号在盘中发生质变 | 预案看好锂电，但盘中锂电龙头全部炸板+跟风全面回落+碳酸锂期货跳水 → 资金确认崩塌 |

### 触发后的快速评估（三个问题，每个<1分钟）

**1. 这是什么类型的预期？**

| 类型 | 优先级 | 持续性 | 示例 |
|------|--------|--------|------|
| 产业预期 | ⭐⭐⭐ | 长，退出信号清晰 | 碳酸锂涨价、创新药BD数据 |
| 政策预期 | ⭐⭐ | 中，看落地 | 算电协同政策、降息 |
| 情绪预期 | ⭐ | 短，退出信号最模糊 | 冰点修复博反弹 |

**2. 退出信号是否清晰？**
- 清晰（产业数据可跟踪、事件有时间节点）→ 值得认真评估，纳入决策
- 模糊（纯跟风、无具体验证手段）→ 观望为主，可能是噪音

**3. 和我当前的计划什么关系？**

| 关系 | 信号清晰 | 信号模糊 |
|------|------|------|
| **加固我的方向** | 继续执行，可考虑加仓 | 继续执行 |
| **矛盾我的方向** | ⚠️ 暂停，重新评估预期强度 | 保持原计划，可能是噪音 |
| **无关** | 记录下来，纳入明天盘前分析 | 忽略 |

### 盘中感知的核心纪律

1. **不是每个异动都需要反应。** 大部分盘中波动是噪音。只有触发了上述三个条件之一，才值得花时间评估。
2. **快速评估，不深度研究。** 盘中的职责是感知，不是研究。发现新方向 → 15分钟内完成三维确认评估 → 给出明确结论（买/不买/等什么条件），不能只写"观察"。
3. **发现 ≠ 立刻行动，但确认 = 必须行动。** 盘中发现新预期后，第一反应是快速评估三维确认。如果三维确认不齐全→记录，下一天再研究。**但如果三维确认已经齐全+退出信号清晰+有买入窗口→系统允许盘中执行，不能因为"盘前没覆盖"就放弃。盘前遗漏不是盘中不执行的合法理由。**
4. **预案优先，但不排斥盘中确认。** 如果盘中新预期和盘前预案矛盾，先确认预案的假设是否已被证伪。只有证伪了才调整，不是看到新的就想上。但如果盘中新方向和预案不矛盾（独立主题），且三维确认齐全，应该执行。

## 五、纪律红线

**只回答：绝对不能做什么？**

1. **没有明确预期，不买。** 随手单 = 没有预期的单 = 亏损的根源。
2. **三维确认缺一维，不买。** 看到预期方向 ≠ 资金已经确认，等确认信号。资金、价格、预期依据三个维度都要看。
3. **预期失效，必走。** 不扛单，不抱幻想，不"再看看"。
4. **预期兑现，必走。** 不贪最后一段，不因为涨了就觉得还能涨。
5. **不因市场整体数据打折仓位。** 一个方向资金确认了，它就有承接力。不看大盘涨停数多少来决定买不买——三维确认是该方向自己的事，不是市场整体的事。
6. **不机械执行。** 任何指标都只是感知信号，回到核心问题：预期确认了吗？兑现了吗？失效了吗？
7. **盘中感知不是盘中追涨。** 发现新预期 ≠ 立刻买。评估、验证、等确认。
8. **买前必须定义三件事。** 预期是什么、兑现标志、失效标志——买入前锁定，买入后不改。没有定义这三件事，不执行买入。
9. **信息不足，默认不操作。** 三维确认中任何一维信息不清晰，标记为观察，等信息完整再评估。不在信息模糊时强行决策。注意：信息不足指维度数据缺失，不是没找到完美数据。三维确认所需数据均可从现有数据源获取=信息充足，必须行动。

## 六、感知信号使用

**只回答：看到指标怎么思考？**

以下指标不是机械触发条件，是**提醒你注意的感知信号**。看到信号后，思考方向是：**这对当前的预期意味着什么？**

### 涨停数 / 封板率 / 跌停数

- **不是**：涨停<30就不买，或涨停>100就高潮
- **而是**：关注**你监控方向**的板块级数据——这个方向内部的联动是在增强还是在减弱？板块内涨停增加+封板率上升=资金确认在加强。全局涨跌数是参考，不是门槛

### 换手率
- **不是**：换手率>15%就卖
- **而是**：换手率显著偏离该股近期正常水平时，说明筹码交换在加剧——回到核心问题：这个预期是被确认了还是被兑现了？

### 成交额
- **不是**：缩量就危险
- **而是**：关注成交额变化和价格方向的**背离**——缩量上涨说明增量资金不足，放量下跌说明抛压加重

### 连板高度 / 晋级率
- **不是**：连板高度降低就是退潮
- **而是**：连板高度降低 + 晋级率下降 = 高低位切换中，观察新低位核心能否接力

### 产业数据指标
- 碳酸锂期货、原油、铜等大宗价格
- 行业排产数据、PMI、社融等宏观指标
- **核心用法**：与板块走势做交叉验证。期货涨+板块涨=预期确认；期货跌+板块涨=脱离基本面炒作，警惕

### 倒计时催化效应（v3.10新增·6/16实战教训）

- **不是**：机械套用历史Day2规律判断延续性
- **而是**：判断Day2延续性时，关键变量不是"历史Day2规律"，而是"Day2是否有Day1时没有的独立催化倒计时"
- **倒计时催化**：即将到期的产业催化事件（涨价日/政策日/数据发布日）会打破历史规律，显著提升延续概率
- **实例**：MLCC方向此前两次Day1爆发后Day2均快速分化，但6/16有"村田7/1第三轮涨价10-40%倒计时2个交易日"——这个Day1时不存在的新变量打破了历史规律，6/16 MLCC+6.40%全市场第1
- **使用方法**：盘前分析必须检查活跃方向是否存在"即将到期的独立催化事件"，作为Day2延续性判断的核心变量

## 七、系统执行纪律

1. **系统说买就买，系统说卖就卖。** 不给自己加额外的门槛或条件。三维确认齐全=买点成立，不编"再等等"、"不回落就不买"。
2. **不确定性→可持续的确定性。** 系统无法保证每笔交易都赚钱，但严格执行可以拉开时间看到复利。单笔亏损是系统的成本，不是执行错误。
3. **不在已确认的买点上犹豫。** 犹豫=给自己加条件=脱离系统=变成随意交易。
4. **复盘时的判断标准**：这笔操作是否符合系统规则？而不是这笔操作是否赚钱。赚钱但不符合系统=错误；亏钱但符合系统=正确。
5. **系统迭代只能盘后做，不能盘中做。** 盘中严格按盘前预案执行。如果有新发现，记录下来，盘后再迭代系统。

## 八、系统绩效评估

**核心指标只有一个：系统执行合规率**

### 合规检查标准

每笔交易（包括未操作的决策）完成后，记录以下检查：

| 检查项 | 是/否 |
|--------|------|
| 买入前是否定义了预期三件事（预期/兑现标志/失效标志）？ | |
| 买入时三维确认是否齐全（资金+价格+预期依据）？ | |
| 仓位是否符合买点类型规则（首板≤1.5成/确认=3成/回调=补到3成）？ | |
| 买点类型是否属于系统定义的三类之一？ | |
| 卖出是否由预期兑现/失效触发（而非价格止损或情绪）？ | |

**合规 = 以上所有项均为"是"**。只要有一项"否"，记为违规操作。

### 评估原则

- **赚钱但违规 = 错误**（侥幸，不可复制）
- **亏钱但合规 = 正确**（系统成本，可接受）
- **复盘标准**：这笔操作是否符合系统规则？而不是这笔操作是否赚钱

### 审查触发条件

| 触发事件 | 审查对象 | 处理方式 |
|---------|---------|---------|
| 连续3笔合规交易亏损 | 系统逻辑 | 审查规则本身是否有问题，考虑迭代系统 |
| 连续3笔违规操作 | 执行纪律 | 审查执行偏差原因，不修改系统规则 |
| 单笔违规且亏损 | 两者都查 | 优先修复执行纪律，再看是否需要补系统规则 |
