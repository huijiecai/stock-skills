# 买卖规则

> **边界**：本文件定义买卖决策规则和执行纪律。预期定义 → 核心框架.md。

---

## 一、买入门槛

### 1.0 前提零：预期已入库

- 买入方向必须已存在于 `research/expectations/` 中，且有对应预期文件
- 没有预期文件的方向 → 预期研究Mode A（→ operations/预期研究.md §二）
- 没有预期文件 = 不能买。这是确保买入前三件事（→ §1.3）已锁定

### 1.1 前提一：市场存在可验证的新预期

- 出现新的叙事、新的催化、或新的可验证点
- 旧故事没有更新、没有增量信息 = 不构成新的买入理由
- 违反 = 系统性错误

### 1.2 前提二：三维确认（定义→核心框架.md §2.3）

三维确认齐全 = 预期被市场验证，买入前提成立。**缺一 = 不买**，无例外。

### 1.3 前提三：锁定三件事

买入前必须明确回答并记录：

1. **预期是什么？** — 具体事件/数据/阶段（不能是"感觉要涨"）
2. **兑现标志是什么？** — 什么情况下故事讲完了（→核心框架.md §3.3 类型识别）
3. **失效标志是什么？** — 什么情况下故事被证伪了

**买前锁定，买后不改。** 之后所有持仓决策只对照这三件事评估。未定义 = 不执行。

## 二、买入执行

### 2.1 买点类型与仓位

仓位大小 = 当前时刻预期被资金认可的程度：

| 买点类型 | 出现时机 | 初始仓位 | 判断方法 |
|---------|---------|---------|---------|
| **确认买点**（最安全） | 分歧后资金重新入场，预期经过考验 | 3成 | 炸板/断板/回调后重新走强（含同日分歧修复） |
| **首板买点**（要快） | 新催化首板，资金第一次试探性确认 | 1-1.5成 | 新催化+首板爆发+本轮没涨过（上一轮已结束的不计） |
| **回调买点**（要准） | 预期已验证，上涨途中首次回调 | 加到3成 | 已涨一波+首次回调+预期依据未破 |

- 每个独立主题最多3成，是为了容纳意外，不是表达信心高低
- 都不是以上类型 → 不买，等
- 兑现期和结束期不设买点，加速期不设买点（加速期才发现=盘前覆盖不足）

### 2.2 标的选择

**前提：标的必须在预期研究的直接受益名单中（→ operations/预期研究.md A.2）。** 不在名单中的股票，不管价格多强，都不买。

龙头只能在方向归因完成后的**直接受益名单**内产生。方向未知时的强势股只能叫先导候选，不得提前指定为龙头。

受益名单内多只标的并存时，用以下特征排序选最强：

| 特征 | 说明 | 反例 |
|------|------|------|
| **领涨性** | 板块内率先发动，带动跟涨 | 等其他股涨了才跟上的补涨股 |
| **主动性** | 涨幅/涨速超越同类，有独立上涨动能 | 板块涨时垫底，板块内无超额 |
| **高位性** | 本轮行情中处于板块内相对高位 | 低位横盘、落后补涨的 |

龙头确认前必须先完成预期归因验证：根据搜到的具体预期列出关联股票，核心关联股成片同步上涨才说明归因正确。归因确认后，在直接受益标的中，最先发动、涨幅最强、成交最主动的是龙头；只有候选独自上涨则不确认龙头、不买。

**识别与执行隔离**：龙头一手金额超仓、无交易权限或封死不可成交，不得反向删除其龙头身份；只在执行阶段依次评估直接受益名单中的第二、第三名。

- 大盘共振（大盘涨+板块涨）是更强的资金确认信号
- **龙头一字板（无法排板买入）= 不参与本次机会**，等下一次
- 涨停封死（非一字板）→ 涨停排板买入（→ §2.3）
- 受益名单内排序第一的排不到板 → 评估第二、第三…。全部一字板 → 不参与

### 2.3 执行时机

原则：三维确认完成后立即进入§2.4账户级排序；排序和风险预算通过后当下执行。确认可能在竞价、半路或涨停时完成。

| 确认完成时刻 | 执行方式 |
|------------|---------|
| 竞价阶段三维已齐 | 竞价/开盘即入 |
| 盘中半路三维齐 | 当下买入 |
| 确认完成时龙头已涨停（非一字板） | 涨停排板买入 |
| 一字板（无法排板买入） | 放弃 |

### 2.4 系统确认 = 进入账户级排序

三维齐 + §2.1买点类型成立 + 退出条件清晰，只说明该机会**具备可交易资格**，先进入账户级排序，不等于账户必须同时持有所有合格机会。

同一轮或短时间内出现多个合格机会时，按以下顺序比较：

1. 预期新鲜度：是否有新增催化，而不是旧故事重复交易
2. 资金确认质量：直接受益股是否成片上涨，确认是否持续
3. 龙头质量：是否明确、主动、领先，而不是跟随补涨
4. 买点质量：分歧修复优先于一致加速
5. 账户风险：是否与现有持仓共享同一市场风险因子，执行后是否超限

- 排序靠前、账户风险预算允许、交易约束满足 → **必须执行**
- 同一批同时成立的机会最多执行排序前2名；第3名及以后继续观察，不因尚有现金而机械买入
- 排序落后或风险预算已满 → 合规不交易，记录排序结果和放弃代价
- 只有一个合格机会时，仍须先通过账户风险预算检查；通过后必须执行
- “必须行动”不能突破单主题、共同风险因子、T+1、交易权限和冷静期等硬约束

### 2.5 信息不足 = 默认不操作

- 信息不足 = 三维确认的**维度数据缺失**（如无法获取板块联动数据、无法验证预期依据）
- 不是没找到完美数据——三维数据均可获取 = 信息充足，应进入§2.4账户级排序
- 不确定是否充足 → 默认不操作，记录为"信息不足"

### 2.6 盘中感知 ≠ 追涨

盘中发现异动方向 → 用统一标准快速评估：有预期依据、有资金响应、有价格确认 → 达标则进入账户级排序。这不是追涨，是对盘中新预期的正常响应。区别在于：追涨是看到涨了才想买；盘中感知是看到资金确认后按规则评估并执行排序靠前的机会。

### 2.7 不因大盘打折仓位

三维确认满足且通过§2.4账户级排序 = 买点成立，不因主观大盘判断随意打折单笔目标仓位。

账户共同风险因子上限、冷静期和交易约束仍然优先；这不是“大盘打折”，而是账户级硬风控。

## 三、持仓管理

### 3.1 建仓与加减仓

- **首次建仓**：50-70%目标仓位
- **加仓条件**：预期依据继续验证 + 加仓时点独立满足§2.1中的一种买点类型 + 账户风险预算允许
- **价格创新高只属于价格确认，不能独立构成加仓买点**
- 一致加速阶段不加仓；没有新增催化时，优先等待首次回调后重新走强
- **减仓**：部分兑现减30-50%，完全兑现清仓

**A股整手执行约束**：

- 1手=100股；正常买入、加仓和减仓指令必须按整数手生成，禁止产生50股等不足1手的主动交易指令
- 百分比减仓先计算目标区间，再在区间内选择最接近目标比例的整数手数量
- 持仓仅1手时，30-50%的部分减仓不存在可成交数量；卖出条件成立则直接清仓1手
- 因送转、配股等原因已形成零股时，零股按实际交易规则一次性处理，不得用零股例外反向生成新的不足1手指令

**多主题并发约束**：

- 不同主题是独立机会，各自最多3成，总仓位自然叠加
- 已有仓位时出现新机会 → 与当前所有合格机会一起执行§2.4账户级排序
- 现有持仓没有卖出理由时，不为排序靠后的新机会强行腾仓

**共同风险因子约束**：

| 判定 | 处理 |
|------|------|
| 主题分属不同产业链（锂电+创新药） | 各自独立，各最多3成 |
| 主题业务不同但共享同一市场风险因子（如存储+PCB+CPO+MLCC共同受科技成长风险偏好驱动） | 合并计算风险因子仓位，最高6成 |
| 新交易会使共同风险因子超过6成 | 禁止买入或加仓，不设破例 |

- 市场风险因子按“资金是否会在同一次风格切换中同步撤退”判断，不只看产业链名称
- 每次买入和加仓前，必须写明该主题所属风险因子、当前合计仓位和交易后合计仓位
- 新规则生效时已经超过6成的存量仓位，不因超限本身强制卖出；禁止继续买入/加仓，并按§4卖出规则处理至回到上限内

### 3.2 龙头切换：回归原始预期

老龙头断板、新股接力时，**不问"龙头换没换"，只问买入时的预期**：

| 买入时的预期 | 老龙头断板时怎么判断 |
|-------------|-------------------|
| 龙头加速/情绪高潮本身就是预期 | 龙头力竭 = 预期兑现 → 走 |
| 板块/产业级预期 | 龙头调整但催化未兑现 → 预期仍在，减仓或持有 |
| 确认期再次走强 | 板块整体预期还在吗？联动还在吗？在则持有 |

判断锚点：回到买前锁定的三件事。龙头是观察预期状态的窗口，不是持仓的理由。

### 3.3 卖出后新信号：重新评估

卖出后方向再次走强，先区分上次从哪个出口离场：

- **出口A离场（预期兑现/结束/被否定）**：预期文件已结束或删除；必须有新催化，重新执行Mode A并重新定义三件事
- **出口B离场（交易确认失败）**：预期文件仍在观察；执行Mode B，原预期出现新的验证点且重新完成三维确认后，才可进入买点与账户级排序
- 出口B后的价格反弹不能直接重买；必须重新出现资金广度、龙头主动性和价格响应
- 原来的卖出是正确的，新的买入是独立决策；“已卖出”不是跳过评估的理由
- §1.1仍适用：没有新催化，也没有新的可验证点或重新确认，不构成买入理由

## 四、卖出规则

系统不设脱离预期与资金确认的单独价格止损。纯价格波动不能独立触发卖出，但产业预期仍成立也不代表必须继续持有：买入时的资金确认可能失败，交易可以退出而方向继续保留观察。

### 4.1 卖出判断双出口流程

这是唯一的卖出判断入口。每次必须同时检查“预期出口”和“交易确认出口”，两者相互独立：

```
第零步：T+1检查
  → 当日买入的股票：禁止卖出；完成评估并标记次日优先动作
  → 非当日买入：继续

出口A：预期退出
  → 兑现期/结束期，或预期依据被否定：清仓
  → 未触发：不代表必须持有，继续检查出口B

出口B：交易确认退出
  → 买入时的资金投票、价格响应和龙头主动性仍在：持有
  → 确认减弱：检查§4.3交易失效信号
  → ≥2个交易失效信号且资金撤退得到确认：减仓或清仓
  → <2个，或资金仍有承接：持有观察
```

- 预期退出意味着方向逻辑结束；交易确认退出只意味着本次交易失败，预期文件保留并降级观察
- 方向仍可能成立，但资金不再为本次交易提供承接；不得用“预期依据未否定”跳过出口B
- 分歧不是方向结束，但分歧中的持仓仍须检查买入确认是否已经消失

### 4.2 预期退出信号（出口A）

本轮故事讲完了：
- 利好正式公告（利好出尽）
- 产业数据见顶（如碳酸锂价格开始回落且持续）
- 预期逻辑被市场充分定价（后续无增量资金）
- 所有能讲的逻辑都被讲完了

### 4.3 交易失效信号与动作（出口B）

以下信号用于判断买入时的资金确认是否失败，不要求产业预期同时被证伪：

- 直接受益池从成片上涨退化为全面走弱或只剩孤票
- 龙头失去领涨性和主动性，且反抽无承接；单次炸板或日内震荡不算
- 买入时的价格响应失败，例如突破/回封后持续回落且无法重新确认
- 方向级涨停归零，或原有资金广度显著消失
- 新方向持续吸血，原方向成交与相对强度同步下降
- 放量下跌、成交额放大但价格持续走弱，显示资金主动撤退

时间与动作：

- 盘中信号至少经过两个关键观察点或收盘确认；单次瞬时波动不处理
- 只有1个信号，或核心仍有承接 → 持有观察
- ≥2个信号且资金撤退确认，首日减仓30-50%；成交数量按§3.1整手约束执行
- 次日仍未恢复，或买入时三维确认整体消失 → 清仓
- 出口B执行后，将预期降级为观察；方向再次走强时按§3.3重新评估

### 4.4 常见错误

**把分歧当方向结束**：单次炸板、换手升高或跟风回落，不能证明产业预期结束。预期依据仍在验证，只能说明方向处于分歧，不得删除预期文件。（→核心框架.md §3.2/L040）

**用“方向未结束”强迫持仓**：L040只保护方向判断，不保护每一笔交易。预期依据未否定时，仍必须检查§4.1出口B；资金确认失败可以减仓或清仓，同时保留方向观察。（→L012）

**用单一价格波动卖出**：跌破某个临时价格、一次炸板或单轮下跌不能独立触发出口B。必须与直接受益池、龙头主动性和资金撤退交叉验证。

**盘前红线脱离买入预期**：买入锚的是产业预期，但盘前临时设定的卖出红线却盯价格形态——两条逻辑不在一根链上。新增的任何卖出条件必须能回答："这个条件和买入时定义的预期是什么关系？"回答不上来 = 不能用。
