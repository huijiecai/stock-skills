# 核心框架：预期驱动交易体系

> **边界**：本文件只定义“是什么”和“怎么判断”，不定义“什么时候做”和“怎么做”。

---

## 一、什么是预期

**预期 = 市场资金正在投票的产业方向或事件催化。**

围绕预期做交易，不是量化公式，是投资者的思维框架。每一个数值都是感知信号，不是机械触发条件。

### 1.1 核心逻辑

- **预期确认 = 取得买入资格**：市场形成新预期 + 资金完成确认（三维确认）；是否执行还要经过买点与账户级排序
- **预期退出或交易确认失败 = 卖**：本轮故事讲完/被证伪，或资金不再确认本次交易

### 1.2 系统原则

- 不猜、不赌、不扛
- 低频，但确定
- 预期不问出处，确认只看资金
- 资金认可就是最好的确认力——有增量资金在进场，就有承接力

## 二、预期的来源与判断

### 2.1 预期从哪来

| 来源 | 说明 |
|------|------|
| 产业催化 | 涨价/缺货/扩产/技术突破/供应链重构 |
| 政策事件 | 产业政策/补贴落地/监管变化/国家级投资 |
| 资金异动 | 板块集体涨停/龙头连续走强/成交量异常放大 |

### 2.2 预期依据四类

判断预期本身有没有站得住脚的逻辑基础：

| 类型 | 特征 | 验证方式 |
|------|------|---------|
| **产业驱动** | 涨价/缺货/扩产/技术突破 | 期货价格、排产数据、供需报告 |
| **成长逻辑** | 业绩拐点/渗透率提升/份额扩张 | 财报数据、行业出货量、市占率 |
| **政策催化** | 产业政策/补贴/监管变化 | 政策文件、投资规模、落地节点 |
| **个股事件** | 重组/回购/业绩预告/股权激励 | 公告内容、业绩数据 |

### 2.3 确认的含义

一个预期被"确认"，意味着三个维度同时成立。三个维度对应三个核心问题：**有多少在涨？领涨的是哪个？预期带来的最核心表现咋样？**

| 维度 | 含义 | 典型信号 |
|------|------|----------|
| **资金投票** | 钱在方向性地流入该方向 | 方向内多只股票在涨（涨停或涨幅≥5%，广度） |
| **价格响应** | 龙头价格行为验证了预期 | 龙头涨停/突破关键位/半路放量/回踩企稳（深度） |
| **可验证依据** | 预期背后的逻辑正在被数据验证 | 对应§2.2四类依据的锚点数据在验证方向（如期货价上涨、业绩超预期、政策落地） |

**三者缺一 = 未确认：**
- 只有逻辑没有资金 = 空气（故事再好，没有资金响应就不成立）
- 只有异动没有锚点 = 噪音（板块涨了但归因不到可追踪的依据）
- 只有资金没有价格响应 = 未兑现（多只在涨但龙头没走出来，还在博弈）

**“确认”是预期的一种状态**，和五阶段模型中的“确认期”对应。判断一个预期是否被确认，是理解预期生命周期阶段的基础——不是只有买入时才需要判断。

## 三、预期生命周期

### 3.1 五阶段模型

| 阶段 | 含义 | 判断标准 |
|------|------|----------|
| **出现期** | 新预期首次出现，尚未经过市场检验 | 新催化出现，板块首次爆发（≥5只涨停） |

> **注**：出现期的判断标准（≥5涨停）是阶段判断标准，用于评估预期生命周期。研究触发的门槛更低（→ operations/预期研究.md §二），两者不是同一层级的概念。
| **确认期** | 预期持续性被验证，不只是一日游 | 二次走强（无论是否经历分歧） |
| **加速期** | 预期充分验证，进入主升浪 | 龙头持续走强，梯队完整，依据仍在验证 |
| **兑现期** | 预期逻辑开始兑现，本轮定价完成 | 利好正式公告，产业数据见顶 |
| **结束期** | 预期完结，资金已离场 | 龙头A杀，板块联动消失，依据被推翻 |

### 3.2 分歧 ≠ 结束

分歧是确认期内的自然阶段。核心判断锚点：**预期依据还在被验证 → 分歧；被否定 → 结束。**

| | 分歧（确认期内） | 结束（结束期） |
|---|---|---|
| 本质 | 筹码交换，资金在犹豫"要不要继续" | 资金已经放弃，在离场 |
| 龙头表现 | 震荡、断板但未大跌 | 大跌、A杀 |
| 板块联动 | 部分跟风回落但核心还在 | 全面溃散 |
| 操作含义 | **方向观察窗口**：方向不删除，但持仓仍需检查交易确认是否失败 | **空仓窗口**：等新预期出现 |

### 3.3 预期类型识别

**目的：帮助定义「兑现标志」和「失效标志」（买前三件事）**

| 类型 | 退出信号特征 | 案例 |
|------|------------|------|
| **持续数据型** | 月频或更高频率量化数据可追踪，数据见顶/破位即退出 | AI算力（光模块出货量）、锂电（碳酸锂期货） |
| **事件节点型** | 明确的一次性事件，事件兑现/取消即退出 | 商业航天（发射节点）、个股业绩（财报落地） |
| **实时感知型** | 无客观外部数据，依赖龙头行为/板块联动实时判断 | 纯连板炒作、情绪高潮 |

类型不决定仓位，仓位由买点类型决定（→买卖规则.md §2.1）。同一只股票在不同阶段可能属于不同类型。

## 四、感知信号解读

### 4.1 核心原则：信号 = 提醒注意，不是触发条件

系统中的数值（涨停数、封板率、换手率等）是**感知信号**。看到信号后的思考方向：**这对当前的预期意味着什么？**

- 某方向出现5只涨停 → "这个方向有资金进场" → 判断"这个预期值不值得交易"
- 不是"够不够触发条件"，而是"预期确认了吗？"
- **先行信号（T-1已有涨停）是加分项**（延续性更强），不是必要条件。无先行信号=当日催化驱动，同样有效

### 4.2 异动候选不等于龙头

方向未知时，只能把首次涨停、快速拉升、深水反转、高成交额突破的股票称为**异动候选/先导候选**，不能直接称为龙头。

固定识别顺序：

```
全市场发现异动候选
→ 搜索公告、新闻、财经媒体、雪球等信息，找市场正在交易的具体预期
→ 根据这个预期列出关联股票
→ 检查核心关联股是否成片同步上涨
→ 联动成立：归因正确、预期获得资金确认
→ 在关联股票中，最先发动且最强的是龙头
→ 检查权限、价格、仓位并决定交易标的
```

- `industry/sector/business`和概念标签都只是帮助搜索的线索，不能直接代替“今天为什么涨”的结论。
- 必须搜到具体预期，不能停留在“半导体”“华为概念”等方向标签。
- “成片同步上涨”指核心关联股普遍走强，不要求清单中每一只股票100%上涨。
- 如果只有候选自己上涨，说明当前归因未确认：继续搜索其他原因；仍找不到合理解释则作为孤立异动，不交易。
- 方向在state.md中已结束/归档，不得抑制重新归因；新异动仍须从零执行Mode A。
- 标的不可买或一手金额超限，只影响交易执行，不影响异动识别、方向研究和龙头确认。

### 4.3 各信号解读指引

| 信号 | 不是 | 而是 |
|------|------|------|
| **涨停数/封板率/跌停数** | 涨停<30就不买，或>100就高潮 | 关注你监控方向的板块级数据——联动在增强还是减弱？ |
| **换手率** | >15%就卖 | 换手率显著偏离近期正常水平 → 预期是被确认了还是被兑现了？ |
| **成交额** | 缩量就危险 | 关注成交额变化和价格方向的背离——缩量上涨=增量不足，放量下跌=抛压加重 |
| **连板高度/晋级率** | 高度降低就是退潮 | 高度降低+晋级率下降=高低位切换，观察新低位核心能否接力 |
| **产业数据指标** | 期货跌=板块完蛋 | 与板块走势交叉验证：期货涨+板块涨=确认；期货跌+板块涨=脱离基本面，警惕 |

### 4.3 倒计时催化效应

- 判断延续性时，关键变量不是"历史规律"，而是"有没有新出现的独立催化倒计时"
- **倒计时催化**：即将到期的产业催化事件（涨价日/政策日/数据发布日）会打破历史规律，显著提升延续概率
- 盘前分析必须检查活跃方向是否存在"即将到期的独立催化事件"

### 4.4 关键原则

- **概念标签 ≠ 归因结论** — astock板块排名的概念标签是数据输入，不是分析结论。每只涨停股必须追问"它为什么涨停？实际催化是什么？"同一只股只归入一个方向（主驱动方向）
- **大叙事反向拆解** — 某方向≥20只涨停时，必须反向检查"跟风股"有没有自己的独立催化。剥离后重新统计：独立方向的涨停数可能是被低估的
- **连板股独立归因** — 连续2天+涨停的个股，必须追问其连续涨停的独立催化源，不能因为"大方向在爆发"就归入大方向
