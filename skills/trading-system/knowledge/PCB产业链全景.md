## 一、产业链结构

```
第1层：最上游原材料
  铜箔 ← 铜冠铜箔（出货量第一）、诺德股份、德福科技、嘉元科技（英伟达认证）
  玻纤纱 → 玻纤布 ← 宏和科技（中国唯一超薄电子布）、中国巨石
  环氧树脂 ← 宏昌电子（英伟达链：供货胜宏/沪电/欣兴）、圣泉集团
  油墨/光刻胶 ← 广信材料（PCB光刻胶）
  药水 ← 天承科技（PCB电镀药水）
    ↓
第2层：覆铜板CCL（把铜箔+玻纤布+树脂压在一起）
  生益科技（全球第二，内资第一）
  金安国纪（内资前三，纯CCL 90%+）
  南亚新材（偏高端CCL/PP半固化片）
  华正新材（高端CCL+CBF膜，华为认证）
    ↓
第2.5层：封装基板材料（先进封装用）
  华正新材 ← CBF膜（ABF膜国产替代，通过兴森验证）
  味之素（日本）← ABF膜全球垄断95%+
    ↓
第3层：PCB制造（蚀刻出电路）
  胜宏科技（AI服务器PCB全球第一，英伟达GPU 50%+）
  深南电路（营收最大，PCB+IC载板+电子装联全产业链）
  沪电股份（数据中心+汽车PCB）
  东山精密（FPC柔性板，苹果链）
  鹏鼎控股（全球最大FPC，苹果独家）
  世运电路（汽车PCB）
  景旺电子（全品类PCB）
  崇达技术（通信/服务器PCB）
  迅捷兴（小批量快板，弹性大但毛利低）
    ↓
第3.5层：IC封装基板（芯片封装用，比PCB更高端）
  兴森科技（国内先行者，FCBGA，华为海思核心供应商）
  深南电路（也做IC载板）
  （台资）：欣兴电子、南亚塑胶、景硕科技
    ↓
第4层：PCB生产设备
  大族数控（大族激光子公司，激光钻孔/曝光/AOI）
  快克智能（固晶/焊接设备）
    ↓
第5层：终端应用
  AI服务器 ← 英伟达（→胜宏/沪电） / 华为昇腾（→华正CCL→深南/兴森IC载板）
  消费电子 ← 苹果（→鹏鼎/东山） / 华为
  通信设备 ← 华为、中兴（→深南/兴森）
  汽车电子 ← 特斯拉、比亚迪（→世运/沪电）
  数据中心 → 深南/沪电/胜宏
```

## 七、IC封装基板（先进封装）

### 什么是IC载板

IC载板是芯片和PCB之间的"桥梁"，比普通PCB更精密、技术壁垒更高。用于CPU/GPU/AI芯片的封装。

### ABF膜/CBF膜

ABF膜（味之素垄断95%+）是高端IC载板（FCBGA）的核心材料。CBF膜是国内对ABF膜的国产替代叫法。

| 公司 | 定位 | 进展 |
|------|------|------|
| **华正新材** | CBF膜材料商 | 通过兴森科技验证，小批量调试中，预计2025逐步国产替代 |
| **兴森科技** | IC载板制造商（用CBF膜做载板） | FCBGA国内产能最大，华为海思核心供应商，仍在投入期 |
| **深南电路** | IC载板+PCB | 也有IC载板业务 |
| 味之素（日本） | ABF膜全球垄断 | 95%+份额，30年技术积累 |

### IC载板涨价预期（2026年）

BT载板（存储用）和ABF载板（CPU/GPU用）供需紧缺，价格持续上涨。受益标的：深南电路、兴森科技。

### 涨价传导路径

```
上游材料涨价（铜/玻纤布/树脂）
  → CCL厂商涨价（建滔+10%、MGC+30%）
    → PCB厂商涨价传导（有定价权的高端厂）或利润挤压（无定价权的低端厂）
      → 终端客户接受（英伟达/华为不差钱）
```

### 谁最受益

| 产业链位置 | 受益逻辑 |
|-----------|---------|
| CCL厂商（生益/华正/金安/南亚） | 自己就是涨价方，直接赚差价 |
| 上游原材料（宏和/宏昌/铜冠/嘉元） | CCL扩产→量价齐升 |
| 高端PCB（胜宏/沪电/深南） | 需求旺盛+有定价权 |
| PCB设备（大族数控） | 行业景气→扩产→买设备 |
| 低端PCB（迅捷兴等） | 成本涨+没定价权→可能受损 |
