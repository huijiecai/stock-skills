# 谷歌TPU v7液冷产业链深度分析

> 整理时间：2026-04-10
> 触发事件：谷歌宣布2026年TPU芯片出货量目标上调50%至600万颗，TPU v7单芯片功耗980W，要求100%全液冷

---

## 一、事件本身：为什么这是大催化？

### 核心数据

| 指标 | 数据 | 意义 |
|------|------|------|
| TPU出货量上调 | **+50%** 至600万颗 | 超市场预期（原预期380-400万颗） |
| TPU v7单芯片功耗 | **980W** | 远超风冷极限（通常250-300W），液冷从"可选"变"强制" |
| 液冷方案要求 | **100%全液冷** | 不是部分液冷，是机柜级别全面液冷 |
| 单机柜液冷价值量 | **7-8万美元** | vs 传统风冷机柜2-3万，价值量提升3倍+ |
| 2026谷歌液冷市场规模 | **~180亿元人民币** | 去年的4倍！ |
| 谷歌液冷价值量增速 | **今年→明年 = 4倍** | 这是板块级爆发，不是温和增长 |

### 为什么980W必须液冷？

```
传统CPU/GPU：65-350W → 风冷足够
英伟达A100：400W → 需要风冷加强/入门液冷
英伟达H100：700W → 大部分需要液冷
英伟达B200：1000W+ → 必须液冷
谷歌TPU v7：980W → 100%强制液冷（没得选）
```

**结论**：这不是"液冷渗透率提升"的故事，而是**新芯片根本不能用风冷**的硬性升级。液冷从nice-to-have变成must-have。

## 二、液冷产业链拆解

### 一台谷歌TPU液冷机柜的构成

```
┌─────────────────────────────────────────┐
│         TPU v7 液冷机柜（价值量$7-8万）    │
│                                           │
│  ┌──────────┐  ┌──────┐  ┌──────────┐    │
│  │ CDU      │  │ 冷板  │  │ 快接头    │    │ ← 核心三大件（占60-70%）
│  │ (冷量分配)│  │(散热) │  │(快速连接) │    │
│  └──────────┘  └──────┘  └──────────┘    │
│                                           │
│  ┌──────┐  ┌──────┐  ┌──────┐  ┌──────┐  │
│  │ 泵阀  │  │管路  │  │冷却液 │  │电源   │  │ ← 配套（占20-30%）
│  └──────┘  └──────┘  └──────┘  └──────┘  │
│                                           │
│  ┌───────────────────────────────────┐    │
│  │ 测试设备 / 组装设备 / 密封材料     │    │ ← 边缘受益
│  └───────────────────────────────────┘    │
└─────────────────────────────────────────┘
```

### 各环节价值量 & A股标的

| 环节 | 价值占比 | 技术壁垒 | A股核心标的 |
|------|---------|---------|-----------|
| **CDU（冷量分配单元）** | ~25-30% | ⭐⭐⭐⭐⭐ 最高 | **英维克**（已获订单） |
| **冷板（Cold Plate）** | ~20-25% | ⭐⭐⭐⭐ | 高澜股份、飞荣达、鸿富瀚 |
| **快接头（QDC）** | ~10-15% | ⭐⭐⭐⭐ | 英维克（自研）、中石科技 |
| **泵阀/管路** | ~10% | ⭐⭐⭐ | 飞龙股份（但传出局？）、大元泵业 |
| **冷却液（氟化液）** | ~5-8% | ⭐⭐⭐ | 江化微、新宙邦 |
| **服务器电源（UPS）** | ~15-20% | ⭐⭐⭐⭐ | **欧陆通**（高功率电源） |
| **液冷测试/组装设备** | 边缘 | ⭐⭐⭐ | 科瑞技术、博杰股份 |

## 三、核心公司深度分析

### 🥇 英维克（002837）——液冷绝对龙头，谷歌订单最大受益者 ⭐⭐⭐⭐⭐

> **这是整个谷歌TPU液冷故事中最确定的公司**

| 项目 | 内容 |
|------|------|
| **定位** | 液冷温控全链条自研龙头（国内唯一全覆盖CDU+冷板+快接头+coolant） |
| **谷歌关系** | ✅ **已通过谷歌审厂**（2025年12月-2026年3月多轮审厂完成） |
| **谷歌订单** | ✅ **1.4MW + 2MW CDU批量订单已签，Q2开始交付** |
| **预计份额** | TPU机柜CDU约**25%份额** → 对应**20-30亿元**潜在订单（=2024全年营收的60%） |
| **产品匹配** | 专门为谷歌Project Deschutes 5规格开发了**2MW CDU**（行业最大功率之一） |
| **其他客户** | 英伟达（合作）、华为（供昇腾液冷）、微软、Meta、字节跳动 |
| **液冷业务增速** | 高盛预计2026年液冷收入**逐季增长** |
| **产能布局** | 扩建广东工厂 + 泰国工厂 + 美国工厂（全球化交付能力） |
| **股价表现** | 2025年以来液冷概念龙头，逼近千亿市值 |

**为什么英维克是最确定的？**
1. **审厂通过了**——不是"在谈"，是"过了"
2. **订单签了**——1.4MW+2MW CDU，Q2交货
3. **全链条**——不只做CDU一个环节，冷板/快接头都是自己的，利润率更高
4. **产能就位**——中/泰/美三地产能，能接谷歌的大单
5. **高盛背书**——分析师电话会后发布报告看好

**风险点**：
- 千亿市值+高PE，预期已经price in不少
- 谷歌订单具体金额尚未正式公告（目前是"传闻+机构测算"）
- 液冷竞争加剧（华为/中兴也在做液冷）

### 🥈 欧陆通（300870）——服务器电源，液冷的"隐形必需品" ⭐⭐⭐⭐

| 项目 | 内容 |
|------|------|
| **定位** | 服务器高压直流电源（HVDP）龙头 |
| **与液冷的关系** | 液冷机柜需要更高功率/更稳定的电源——**液冷越普及，高端电源需求越大** |
| **谷歌链** | 作为**英维克CDU的核心泵供应商**，间接进入谷歌供应链 |
| **技术优势** | 高功率电源（3300W/5500W），适配高算力场景 |
| **客户** | 英伟达（服务器电源）、谷歌（间接）、大型数据中心 |
| **逻辑** | TPU v7 980W功耗 → 液冷机柜功率密度飙升 → 电源功率和数量双升 |

**一句话**：液冷机柜比风冷机柜需要更多/更强的电源，欧陆通是"卖水人中的卖水人"。

### 其他值得关注的公司

#### 飞龙股份（002536）——液冷泵龙头，谷歌审厂传闻迷雾重重 ⭐⭐⭐⭐

> **这是整个液冷链中争议最大的公司——有人说出局了，有人说已通过**

**传闻 vs 现实的时间线**：

| 时间 | 事件 |
|------|------|
| 2025年12月8日 | HP22K液冷循环泵**批量交付仪式**举行，连夜发运客户（官方新闻） |
| 2026年3月中旬 | 市场传出"飞龙H22K液冷泵**未通过Google审核**"→股价波动 |
| 2026年3月16日 | 有分析文章称该传闻为**"不实传闻"**，可完整溯源传播链路 |
| 2026年3月27日 | 年报业绩说明会，投资者多次提问谷歌审厂事宜 |
| **管理层回应** | **"相关事项敬请关注公司公告""重要事项请以公司公告为准"** —— 未否认也未确认 |

**多方信息交叉对比**：

| 信息源 | 说法 |
|--------|------|
| 看多方（雪球等） | ✅ 已通过谷歌审厂、✅ 英伟达认证、✅ 全球唯二同时进入谷歌+英伟达供应链、✅ 通过台达供应NV |
| 看空方（传闻） | ❌ H22K谷歌审厂0通过率出局 |
| 公司官方（董秘） | 🤐 "以公告为准"（既不认也不否） |
| 确认事实 | ✅ HP22K已批量交付（有仪式+发运）、✅ 22kW/37kW/60kW/80kW产品线在推进、✅ 出口占比50% |

**飞龙股份的真实基本面**：

| 项目 | 内容 |
|------|------|
| **定位** | 全球液冷泵龙头（传统业务：汽车水泵/发动机部件） |
| **液冷核心产品** | HP22K（22kW大型IDC液冷循环泵），已批量交付 |
| **产品线** | 22kW → 37kW → 60kW → 80kW（功率递进，全面覆盖） |
| **应用延伸** | 从汽车向服务器液冷/IDC/AI/充电桩/机器人/5G基站/氢能储能延伸 |
| **传统业务** | 发动机热管理(-10.47%) + 节能减排(-6.17%)承压，新能源热管理成新引擎 |
| **出口占比** | **50%**（博格华纳/盖瑞特/康明斯/通用/福特等） |
| **Q4环比** | 收入+22%（新能源热管理集成销量增长较快） |
| **产能** | 液冷泵现有3条产线，按订单逐步扩张 |

**我的判断**：

飞龙股份的处境和科瑞技术惊人地相似：
- 产品真实✅ 客户真实✅ 批量交付✅
- 但对"是否进入谷歌供应链"这个关键问题，董秘一律"以公告为准"
- 多头说"已通过"，空头说"出局"，真相在中间某个地方

**可能的真相**：
1. HP22K确实已批量交付——但**不一定是给谷歌的**（可能是其他IDC客户）
2. 谷歌审厂可能进行了，但结果可能不是简单的"过/不过"——可能是"某型号过某型号需改进"
3. 公司不回应是因为涉及大客户保密协议（和科瑞技术一模一样的理由）

**结论**：飞龙股份**不能排除在谷歌链之外**，但也不能确认已进入。它的价值在于：
- 液冷泵是CDU的**核心零部件**（每个CDU平均2.5个泵）
- 即使不走谷歌直供，通过**台达→英伟达**或**Tier1→谷歌**间接供货也是可能的
- 传统汽车业务提供安全垫（出口50%），液是新增量
- 如果最终确认进入谷歌链，当前股价就是黄金坑

**风险**：如果谷歌真的没过且短期内无法进入，纯靠液冷概念支撑估值有压力。

| 公司 | 预期强度 | 预期依据 | 资金确认 | 价格确认 | 生命周期 |
|------|---------|---------|---------|---------|---------|

| **欧陆通** | 板块级 | 液冷→高功率电源需求增长，间接进谷歌链 | ⚠️ 有关注但非主线 | 未大涨 | 出现期 |

### 核心判断

**这个事件的性质**：
- **不是小题材**——谷歌一家2026年液冷180亿市场规模，且是去年的4倍
- **不是远期故事**——Q2就要开始交付（英维克CDU）
- **不止一家受益**——整条液冷产业链都有增量
- **但最确定的还是英维克**——审厂通过+订单在手+全链条
