## 二、技术路线对比：冷板式 vs 浸没式 vs 喷淋式

### 三种路线的本质区别

| 维度 | 冷板式（板式液冷） | 浸没式（ immersion） | 喷淋式 |
|------|------------------|-------------------|--------|
| **原理** | 冷却液流过贴在芯片背面的冷板管道 | **整个主板/器件直接泡在冷却液中** | 冷却液喷淋到发热表面 |
| **接触方式** | 间接（液体不接触芯片） | **直接**（液体包围芯片） | 半直接 |
| **冷却介质** | 水/乙二醇混合液 | **氟化液**或**矿物油/合成油** | 氟化液 |
| **PUE值** | 1.1-1.3 | **1.04-1.08**（最低！） | 1.08-1.15 |
| **散热上限** | ~800W/芯片 | **1500W+/芯片**（无上限） | ~1000W/芯片 |
| **改造成本** | 较低（可改造现有风冷机柜） | **高**（需专用机柜） | 中等 |
| **单机柜成本** | $5-7万 | $8-12万 | $6-9万 |
| **技术成熟度** | ✅✅✅ 最成熟，已大规模商用 | ✅✅ 快速放量中 | ✅ 早期阶段 |
| **代表客户** | 英伟达GB200 NVL72（主用）、谷歌TPU（部分） | **谷歌TPU v7（100%！）**、未来Rubin | 少量试点 |
| **主要玩家** | 英维克、高澜股份、飞荣达 | **申菱环境、曙光数创、新朋股份** | 少数 |

### 各路线适用场景

```
芯片功耗区间与液冷路线选择：

0-300W  → 风冷就够了（传统CPU/GPU）
300-700W → 风冷加强 或 入门冷板式（英伟达A100时代）
700-1000W → **冷板式液冷**（英伟达H100/B200、当前主流）
1000W+   → **浸没式液冷**（谷歌TPU v7的980W！= 强制浸没）
1500W+   → 只有浸没式能搞定（英伟达Rubin时代）
```

### 价值量拆分（以一台$7-8万的谷歌TPU v7液冷机柜为例）

| 环节 | 价值量（美元） | 占比 | A股核心标的 |
|------|-------------|------|-----------|
| CDU | 17,500-24,000 | 25-30% | **英维克** |
| 冷板 | 14,000-20,000 | 20-25% | 高澜股份、飞荣达 |
| 快接头 | 7,000-12,000 | 10-15% | 中石科技、英维克 |
| 液冷泵 | 5,600-9,600 | 8-12% | **大元泵业**、飞龙股份 |
| 冷却液 | 3,500-6,400 | 5-8% | 江化微、新宙邦 |
| 电源 | 10,500-16,000 | 15-20% | **欧陆通** |
| 管路/Manifold/其他 | 7,000-11,200 | 10-15% | — |
| **合计** | **70,000-80,000** | 100% | |

### 6.1 CDU环节（液冷系统核心，价值量最高）

#### 英维克（002837）——液冷绝对龙头，谷歌+英伟达+华为三链通吃 ⭐⭐⭐⭐⭐

| **2025表现** | 液冷业务收入逐季增长，逼近千亿市值 |
| **谷歌关系** | ✅✅ **审厂通过**（2025.12-2026.03多轮）+ **1.4MW+2MW CDU批量订单已签** + **Q2开始交付** |
| **谷歌预期份额** | TPU机柜CDU约**25%** → 对应**20-30亿元**潜在订单（≈2024全年营收60%） |
| **产品匹配** | 专为谷歌Project Deschuates 5开发**2MW CDU**（行业最大功率级别之一） |
| **英伟达关系** | ✅ 深度参与NVL72液冷方案 |

| **技术覆盖** | CDU ✅ 冷板 ✅ 快接头 ✅ coolant ✅ —— 全链条自研 = 利润率更高 |

**为什么英维克是液冷板块的"锚定标的"**：
1. **三链通吃**：谷歌（最确定的大单）+ 英伟达（持续放量）+ 华为（长期基本盘）
2. **全链条**：不只做CDU一个零件，是从CDU到coolant的全栈——单一公司吃掉液冷系统25-30%+20-25%+10-15%=**超过50%的价值量**
3. **产能全球化**：中/泰/美三地产能=能接任何体量的订单
4. **Q2是关键催化剂**：第一批CDU交付谷歌=收入确认=整个板块的"证据"

**风险点**：
- 千亿市值PE不便宜，预期已部分price in
- 谷歌订单具体金额尚未正式公告
- 液冷竞争加剧（华为/中兴也在做）

##### 为什么屏蔽泵是液冷泵的终局形态？

```
数据中心液冷的第一痛点：漏液！
├── 机械泵（飞龙股份HP22K等）：
│   → 有密封件（轴承/机械密封）
│   → 长期运行磨损 → 密封失效 → 漏液
│   → 数据中心漏液 = 灾难（短路/腐蚀/停机）
│
└── 屏蔽泵（大元泵业核心产品）：
    → 电机+泵一体化全密封（无轴封）
    → 零泄漏可能性
    → 数据中心首选（尤其浸没式中—泵浸在冷却液中更不能漏）
    → 唯一缺点：单价更高、效率略低

结论：随着液冷渗透率提升+数据中心安全标准提高
→ 屏蔽泵替代机械泵是确定性趋势
→ 大元泵业作为国内唯一能量产高功率液冷屏蔽泵的厂商 = 最大受益者
```
