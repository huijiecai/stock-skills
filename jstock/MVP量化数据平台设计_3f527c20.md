# MVP 量化数据平台设计文档

## 一、项目概述

### 1.1 定位

本地 A 股量化数据平台 MVP，一人使用，Mac 本机运行，纯 AData 扩展实现。

### 1.2 核心需求

| 编号 | 需求 | 数据维度 | 周期 |
|------|------|---------|------|
| R1 | 个股行情 | 日K / 分钟K / 实时 | 最近 30 天 |
| R2 | 同花顺板块行情 | 日K / 分钟K / 实时 | 最近 30 天 |
| R3 | 指数行情 | 日K / 分钟K / 实时 | 最近 30 天 |
| R4 | 盘后排名 | 成交额 TOP30 + 涨停天梯 | 当日 |

### 1.3 技术栈

| 层 | 选型 | 说明 |
|----|------|------|
| 数据采集 | **AData（扩展）** | 纯 AData，不依赖 Tushare / BaoStock |
| 存储 | **PostgreSQL** | 已安装，ACID，网络协议 |
| API | **FastAPI** | 自动文档，本地 `localhost:8000` |
| 调度 | **launchd (macOS)** | 自启动，按交易日历触发 |
| 语言 | Python 3.11+ | 与 AData 一致 |

### 1.4 环境与规模

- macOS 14+，数据量 < 2 GB，30 天滚动清理，无需外部服务

### 架构原则

1. 离线采集写入 PG，在线查询只读
2. 盘中实时数据直调 AData，不落库（省 IO、无延迟）
3. 历史日K/分钟K收盘后批量写入供回测分析

## 三、数据库设计

### 3.1 建表

```sql
CREATE DATABASE astock;

-- 股票基础信息
CREATE TABLE stock_info (
    code        VARCHAR(10) PRIMARY KEY,
    name        VARCHAR(20) NOT NULL,
    exchange    VARCHAR(4) NOT NULL
);

-- 同花顺概念信息
CREATE TABLE concept_info (
    code        VARCHAR(10) PRIMARY KEY,
    name        VARCHAR(50) NOT NULL
);

-- 交易日历
CREATE TABLE trade_cal (
    trade_date  DATE PRIMARY KEY,
    is_trade    BOOLEAN DEFAULT TRUE
);

-- 日K (个股/板块/指数统一)
CREATE TABLE daily_k (
    code        VARCHAR(10) NOT NULL,
    trade_date  DATE NOT NULL,
    data_type   VARCHAR(10) NOT NULL DEFAULT 'stock',
    open        DOUBLE PRECISION, high DOUBLE PRECISION,
    low         DOUBLE PRECISION, close DOUBLE PRECISION,
    volume      BIGINT, amount DOUBLE PRECISION,
    change_pct  DOUBLE PRECISION,
    PRIMARY KEY (code, trade_date, data_type)
);
CREATE INDEX idx_daily_k_code ON daily_k (code, trade_date);

-- 分钟K (个股/板块/指数统一)
CREATE TABLE minute_k (
    code        VARCHAR(10) NOT NULL,
    dt          TIMESTAMP NOT NULL,
    freq        VARCHAR(5) NOT NULL,
    data_type   VARCHAR(10) NOT NULL DEFAULT 'stock',
    open        DOUBLE PRECISION, high DOUBLE PRECISION,
    low         DOUBLE PRECISION, close DOUBLE PRECISION,
    volume      BIGINT, amount DOUBLE PRECISION,
    PRIMARY KEY (code, dt, freq, data_type)
);
CREATE INDEX idx_minute_k_code ON minute_k (code, dt);
```

### 3.2 滚动清理

```sql
DELETE FROM daily_k  WHERE trade_date < CURRENT_DATE - 30;
DELETE FROM minute_k WHERE dt < CURRENT_DATE - 30;
```

## 四、数据采集设计

### 4.1 AData 现有接口映射

| 数据 | AData 方法 | 支持 |
|------|-----------|------|
| 个股日K | `stock.market.get_market(start_date=...)` | 历史完整 |
| 指数日K | `stock.market.get_market_index()` | 历史完整 |
| 概念日K | `stock.market.get_market_concept_ths()` | 历史完整 |
| 个股实时 | `stock.market.list_market_current()` | 盘中 |
| 概念实时 | `stock.market.get_market_concept_current_ths()` | 盘中 |
| 指数实时 | `stock.market.get_market_index_current()` | 盘中 |
| 股票代码 | `stock.info.all_code()` | 全量 |
| 概念代码 | `stock.info.all_concept_code_ths()` | 全量 |
| 交易日历 | `stock.info.trade_calendar()` | 全量 |

### 4.2 唯一需要扩展的部分：同花顺分钟 K 线

AData 不提供历史分钟，但同花顺 v6 API 底层支持 (period=61)：

```python
# collector/ths_minute.py
import json, pandas as pd
from adata.common.base.base_ths import BaseThs

PERIOD_MAP = {
    '1min':  '61',
    '30min': '41',
    '60min': '51',
}

class ThsMinuteKline(BaseThs):
    def get_minute_kline(self, code, freq='1min', prefix='hs', data_type='stock'):
        """
        :param prefix: hs(个股) / 48(同花顺概念) / zs(指数)
        """
        period = PERIOD_MAP.get(freq, '61')
        url = f"http://d.10jqka.com.cn/v6/line/{prefix}_{code}/{period}/last360.js"
        text = self._get_text(url, code)  # 复用 AData 重试/Cookie
        data = json.loads(text[text.index('{'):-1])['data'].split(';')
        
        rows = []
        for d in data:
            p = str(d).split(',')[0:7]
            if len(p) < 7: continue
            rows.append((code, pd.to_datetime(p[0]), freq, data_type,
                        float(p[1]),float(p[2]),float(p[3]),float(p[4]),
                        float(p[5]),float(p[6])))
        return pd.DataFrame(rows, columns=[
            'code','dt','freq','data_type',
            'open','high','low','close','volume','amount'])
```

**关键是 `BaseThs._get_text()`**——它自动处理同花顺的 Cookie、重试、IP 限制，整个分钟扩展就 20 行代码。

### 4.3 初始化脚本 (init_db.py)

首次运行，拉最近 30 天全量：

```
1. 股票列表 → stock_info
2. 同花顺概念列表 → concept_info
3. 交易日历 → trade_cal
4. 遍历个股 → daily_k + minute_k
5. 遍历概念 → daily_k + minute_k
6. 遍历指数 (上证/深成/创业板/科创50) → daily_k + minute_k
```

### 4.4 每日增量 (daily_sync.py)

收盘 15:05 执行：增量当日数据 + 滚动删除 30 天前

## 五、实时查询服务 (不落库)

盘中数据直接调 AData，不存库：

| 接口 | 能力 |
|------|------|
| `RealtimeService.stock_current()` | 全市场实时行情 |
| `RealtimeService.volume_rank(30)` | 成交额 TOP30 |
| `RealtimeService.limit_up_ladder()` | 涨停天梯 (涨跌幅>9.8%) |

成交额排名：从 `list_market_current()` 取 `amount` 列 `nlargest(30)`
涨停天梯：过滤 `change_pct > 9.8%` 且非 ST/新股

## 六、API 设计 (FastAPI)

```
GET  /v1/k/daily?code=000001&start=2025-04-01       → 历史日K (PG)
GET  /v1/k/minute?code=000001&freq=1min&type=stock   → 历史分钟K (PG)
GET  /v1/realtime/stocks                              → 个股实时 (AData)
GET  /v1/realtime/concepts                            → 概念实时 (AData)
GET  /v1/realtime/indexes                             → 指数实时 (AData)
GET  /v1/rank/volume?top=30                           → 成交额排名 (AData)
GET  /v1/rank/limit-up                                → 涨停天梯 (AData)
GET  /v1/info/stocks                                   → 股票列表 (PG)
GET  /v1/info/concepts                                 → 概念列表 (PG)
```
