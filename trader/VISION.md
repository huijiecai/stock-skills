# 产品北极星:核心价值与边界

> 每个功能决策拿这页来裁决。改定位先改这页,再改代码。
> 抽象与实现架构见 [docs/工作台架构.md](docs/工作台架构.md)。

## 一句话

**让普通交易者不用写代码,就能开发、验证、托管运行自己的"判断型交易系统"——每一笔盈亏都有证据可查。**

卖的是省下的学习成本、盯盘时间和验证周期;**永远不卖"AI 替你赚钱"的承诺**。

## 核心价值(按成立顺序)

### 1. 开发门槛:从编程降到自然语言
我们的地盘是**判断型策略**——盘前读新闻写预案、盘中像人一样连续观察量能动态决策。这种"盘感/逻辑/语境"写不成代码,自然语言是它唯一的编程语言。
机械规则型策略("涨幅>2%且量>1.5倍均量就买")劝用户去用聚宽——规则用代码跑得更准更便宜,不是我们的战场。

### 2. 自主托管:用户不在场,系统在值守
盘前自动触发、盘中连续看盘、收盘自动收工;防重复触发、崩溃自愈、优雅停止。
用户买的不是"AI 能力"(聊天助手免费都有),是"我不盯盘,它也在替我执行纪律"。

### 3. 验证:数据说话
虚拟账号持续跑几天 → 收益/回撤/胜率 → 同日两版对比。把"我觉得行"变成"数据说行"。
**模拟盘是主验证路径**;多日回测对 LLM 策略=每个历史日重放一遍推理(贵/慢/不确定),是研究课题,不是 MVP 功能。

### 4. 证据链:每笔盈亏问得出"为什么"
每一轮绑定 prompt 版本指纹 + 工具返回 + 成交记录,不可篡改、只可封存。
这是信任的地基,也是未来市场的货币:**prompt 抄得走,履历抄不走。**

### 5. 进化:系统每天变好
复盘 → 教练分析 → 建议落成新版本 → 次日生效。
克制条款:教练近期的主价值是**解释执行**(建立信任);"优化建议"短样本易过拟合,明确标注置信度,不做自动改。

### 6. 变现(后期):双边市场
- 创作者:卖**托管运行权 + 履历**(不是策略文件——文件会被抄走,持续进化和累积的履历不会)
- 买家:一键托管运行,持续获得作者更新
- 平台:抽成。冷启动 = 我们自己是第一个创作者,自己的实盘记录是第一件商品。

## 边界(红线)

| 平台做的 | 平台不碰的 |
|---|---|
| ✅ 工具:系统的编辑/托管/执行 | ❌ 不承诺收益(实盘不可控) |
| ✅ 履历:不可篡改的执行证据 | ❌ 不代持资金(对接券商通道,不碰钱) |
| ✅ 市场:系统使用权的交易 | ❌ 不做个性化荐股(投顾持牌业务) |

## 阶段路线

```
① 自用跑起来      ② 履历可视化        ③ 系统模板         ④ 市场
   (攒履历)        (净值曲线/对比)      (别人能开始)       (交易使用权)
   现在在这 ✓✓       差这步最多          未建,不急          未建,最后
```

每一步都在为下一步攒信任基础设施,没有一步白做。

## 功能裁决标准

面对选择时只问一句:**这个选择让履历更可信、让归因更强吗?**

- 是 → 做
- 否 → 缓,哪怕它看起来更酷

## 用户是谁

- 首发人群:有交易想法、不会编程、又不愿只当"跟单韭菜"的散户
- 第二波:想卖系统的策略创作者(等②③就绪后才有供给)
- 不服务:想要"无脑躺赚信号"的人——他们是合规风险,不是用户
