【盘前分析 · 目标交易日 {date} · 上一交易日 {prev}】

## 第一步:启动序列(必做)
- get_positions / get_account:当前持仓与现金
- get_expectations:全部预期(活跃的逐个 get_pool 看详情)
- 昨日数据(全部用 date={prev}):get_indices(mode='replay', date='{prev}') / get_market_summary(date='{prev}') / get_limit_up(date='{prev}') / get_top_amount(date='{prev}', limit=20)

## 第二步:八维催化扫描(强制全覆盖,联网搜索;每维无重要消息也要标"无";每条注来源)
1. **美股/外围**:三大指数收盘+重点个股(英伟达/特斯拉等)+商品期货异动(+4%以上)
2. **A股晚间公告**:昨晚重要公告全量
3. **个股业绩**:超预期/不及预期,重点持仓股和池内龙头
4. **活跃产业链纵深**:对每个活跃预期方向拆上/中/下游各自搜索(每方向≥3个query)
5. **行业事件/政策**:峰会/产业政策/技术突破/海外基建
6. **监管动态**:立案/处罚/退市警示
7. **公司行为**:减持/增持/回购/定增
8. **盯盘股专项**:持仓股+各池 core/leader 股逐一搜最新公告

消息优先级:路透/彭博 > 财联社/华尔街见闻 > 雪球 > 东财。

## 第三步:催化→方向映射表(强制产出,禁止只罗列不映射)
| 催化 | 指向方向 | 是活跃预期? | 强度(⭐⭐⭐政策/⭐⭐直接/⭐间接) | 对 {date} 的影响(具体到操作,禁止"重点监控"空话) |

## 第四步:催化→活跃预期交叉(强制产出)
每个活跃预期逐一检查新增催化:依据加强/减弱/不变?
- 有变化的 → update_expectation 落库(阶段/内容)
- 强势新方向不在库 → 立即做预期研究(归因→add_expectation→池)

## 第五步:昨日消化
- get_limit_up({prev}) 的涨停按方向归因:哪些归入已有预期(资金面确认)?哪些是新方向?
- get_top_amount({prev}) 成交额前 N:资金在哪,有无隐含新预期

## 第六步:{date} 场景推演(强制,≥3个场景,每个配具体操作)
```
场景A:...(概率X%)→ 市场表现 + 具体操作
场景B:...(概率Y%)→ ...
场景C:小概率...
```

## 第七步:交易预案(if-then)
- if [确认信号] → 买 [标的/仓位];if [失效信号] → 卖/清仓
- 保守锚点("不追/不做")必须带升级条件(如"若资金+价格+依据三重再确认→升级为买点评估")
- 预案还要包含:持仓股的当日应对(±2%触发怎么办)

## 第八步:落库 + 自检
完整报告(含上述所有表格/场景/预案)调 save_doc(doc_type="premarket", trade_date="{date}") 存档。
自检:八维每维有内容 ✓ 映射表 ✓ 交叉表 ✓ 场景≥3 ✓ 预案 if-then ✓ 无催化被一笔带过 ✓
