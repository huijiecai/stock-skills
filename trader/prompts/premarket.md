【盘前分析 · 目标交易日 {date}({weekday}) · 上一交易日 {prev}】

## 第一步:启动序列(必做)
- get_positions / get_account:当前持仓与现金
- list_docs(doc_type='expectation'):全部预期(meta 看方向/阶段/状态;活跃的逐个 get_doc 看详情,池成员 get_watchlist(组名))
- 昨日数据(全部用 date={prev}):get_indices(mode='replay', date='{prev}') / get_market_summary(date='{prev}') / get_limit_up(date='{prev}') / get_top_amount(date='{prev}', limit=20)

## 第二步:八维催化扫描(强制全覆盖,联网搜索;每维无重要消息也要标"无";每条注来源)

**跨日专项(本次 {date} 与上一交易日 {prev} 间隔 {gap} 个自然日;gap=1 时本节标"不适用"跳过)**:
必须专门扫描这些自然日的消息——搜"{date} 周末要闻 A股"、"周末 央行 证监会 新规 政策"等,
覆盖:宏观(金融数据/逆回购/汇率)、监管新规/交易规则、周末产业政策、周末公司公告。
**禁止只搜"最新"**(搜索引擎以 {prev} 的热门为主,会把周末消息漏掉)。

1. **美股/外围**:**数据状态纪律(硬性)**——隔夜美股已收盘→引用**收盘数据**并写明"美东 X月X日(周X)收盘";
   隔夜美股**仍在盘中**(北京凌晨/早盘运行)→搜盘中实时快照,写明"美东 X月X日(周X)盘中,截至北京 HH:MM",
   并提示"{date} 开盘前按收盘值复核方向是否变化"。
   **禁止把盘中数据当收盘写、禁止把上一交易日当'最新'而不标注日期。**
   内容:三大指数(收盘值或盘中现值)+ 重点个股(英伟达/特斯拉等)+ **商品期货必查**(黄金/原油/铜等,+4% 以上品种;无异动也要标"商品期货:无大异动")。
   **逐条数字必须注来源与新闻发布时间;搜不到可靠来源的标"未核实",禁止凭印象填数。**
2. **A股晚间公告**:昨晚重要公告全量
3. **个股业绩**:超预期/不及预期,重点持仓股和池内龙头
4. **活跃产业链纵深**:对每个活跃预期方向拆上/中/下游各自搜索(每方向≥3个query)
5. **行业事件/政策**:峰会/产业政策/技术突破/海外基建
6. **监管动态**:立案/处罚/退市警示
7. **公司行为**:减持/增持/回购/定增
8. **盯盘股专项**:持仓股+各池 core/leader 股逐一搜最新公告

消息优先级:路透/彭博 > 财联社/华尔街见闻 > 雪球 > 东财。

## 第四步:催化→活跃预期交叉(强制产出)
每个活跃预期逐一检查新增催化:依据加强/减弱/不变?
- 阶段/状态有变化 → set_doc_meta(该预期文档 id, meta 改 stage/status);内容有变 → save_doc 同键覆盖重写正文
- 强势新方向不在库 → 立即做预期研究(归因→save_doc 预期文档→save_watchlist 池)

## 第五步:昨日逐股扫描消化(强制,自下而上)
- **get_limit_up({prev}) 涨停逐只归因,产出表格(禁止只给板块汇总)**:
  | 方向 | 涨停数 | 归因的涨停股 | 是否活跃预期 | 新方向? |
  哪些涨停归入已有预期(资金面确认)?哪些是新方向(带入第三四步评估)?
- get_top_amount({prev}) 成交额前 N:资金在哪,有无隐含新预期

## 第七步:交易预案(if-then)
- if [确认信号] → 买 [标的/仓位];if [失效信号] → 卖/清仓
- 保守锚点("不追/不做")必须带升级条件(如"若资金+价格+依据三重再确认→升级为买点评估")
- 预案还要包含:持仓股的当日应对(±2%触发怎么办)
- **红线:卖出条件必须是"触发双出口评估"的信号(预期兑现/失效/资金确认消失)。
  禁止写"跌破X%即止损"类纯价格止损——±2%/±5% 只是触发评估的巡检线,
  评估后预期与资金都健康就不卖。**

## 第八步:落库 + 自检
完整报告(含上述所有表格/场景/预案,引用池时**内联当时成员名单**——复盘关联靠它)调 save_doc(doc_type="premarket", trade_date="{date}") 存档;
**报告首行必须写"生成时刻:北京 YYYY-MM-DD HH:MM"**。
自检(**逐条真实核对,未做的项不得打✓——发现未做即返工补做,再重新存档**):
- [ ] 八维每维有内容(含商品期货"无大异动"标注)
- [ ] 美股段**标注了数据状态**:收盘数据(注明美东日期)或盘中快照(注明截至北京时刻),未把盘中当收盘、未把上一交易日当最新不标日期;逐条数字有来源
- [ ] 隔周末时,周末消息(宏观/监管/新规)已专门扫描并体现在报告
- [ ] 昨日涨停逐只归因表已产出(逐只,非板块汇总)
- [ ] 映射表 ✓ 交叉表 ✓ 场景≥3 ✓ 预案 if-then ✓
- [ ] 预案无纯价格止损表述
