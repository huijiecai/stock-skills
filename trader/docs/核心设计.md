# trader 核心设计(定稿候选 v1.0)

> 本文档只讲清楚"系统长什么样、规则是什么",不涉及表结构和实现。

## 0. 一句话

**用户用 3 个概念操作系统:实盘、模拟一场、对比;其余一切都是系统内部自动做的事。**

---

## 1. 用户看到的(全部界面)

```
┌──────────────────────────────────────────┐
│  实盘 8/19 ▶(运行中)                      │
├──────────────────────────────────────────┤
│  模拟一场:选日期 [8/12 ▼]  备注[____] 跑   │
├──────────────────────────────────────────┤
│  历史场次                                  │
│  ● 8/19 实盘(今天)                        │
│  ● 8/18 实盘 剑桥清仓                     │
│  ● 8/12 模拟·基线    +1.2%   [选来对比]   │
│  ● 8/12 模拟·新规则  -0.1%   [选来对比]   │
│  → 勾两场 → 并排页:                       │
│     顶部:起点一致 ✓ 差异:prompt           │
│     内容:收益曲线/交易时序/统计卡/思考流对照 │
└──────────────────────────────────────────┘
```

- 场次可点开:看这一天(场)的完整过程——每轮思考流、每笔交易、统计卡
- 删除场次是显式操作,系统永不自动销毁任何一场
- 用户词汇表就三个:实盘、模拟一场、对比

## 2. 核心抽象:档案袋(学术名 run_session)

**每次看盘——不管实盘还是模拟——系统都建一个独立档案袋。**

```
档案袋
├── 封面(开局自动写好,用户不用管):
│     · 策略版本:当时的 prompt 存档(哪一版)
│     · 知识库起点:当时的预期库完整复印件
│     · 数据:实时(哪天)/ 历史(哪天)
│
└── 袋内(这一场产生的一切):
      · 每一轮的思考流与轮日志
      · 这一场的交易记录
      · 这一场的指标(收益/回撤/胜率等,跑完自动算)
```

封面存在的唯一理由:**让"对比"有据可查**——两袋并排时,系统检查封面,
确认除一个变量外其他相同,差异才能归因。

## 3. 三条运行规则

**规则 1|钱包分两种**
- 实盘钱包:唯一、连续(昨天买的今天 T+1 才能卖,因为它连着)
- 模拟钱包:每场发一个一次性的,开局三选一(实现设计 §6)——初始资金(默认)/
  复制正本现状或截至某日(fork,时间安全)/自定义现金持仓;场结束封存

**规则 2|知识库(预期库)正本与复印件**
- 正本:实盘直接写——今天研究的预期,明天开盘接着用(连续演化)
- 复印件:模拟一场开局拍一份,场内随便改,全部留在袋内;
  好发现将来可通过显式操作抄回正本(v1 先不做这个按钮,只留口子)

**规则 3|对比三步**
1. 挑两个档案袋
2. 系统自动校验封面:策略版本、知识库起点、数据,哪些相同哪些不同
3. 只有一个变量不同 → 干净对比 ✓;多个不同 → 标"归因不唯一",照样能看但要提示

## 4. 实盘与模拟的唯一区别

**数据源。** 实盘=当天实时行情;模拟=指定历史日的行情,按时间推进、看不到未来。
两者共用同一条看盘管线(同样的轮次、工具、决策、留痕),不存在"模拟是缩水版"。

## 5. 吸收外部评审(DeepSeek 方案)的四点

| 吸收 | 说明 | v1 采用? |
|---|---|---|
| prompt 版本化存档 | **已实现**:PG 是平台唯一正本,Web 负责编辑并生成新版本;CLI:`python -m trader.prompts versions/diff` 仅供查询 | 是 |
| 场次指标 metrics | 每场跑完自动算收益/回撤/胜率,挂袋上,对比页直接用 | 是 |
| 实验(experiment)分组 | 多场组成命名实验、指定基准场 | 否,留口子(v1 临时勾两场够用) |
| 模拟持仓由流水推算 | 不单独维护模拟持仓表,从该场成交算 | 是(实现细节) |

## 6. 保留我们领域模型的理由(评审方案不懂的部分)

- **预期库 = 方向级知识库**(产业逻辑/五阶段/池分级/失效标志),不是"单股目标价预测"——
  六类轮转、双出口、池健康度全建在它上面,不可替换
- **盘中轮次与思考流**是一等资产(审计与对比的核心素材),不是"盘前/盘中/盘后三次调用"
- **AI 用工具自主决策**(agentic),不是"输出 JSON 解析下单"——已实战验证

## 7. v1 明确不做(只留口子,全部只加不改)

分支(知识库多线演化)、知识回流按钮、连续多日模拟、多用户、PostgreSQL 迁移、
prompt 在线编辑器。
