## 1. 背景与痛点

prompt 正式全走 PG 后,web 指令编辑器成为用户写自己交易逻辑的**唯一编程界面**。但一个"编程环境"的三要素全缺:

| # | 痛点 | 现状 |
|---|---|---|
| 1 | **不知道有哪些环境变量可用** | 变量由引擎按阶段类型隐式注入(single:`date/prev/weekday/gap`;live 轮:`rounds/now/date`;replay:`rounds/date/clock`),manifest 里的 `vars` 只是提示列表,编辑器无处展示;写错占位符要等运行时才炸(`load()` 的 RuntimeError) |
| 2 | **不知道有哪些工具可引用、返回长什么样、无法测试** | 19 个内置工具的说明只存在于 Python docstring(LLM 能看到,作者看不到);白名单是个裸名字多选框;想看返回只能去终端跑 `python -m trader.tools call` |
| 3 | **无法添加自己的工具/MCP** | `core/registry.py` 硬编码,零扩展机制(本轮不做,§8 预留) |

**铁律**:工具试运行一律挂**测试账号**,owner(user 0)绝不参与——owner 是用户自己手工测的。

## 2. 目标与非目标

**目标**:
1. 变量契约机器化——编辑器与运行时**同源**,永不漂移
2. 工具目录可视化——名称/参数/说明/是否写操作,随手可查
3. 工具试运行——编辑器里点一下,看真实返回(就是 LLM 看到的字符串),打到测试账号
4. 占位符 lint——运行时报错前移到编辑时

**非目标(本轮明确不做)**:
- MCP / 声明式 HTTP 自定义工具(已决策暂缓,§8 预留接口位)
- LLM 真跑预演(烧 token,价值/成本比待验证)
- 工具的细粒度权限(任何登录用户可试运行,反正只打测试账号)

## 3. 总体设计:三层能力

```
┌─────────────────────────────────────────────────────┐
│  PromptWorkbench(编辑器)                            │
│  ┌───────────────────┬───────────────────────────┐  │
│  │ 编辑/预览/对比     │ 右栏 Tab                   │  │
│  │                   │ 📖 执行史(现有)            │  │
│  │  ↑ 光标处插入      │ { } 变量面板 ←──────┐      │  │
│  │  ⚠ 占位符 lint     │ 🔧 工具面板         │      │  │
│  │                   │   ├ 目录/搜索/签名  │ 同源  │  │
│  │                   │   └ [试运行] ───────┼→ 测试 │  │
│  │                   │      真实返回 <─────┘  账号 │  │
│  └───────────────────┴───────────────────────┴──────┘  │
└─────────────────────────────────────────────────────┘
     第一层:上下文面板(看见) → 第二层:试运行(验证) → 第三层:扩展(后置)
```

核心原则:**一份契约,两处消费**——变量 schema 和工具目录既是 API 给编辑器的数据,也是运行时/引擎的依据,不允许两套描述。

## 4. API 契约草案

### 4.1 变量契约 `GET /systems/{slug}/stages/{stage}/context?date=YYYYMMDD`

引擎侧新增 `stage_var_schema(stage)`,从 manifest 阶段定义推导;`_stage_vars()` 运行时逻辑不动,schema 纯描述(同文件,天然同源)。

**带 `date` 时,派生变量(prev/weekday/gap)由服务端用与运行时同一套函数算出真值**(替换预览用,预览即所得;不带 date 只给 example):

```jsonc
// 响应(?date=20260824)
{
  "stage": "premarket", "kind": "single",
  "vars": [
    {"name": "date",    "desc": "目标交易日 YYYYMMDD", "example": "20260824", "value": "20260824", "source": "caller"},
    {"name": "prev",    "desc": "上一交易日(自动推算,跳过节假日)", "example": "20260821", "value": "20260821", "source": "auto"},
    {"name": "weekday", "desc": "星期(中文)", "example": "周一", "value": "周一", "source": "auto"},
    {"name": "gap",     "desc": "距上一交易日的自然日数", "example": "3", "value": 3, "source": "auto"}
  ]
}
```

- 系统设定 Prompt（如 slug=`system`）：返回空 vars + 说明"系统设定不做变量替换,任何 `{xxx}` 都是字面文本"
- 研究类阶段的调用方变量(如 `topic`)也出现在列表(source=caller)

### 4.2 工具目录 `GET /tools`

自省 `core/registry.TOOLS`(权威表,含 `get_us_market`)+ `tools/__main__.TOOLS` 分组:

```jsonc
{
  "tools": [{
    "name": "get_quotes", "group": "market", "write": false,
    "desc": "查多只股票报价。codes 是6位代码列表…",   // docstring 首行
    "doc": "…全文…",
    "params": [
      {"name": "codes",  "type": "list[str]", "required": true},
      {"name": "mode",   "type": "str", "required": false, "default": "live"},
      {"name": "date",   "type": "str", "required": false, "default": ""}
    ]
  }, …],
  "portfolios": [{"id": 107, "name": "纸面", "type": "paper", "has_positions": true}, …],  // 测试账号名下
  "test_user": {"id": 3, "display_name": "API测试"}
}
```

### 4.3 工具试运行 `POST /tools/{name}/call`

```jsonc
// 请求
{"args": {"codes": ["000021", "002463"], "mode": "live"}, "portfolio_id": 107}  // portfolio_id 可选
// 响应
{
  "name": "get_quotes", "portfolio": 107,
  "output": "【报价】\n000021 深科技 12.34 +1.2%…",   // LLM 看到的原始字符串
  "truncated": false,                                   // >8000 字截断并标注
  "write_warning": null                                 // 写工具时:"已写入测试账号组合 #107"
}
```

行为约束:
- **强制测试账号**:`set_context(portfolio_id 或测试账号默认组合, None, TEST_USER_ID)`;传入的 `portfolio_id` 必须 `owner_user == TEST_USER_ID`,否则 403
- `TEST_USER_ID` 读环境变量 `TOOL_TEST_USER`(默认 3=api-test@test.io,数据最全;测试里 monkeypatch 成隔离用户)
- 参数按签名校验:未知参数 400、缺必填 400、类型不符 400
- 未知工具 404

## 5. 前端交互草案

### 5.1 右栏 Tab 化(执行史不动,新增两页)

```
┌─ 编辑/预览/对比(Tab,现有) ──┬─ 右栏 ─────────────────┐
│                              │ [📖执行史][{ }变量][🔧工具] │
│ 【盘前分析 · 目标交易日       │                          │
│  {date}({weekday})…          │  {date}    目标交易日     │
│                              │  {prev}    上一交易日 ↖点击 │
│ ⚠ 未知占位符 {dat}           │            在光标处插入     │
│   (不在本阶段可用变量中)      │  {weekday} 星期(中文)     │
│                              │  {gap}     距上交易日天数  │
│ [保存新版本]                  │  来源:自动注入/调用时传    │
└──────────────────────────────┴──────────────────────────┘
```

### 5.2 触发式补全:`@` 工具 / `{` 变量(已拍板:方案 2)

```
编辑区打 @ → 工具浮层                      打 { → 变量浮层(天然语法入口)
┌────────────────────────────┐
│ 【盘前分析…                  │  @get_ ⟶ ┌──────────────────────┐
│                              │           │ get_quotes    查报价 │
│  @get█                       │           │ get_indices   查指数 │
│                              │           │ get_positions 持仓   │
│                              │           └──────────────────────┘
└────────────────────────────┘  { ⟶ ┌────────────────────┐
                                  │ {date}    目标交易日 │
                                  │ {prev}    上一交易日 │
                                  │ {weekday} 星期(中文) │
                                  └────────────────────┘
```

交互细节:
- **触发**:光标前一个字符是 `@`(工具)或 `{`(变量)即弹浮层;继续输入按前缀过滤(`@get_`、`{we`)
- **选择**:↑↓ 导航、Enter 插入、Esc/失焦关闭、鼠标点击也可选
- **插入产物**:变量 → `{name}` 原样;工具 → 引导句模板(可编辑),如 `- get_quotes(codes): 查多只股票报价…`。注意:白名单工具的签名+docstring 本来就会由 pydantic_ai 自动发给 LLM,prompt 里插的是**使用引导**(何时用/别用哪个),不是功能引用
- **边界**:`{{` 转义不触发(第二个 `{` 使前缀非法,浮层自动关);markdown 代码块内触发就 Esc,不强做语法感知
- **定位**:v1 浮层锚定编辑器左下角(不做光标像素级镜像定位,留作优化)
- 面板里的「插入说明」按钮保留(§5.3),三条入口(@ 触发/{ 触发/面板点击)共用一个插入函数
- 实现要点:复用已有 `taRef` 拿光标位置,TextArea onKeyDown 拦 ↑↓/Enter/Esc

### 5.3 工具面板

```
🔍 搜索…                          分组:market(10) account(3) …
┌ get_quotes ⚠无 ─────────────────┐
│ 查多只股票报价。codes 是6位…     │
│ 参数: codes*  [000021,002463]    │
│       mode   [live ▾]  date [  ] │
│ [▶ 试运行]  [插入说明]            │
│ ┌ 返回(即 LLM 看到的内容) ─────┐ │
│ │【报价】000021 深科技 12.34…  │ │
│ └─────────────────────────────┘ │
└─────────────────────────────────┘
```

- 「插入说明」= 在光标处插入文档行:`- get_quotes(codes): 查多只股票报价…`(prompt 里引导 LLM 用工具的参考)
- 写工具(execute/save_doc…)带 ⚠ 红徽标;试运行后提示"已写入测试账号组合 #107,不影响你的账户"
- 组合下拉:仅列测试账号名下组合(目录接口带出),默认选有持仓的纸面组合

### 5.4 占位符 lint + 替换预览

- **lint**:编辑时正则扫 `{xxx}`(排除 `{{}}` 转义),不在可用变量集 → 编辑器顶部黄条"未知占位符 {xxx},运行时会报错";**只警告不阻断保存**(待拍板 §7-Q3)
- **替换预览**:预览 Tab 加开关,按变量值表单(预填示例值)客户端替换,展示 LLM 将收到的最终文本;未覆盖占位符红色高亮
- 光标插入:复用已有 `taRef`(`resizableTextArea.textArea`,现已挂载未使用)

## 8. 扩展预留(本轮不做,记下方向)

- **@工具(...) 内联执行("prompt 即程序",远期)**:`@get_quotes(codes=["000021"])` 写进 prompt,`load()` 变量替换阶段**真的执行**并把返回文本内联进 prompt(类似变量替换但工具驱动)——可把盘前快照钉死进 prompt。语法与 §5.2 区分:带括号=执行,不带=说明引导。成本:失败处理/缓存/打哪个组合都要设计,运行时语义大改,故远期
- **MCP**(优先):pydantic_ai 2.29 原生 `MCPToolset`(Stdio/HTTP 传输)。manifest 或独立表配 `mcp_servers`,engine `build_agent` 挂载;MCP 工具复用同一套目录/试运行通道(调用路由到 MCP client)。stdio=宿主机执行代码,多用户场景需管理员门禁
- **声明式 HTTP 工具**(更远期,SaaS 安全):用户填 URL+参数映射生成工具,免代码
- 设计约束:目录/试运行的 API 形状现在就按"多来源工具"设计(`group` 字段预留 `builtin`/`mcp:xxx` 命名空间),扩展时前端零改动
