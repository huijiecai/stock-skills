## 1. 架构与工程结构

```
web/                          ← 新增:React SPA(Vite + TS + AntD)
├── src/api/                  ← API 客户端(fetch 封装,Bearer token 自动携带)
├── src/pages/                ← 路由页(见 §3)
├── src/components/           ← 思考流时间线/指标卡/版本 diff 等领域组件
└── vite.config.ts            ← dev 代理 → localhost:8501(API)
trader/api/                   ← 新增:平台 API 服务,与 core 平级(core 纯领域层不感知 HTTP)
trader/viewer/                ← 保留,降级为开发调试视图,逐步被 SPA 替代
```

- dev:前端 `npm run dev`(5173)代理 API(8501);build 后由 FastAPI 静态托管 `web/dist`,
  单进程部署(将来上云再拆)
- 认证:登录换 session token(§2),SPA 存 localStorage,请求头 `Authorization: Bearer`

## 2. API 契约(FE-0,M1.5 本体)

| 域 | 端点 | 说明 |
|---|---|---|
| auth | POST /auth/register、/auth/login、GET /auth/me、POST /auth/logout | 邮箱+密码(scrypt 已就绪);登录返回 session token |
| systems | GET/POST/PUT /systems、GET /systems/{name}/prompts、PUT /systems/{name}/prompts/{prompt}、GET /prompts/{name}/versions、GET diff | manifest 表单化读写 + **prompt 在线编辑**(版本库已就绪,md 退役在此完成) |
| ledgers | GET/POST /ledgers | 开账本(live 仅管理员) |
| runs | GET /runs?kind&date、GET /runs/{id}、GET /runs/{id}/rounds/{n}(轮日志+思考流)、GET /runs/{id}/metrics、GET /compare?a=&b= | 场次列表/详情/指标/对比 |
| trading | GET /positions、/account、/trades | 当前账本视图 |
| docs | GET /docs?doc_type&date、GET /docs/{id} | 报告阅读(预案/收盘/预期文档) |
| watchlists | GET/PUT /watchlists/{name}、GET /watchlists/{name}/as_of | 自选组管理+历史时点 |

铁律:全部端点带 `require_user` 依赖(core/identity 的三层校验),数据查询自动限定
当前 user——**API 层即多租户边界**。错误统一 JSON `{detail}`。

## 3. 页面清单(FE-1 MVP)

| 路由 | 页面 | 核心交互 |
|---|---|---|
| /login /register | 登录/注册 | 表单;登录后进工作台 |
| / | 工作台 | 今日场次+账户概览+快捷发起 |
| /runs | 场次列表 | 筛选(类型/日期);勾两场→对比 |
| /runs/:id | 场次详情 | 轮次时间线;点开=轮日志(md 渲染)+**思考流折叠流**(指令→工具→返回→推理,viewer 的强项平移) |
| /compare | 对比页 | 指纹一致性/版本差异/指标并排/归因结论 |
| /systems | 系统管理 | 列表+编辑器:阶段表单/工具白名单勾选/**prompt 编辑器(带版本 diff 与回滚)** |
| /docs/:type/:date | 报告阅读 | 预案/收盘/预期文档,md 渲染 |

FE-2(其后):账本管理页/用量计量页/建系统向导/自选组管理页。

## 4. 关键领域组件(一次写好,处处复用)

- **TranscriptTimeline**:思考流折叠组件(指令/工具调用/返回/推理分色)——场次详情与对比页共用
- **MetricsCards**:收益/回撤/胜率/盈亏比/计数 卡片组
- **PromptEditor**:编辑+保存新版本+任意两版 diff+回滚(版本库能力前端化)
- **ManifestForm**:阶段/工具白名单/联网开关的表单化(替代手写 JSON)
