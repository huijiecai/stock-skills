# trader 实现设计(v2.0)

> v1 作废:v1 的"系统=代码包(registry/store 类/扩展段)"意味着建新系统仍要写代码,
> 违背根本需求——**用户通过 Prompt 定义交易系统,平台只提供基础设施**。
> v2 铁律:平台是哑巴,系统是纯数据;建新系统 = 写 prompt + 插一行,零代码。

---

## 0. 一句话

**平台 = 通用件(行情/账本/文档/自选组/引擎/袋子/评估);交易系统 = PG 里的数据。**

---

## 1. 硬约束(每条都是验收标准)

1. **实盘不断档**:施工分 commit,切换类操作(C3)安排在非交易时段,且可回退
2. **CLI 兼容**:旧五命令(premarket/live/replay/close/research)保留为兼容别名;
   新增通用命令 `runner run <system> <stage> [args]`
3. **老数据不坏**:老 expectations/pool_members 表与老 run_* schema 冻结只读、
   永不 drop;老场次/轮日志/思考流继续可读(viewer 老场兼容)
4. **表只加不改**:现有表结构不动,变更全部是加列/加表
5. **零代码验收**:core/ 无"预期"字样、不存在 systems/ 代码目录;
   用纯 prompt+manifest 建一个玩具系统跑通回放(§10 C5)

## 2. 平台通用件(core,永不出现"为某系统写的代码")

| 通用件 | 内容 |
|---|---|
| **行情** market.py | 现 9 工具原样(live/replay 双模 + time 截断防未来) |
| **账本** ledger.py | Account(现金/持仓/fills,T+1,分计价)+ execute 下单 |
| **文档** documents | 万物记忆:预案/报告/轮日志/思考流/**预期条目**/任何产物;每篇带 meta JSONB;**每次保存留版本**(§7 versions) |
| **自选组** watchlist | 唯一结构化原语:命名的一篮子股票,成员带任意字段(role/reason/任何系统的任何标注) |
| **引擎** engine.py | 读 systems 行 → 按阶段定义跑 single/loop → 建袋/封场/算 metrics |
| **袋子** runs.py | 档案袋(**bag_id 行级隔离**,一场一个 bag_id,正本=bag_id 0;§7)+ 开局状态(§6)+ 指纹 |
| **评估** | metrics + 对比页 |
| viewer | 通用页面 |

**平台工具全集**(manifest 白名单从这里选):行情 9 + get_positions/get_account/
get_trades + execute + scan_market + save_doc/get_doc/list_docs/set_doc_meta +
watchlist 四件(save_watchlist / get_watchlist(**可传 as_of 查历史时点成员**)/
get_watchlist_quotes(组报价+X/Y 上涨统计)/ remove_watchlist_member)。

**execute 变更**:去掉 expectation_id 参数(老列保留冻结),reason 必填留痕不变,
整手/主板/T+1/单票 40% 闸不变。

**scan_market**:指数 + 持仓(±2% 标警)+ **【自选组快览】**(全部自选组状态自动
呈现,反注意力漂移机制平台化)+ 板块 top5 + 异动 top5。任何用自选组的系统自动受益。
快览按组全量呈现,不做 status 过滤(平台不知道 status);已结束预期的自选组由
prompt 约定处置(删除或改名 `archived-` 前缀,快览与 AI 约定忽略该前缀)。

## 3. 系统定义(systems 表,纯数据)

| 列 | 类型 | 说明 |
|---|---|---|
| id | IDENTITY PK | |
| name | TEXT UNIQUE | 如 "expectation";runs.system 指向它 |
| manifest | JSONB | 见下 |
| status | TEXT | active / archived |
| created_at / updated_at | TEXT | |

manifest 结构:

```json
{
  "system_prompt": "system",
  "stages": {
    "premarket": {"kind": "single", "prompt": "premarket", "request_limit": 200,
                   "vars": ["date", "prev", "weekday", "weekend_note"]},
    "live":      {"kind": "loop", "prompt": "round_live", "request_limit": 50,
                   "data_mode": "live", "clock": "real", "window": "09:35-15:05",
                   "skip_lunch": true, "log_type": "watch_live"},
    "replay":    {"kind": "loop", "prompt": "round_replay", "request_limit": 50,
                   "data_mode": "replay", "clock": "simulated", "interval": 5,
                   "window": "09:35-15:00", "skip_lunch": true, "log_type": "watch_replay"},
    "close":     {"kind": "single", "prompt": "close", "request_limit": 200},
    "research":  {"kind": "single", "prompt": "research", "request_limit": 200}
  },
  "tools": ["get_quotes", "get_indices", "...", "execute", "scan_market",
            "save_doc", "get_doc", "list_docs", "set_doc_meta",
            "save_watchlist", "get_watchlist", "get_watchlist_quotes"],
  "web_search": true
}
```

**运行时**:engine 读 systems 行 → prompt 从 prompt_versions 取最新版(运行时
不读文件)→ 注入阶段变量 → 按白名单组装工具 → 跑。封面记录当次 {prompt: 版本},
跑过的场不因后续编辑变化。

engine 通用能力(所有 loop 阶段共享):轮次计数与断点接续(按 log_type 轮日志)、
KEEP_ROUNDS 上下文裁剪、API 重试、思考流落库(transcript_{stage})、午休跳过、
收盘收工、T+1 结算。

## 4. 预期系统 = 平台上的第一个系统(零代码)

方法论本体(六份 prompt 的内容)原样保留,只改写工具调用:

| 原私有东西 | 变成(平台通用件) |
|---|---|
| expectations 表 | documents:一条预期一份 md(type='expectation',meta 存 stage/status/direction),thesis/催化/兑现/失效标志在正文 |
| pool_members 表 | watchlist:一条预期一个自选组,成员字段带 role/reason |
| get_expectations / get_pool | list_docs(type+meta 过滤)/ get_doc |
| update_expectation(stage/status) | set_doc_meta + 按需重写正文(版本史自动留痕) |
| get_pool_health(池 X/Y) | get_watchlist_quotes(通用组报价+上涨统计) |
| scan_market【预期池快览】 | 平台【自选组快览】 |
| knowledge_events | documents/watchlist 统一版本史(§7),免费副产品:预期演化史 |
| tools/knowledge.py、watch.py 池快览、store.Expectations | **删除**(C3);旧表冻结只读 |

**复盘关联双轨制**:机器层 = watchlist 每次变更落 versions(重新研究改池,旧池
永远可回放,get_watchlist(as_of) 直接查历史时点成员);人类层 = prompt 约定
决策文档(预案/轮日志/报告)引用池时**内联当时成员名单**——复盘读文档即所见,
versions 做交叉校验。单靠文档不够(研究后改池,成交时点状态丢失;机器不可查),
单靠 versions 也不够(复盘要现算,人读不了)。

**一次性迁移**:脚本把老 expectations/pool_members 转成 documents+watchlists
(老表不动,幂等可重跑)。

## 5. 实体与模式矩阵

| 实体 | 本期落地 | 以后 |
|---|---|---|
| User | 单用户,无表 | users + 认证 |
| 交易系统 | systems 一行 | viewer 在线建系统 |
| 交易账号 | 行级账本,正本 = bag_id 0(唯一) | 多账号 = account_id 列;券商关联 |
| 场次 Run | runs 表 | +system +metrics 列 |
| 档案袋 | bag_id(行级,一场一个) | 不变 |
| 文档/自选组 | documents + watchlists(行级,带 bag_id) | 不变 |

| | 实时数据 | 历史数据 |
|---|---|---|
| **正本袋** | 实盘 live ✓ | ❌ 禁止 |
| **副本袋** | 实时模拟(以后) | 模拟 replay ✓ |

副本永不回写正本。**"正本×历史=禁止"由 engine 强制校验**(replay 数据模式的阶段只允许非 0 bag),不是口头纪律。

## 6. 开局状态(OpeningState)三模式

| 模式 | CLI | 语义 | 时间安全 |
|---|---|---|---|
| fresh(默认) | 现状即默认 | 钱包从初始资金开始;**知识(文档+自选组)照常从正本复制**(= 现 replay 语义,模拟盘 AI 必须有同样的预期库) | ✓ |
| fork | `--fork` / `--fork-as-of D` | 复制正本现状 / 重建"截至 D 收盘"的正本状态(账本从 fills 折叠,文档与自选组从版本史折叠) | as-of ✓;fork 现状回放历史日带未来持仓,封面标 ⚠ |
| custom | `--custom wallet.json` | 手工指定现金+持仓;知识同 fresh 从正本复制 | 用户自担 |

fork = INSERT...SELECT 换 bag_id(fills 连 ≤ as_of 的历史一起),袋子自包含。封面全状态指纹 = 现金+持仓+文档
+自选组的规范化哈希,对比页校验起点一致。

**事件史起点边界**:versions 从 C1 上线才开始记录;更早日期的 as_of / fork-as-of
退化为"迁移时快照"(老预期数据一次性迁入 documents/watchlists,没有更早的事件可折叠)。

## 7. 表结构变更(只加不改)

| 对象 | 变更 | 用途 |
|---|---|---|
| **全部业务表加 bag_id(正本=0)** | positions / fills / documents / watchlists / watchlist_members / versions;现金按袋挂新表 wallets(bag_id, cash_cents, **initial_cents**) | **行级多租户,替代 schema 隔离**:单库单 schema;删袋 = 事务内 DELETE WHERE bag_id;fork = INSERT..SELECT 换 bag_id;多用户时不爆炸;initial_cents 是 metrics 收益基准 |
| 新表 systems(库级) | §3 | 系统定义正本 |
| runs | + system TEXT / + metrics JSONB / **+ bag_id INTEGER(live 场=0,replay 场=它的袋)** | 归因与指标;每场写哪个袋子在此登记 |
| fills | + run_id INTEGER(老数据 NULL;expectation_id 老列冻结不写) | 成交→场次→系统版本 归因;bag_id=隔离键,run_id=版本归因键(经 runs 互查) |
| documents | + meta JSONB | 结构化过滤(stage/status/type 级查询) |
| 新表 versions | (bag_id, subject_type='document'/'watchlist', subject_id, action, payload JSONB, ts),只追加 | **成员级/文档级变更各一条**(加/剔成员/改字段/改正文);回放可重建任意时点;全系统演化史;复盘关联的机器层依据 |
| 新表 watchlists + watchlist_members | (带 bag_id)name + 成员(code, fields JSONB) | 唯一结构化原语 |
| prompt 运行时 | 改读 prompt_versions(不再读文件) | md 仅临时编辑面(附录 8) |
| 老 expectations/pool_members 表 + 老 run_* schema | 全部冻结只读,永不 drop(老场 viewer 兼容读冻结数据;新数据一律走 bag_id 行级表) | 老数据兼容 |

## 8. 场次指标(封场时 engine 自动算,存 runs.metrics)

收益(期末资产 vs 初始)/ 净值曲线与最大回撤(由 fills 推算,粒度=成交时点)/
胜率与盈亏比(平仓回合)/ 计数(交易数/轮次/tokens)。对比页读库。

## 9. runner / viewer 改造

- **runner**:薄壳。通用命令 `run <system> <stage> [args]`;旧五命令 = expectation
  系统对应阶段的兼容别名;replay 增 --fork / --fork-as-of / --custom
- **viewer**:通用页不动逻辑;新增自选组页;文档列表支持 meta 过滤(预期视图 =
  type='expectation' 的文档集);对比页读 metrics;老场兼容(读冻结旧表渲染历史)
