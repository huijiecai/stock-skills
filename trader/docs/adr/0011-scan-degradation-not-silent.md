# ADR-0011: 快扫分段降级,禁止静默降级

- 状态:已接受
- 日期:2026-08-17(停机静默降级事故日)
- 相关代码:`trader/core/scan.py`

## 背景

快扫(指数/持仓报价/自选组快览/板块 top5/异动 top5)依赖多个数据源
(astock CLI→ClickHouse)。8/17 事故:数据源停机期间快扫静默降级近 1 小时——
返回内容看似正常,AI 以为已完成市场感知,实际一直在用残缺数据看盘。

## 决定

降级容忍但**绝不静默**:某数据段取不到时该段标注降级原因,输出顶部加显著警示,
让 AI 明确知道"本轮感知不完整";不让整轮快扫因单段失败而整体失败。

## 后果

- 正:AI 看到的永远是"真实可得性"的市场图景,感知缺口被显式暴露,可以把
  降级纳入判断(如"数据缺失,本轮只观察不下单")。
- 负:输出更长(每段要带状态);警示依赖 AI 真的会读——这是 prompt 层的责任,
  系统 prompt 需强调"看到降级警示必须 acknowledged"。
- 推广:凡"外部数据可能不可得"的工具都适用同一原则——降级可以,静默不行。
