# 架构决策记录(ADR)

架构决策不再寄生在代码注释里。每个够格的决策(事故驱动/有多种合理选项/推翻代价高)
在此落一篇短记录,代码注释只留一句话 + 引用编号(如 `见 ADR-0003`)。

## 格式

每篇一个文件 `NNNN-kebab-case.md`,三段式:

```
# ADR-NNNN: 标题

- 状态:已接受 | 已废弃(被 ADR-XXXX 取代)
- 日期:决策日期(事故驱动的记事故日)
- 相关代码:主要落点

## 背景    —— 当时面对什么问题/约束,有哪些选项
## 决定    —— 选了什么,一句话能说清
## 后果    —— 正/负影响,推翻它需要做什么
```

规则:决策只增不改;推翻旧决策 = 新写一篇并把旧的状态改为"已废弃"。
