# ADR-0001: 倒计时按墙上时钟,机器睡眠不补睡

- 状态:已接受
- 日期:2026-08-21(run 336 事故日)
- 相关代码:`trader/core/engine.py::_interruptible_sleep`、`tests/test_engine_loop.py`

## 背景

live 看盘按 interval 倒计时进入下一轮。旧实现用"累计已睡时长"判断倒计时是否完成。
2026-08-21 run 336:午休 90 分钟倒计时期间 macOS 系统睡眠 2 小时,唤醒后旧实现继续
数完剩余分钟——`time.sleep` 在系统睡眠期间不走,累计时长远远落后墙上时钟,
整场看盘被拖过收盘。

## 决定

倒计时以**墙上时钟 deadline** 为准:分片睡眠,每片醒来对比当前时刻与 deadline,
过期立即返回,绝不"补睡"系统睡眠期间欠下的时长。

## 后果

- 正:机器睡眠/挂起后恢复,轮次立刻对齐真实时刻,不会拖场。
- 负:睡眠期间错过的轮次被跳过而非补跑——看盘场景正确(过期行情无意义),
  若将来有需要补跑的批处理型循环,不能复用此函数。
- 护栏:`test_interruptible_sleep_wakes_after_machine_sleep` 模拟系统睡眠 2 小时,
  断言分片数 ≤2(发现过期即退出,而非数完 540 个分片)。
