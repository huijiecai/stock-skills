# 预期驱动交易系统：核心逻辑总结

> **目的**：把当前系统（trading-system v2）的交易逻辑提炼成投资人视角的一份总结，作为下一版系统讨论与升级的共同基准。
> **范围**：只讲交易逻辑——怎么理解市场、怎么决策买卖；不讲文件、工具与执行细节。
> **事实基准**：核心框架 + 买卖规则 + 62 条实战教训沉淀后的现行规则。
> **实绩背景**：2026-03-26 起 10 万虚拟账户运行约 5 个月，96 笔交易，+8.8%。

---

## 一、这套系统是什么

**一句话：预期驱动，三维确认决定买卖，纪律执行。**

**赚的是什么钱**：市场对某个产业预期**重新定价过程**的钱。路径是：新催化出现 → 增量资金进场为它定价 → 定价完成（利好落地/数据见顶）。系统不预测预期会不会出现，只做三件事：

```
识别资金正在投票的预期 → 等三维确认后跟随买入 → 预期兑现或资金撤退时退出
```

三条底层信念：

1. **资金认可就是最好的确认力**——有增量资金进场就有承接力；没有资金响应的逻辑再好也是空气。
2. **信号是感知，不是触发**——涨停数、换手、成交额只回答"市场结构在发生什么"，禁止机械阈值（"涨停<30就不买"这类规则不存在）。
3. **低频但确定**——不猜、不赌、不扛；条件不齐宁可错过。

---

## 二、五个核心概念

| 概念 | 定义 |
|---|---|
| **预期** | 市场资金正在投票的产业方向或事件催化（不是"我觉得会涨"） |
| **三维确认** | 预期成立的判定：资金投票（广度）× 价格响应（深度）× 可验证依据（锚点），缺一 = 未确认 |
| **龙头** | 直接受益池内最先发动、最强、成交最主动的标的 |
| **买点** | 仓位大小的唯一依据：由"预期被资金认可的程度"决定 |
| **出口** | 卖出的唯一通道：出口A（预期结束）或出口B（交易确认失败） |

**三维确认**是全系统的心脏，本质是回答三个问题：

| 维度 | 问题 | 典型信号 |
|---|---|---|
| 资金投票（广度） | 有多少在涨？ | 方向内多只同步走强 |
| 价格响应（深度） | 领涨的走出来了吗？ | 龙头涨停/放量突破/回踩企稳 |
| 可验证依据（锚点） | 逻辑被数据验证了吗？ | 期货涨价、业绩超预期、政策落地 |

三者缺一的诊断：只有逻辑没有资金 = **空气**；只有异动没有锚点 = **噪音**；只有资金没有价格响应 = **未兑现**。

**预期类型三分**（决定退出信号怎么定义）：

| 类型 | 特征 | 退出信号 |
|---|---|---|
| 持续数据型 | 有月频以上可追踪的数据锚 | 数据见顶/破位 |
| 事件节点型 | 明确的一次性事件 | 事件兑现/取消 |
| 实时感知型 | 无外部数据，纯资金行为 | 龙头A杀/联动消失 |

## 三、预期的时间结构：五阶段生命周期

```
出现期 → 确认期 → 加速期 → 兑现期 → 结束期
```

| 阶段 | 特征 | 系统动作 |
|---|---|---|
| 出现期 | 新催化首次爆发，尚未验证 | 观察；首板买点 1-1.5 成 |
| 确认期 | 二次走强（经历分歧仍延续） | **主战场**：确认买点 3 成 |
| 加速期 | 主升浪，梯队完整 | 无买点；持仓可持不加 |
| 兑现期 | 利好落地，数据见顶 | 只卖不买（卖事实） |
| 结束期 | 龙头A杀，联动消失 | 空仓等新预期 |

两个关键判断：

- **分歧 ≠ 结束**（全系统最重要的区分）：预期依据还在被验证 = 分歧（筹码交换，方向观察窗口）；依据被否定 = 结束（资金离场，空仓窗口）。单次炸板、一日大跌、换手升高都只是分歧。
- **加速期才发现 = 盘前覆盖不足**，不追。兑现期/结束期永远没有买点。

---

## 四、买入逻辑链

**前提门槛（顺序不可跳，任一不满足 = 不买）**：

1. **预期已入库**——没有研究文件的方向不能买（逼着先想清楚再动手）
2. **存在可验证的新催化**——旧故事没有增量信息，不构成新买入理由
3. **三维确认齐全**——缺一不买，无例外
4. **锁定三件事**——买前写下：预期是什么 / 兑现标志是什么 / 失效标志是什么。**买前锁定，买后不改**，此后所有持仓决策只对照这三件事评估
5. **归因四行**——具体事件 → 最短传导链 → 直接受益池 → 联动结论。池必须**先于行情建立**，行情只验证，不反向拼池

**选股**：

- 只在**直接受益池**内选：直接销售催化产品者、已验证的销量/订单受益者。相邻题材、成本受压者一律排除
- 龙头按**领涨性 / 主动性 / 高位性**确认，且必须在归因成立后才可确认
- **识别与执行隔离**：龙头封死买不到 → 依次评估池内第二、第三名；但执行困难不否定龙头身份

**账户级排序**（多个合格机会同批出现时）：

- 比较五维：预期新鲜度 → 资金确认质量 → 龙头质量 → 买点质量（分歧修复优于一致加速）→ 账户风险
- **同批最多执行前 2 名**；排序落后或风险预算满 = 合规放弃（记录放弃代价），不因还有现金而机械买入

**买点类型决定仓位**：

| 买点 | 出现时机 | 初始仓位 | 性格 |
|---|---|---|---|
| 确认买点 | 分歧后资金重新入场（含同日分歧修复） | 3 成 | 最安全 |
| 首板买点 | 新催化首板，本轮没涨过 | 1-1.5 成 | 要快 |
| 回调买点 | 已涨一波 + 首次回调 + 依据未破 | 加至 3 成 | 要准 |

设计哲学：**仓位 = 当前时刻预期被资金认可的程度**；单主题 3 成上限是为了容纳意外，不是表达信心高低。

**执行时机**：确认完成当下执行——竞价确认就竞价买，半路确认就当下买，封板（非一字）就排板，一字板放弃。不因主观大盘判断给仓位打折。

## 五、卖出逻辑链：双出口（本系统最独特的设计）

**系统不设纯价格止损**：跌破某条价格线不能独立构成卖出理由；任何卖出条件必须能回答"它和买入时锁定的预期是什么关系"。

每次持仓评估**必须同时检查两个相互独立的出口**：

**出口A：预期退出（方向级）**
- 触发：进入兑现期/结束期，或预期依据被否定
- 动作：清仓，预期归档
- 含义：本轮故事讲完了

**出口B：交易确认退出（交易级）**
- 触发：买入时的资金确认失败——受益池从成片上涨退化为孤票 / 龙头失去领涨性且反抽无承接 / 价格响应失败 / 放量下跌资金撤退——**≥2 个信号 + 资金撤退确认**
- 动作：首日减仓 30-50%；次日未恢复或三维整体消失 → 清仓
- 含义：本次交易失败，但**方向可以继续观察**（预期保留、降级）

**双出口的本质**：把"方向判断"（预期库）和"交易判断"（持仓）解耦——预期没死 ≠ 必须死扛持仓；交易退出 ≠ 方向死亡。分歧保护方向，不保护交易。

配套纪律：

- 分歧中的持仓仍须检查出口B（不能拿"方向未结束"强迫持仓）
- 卖出后重入：出口A离场须新催化重新研究；出口B离场须重新完成三维确认（价格反弹本身不是买入理由）
- 同一证据只消费一次，防重复减仓

## 六、持仓管理

- **建仓**：首次建仓为目标仓位的 50-70%
- **加仓**：必须独立满足一种买点类型 + 预期依据继续验证 + 风险预算允许；**价格创新高不能独立构成加仓理由**；一致加速阶段不加仓
- **减仓**：部分兑现减 30-50%，完全兑现清仓
- **龙头切换**：老龙头断板时，不问"龙头换没换"，**回到买入时锁定的三件事**——龙头是观察预期状态的窗口，不是持仓的理由
- **多主题并发**：不同主题各自独立（各最多 3 成）；现有持仓没有卖出理由时，不为新机会强行腾仓

## 七、账户级硬约束（风控骨架）

| 约束 | 规则 |
|---|---|
| 单主题仓位 | 最多 3 成 |
| 共同风险因子 | 同一次风格切换中会同步撤退的主题合并计算，最高 6 成 |
| 同批机会 | 最多执行排序前 2 名 |
| 品种 | 仅沪深主板（300/301/688 排除） |
| 交易规则 | T+1、整手、14:50 后不开新仓 |
| 冷静期 | 当日累计亏损 >5% 禁止开新仓 |
| 复盘标准 | **赚钱违规 = 错误 / 亏钱合规 = 正确**（纪律一致性高于单次盈亏） |

共同风险因子的判断标准是"资金是否会在同一次风格切换中同步撤退"，不看产业链名称（如存储+PCB+CPO+MLCC 同受科技风险偏好驱动 = 一个因子）。

## 八、市场感知：预期从哪里来

**预期来源**：产业催化（涨价/缺货/扩产/技术突破）、政策事件、资金异动。

**发现顺序（固定，不可倒置）**：

```
全市场发现异动候选（只是候选，不是龙头）
→ 搜索市场正在交易的具体预期（公告/新闻/媒体/雪球）
→ 根据预期列出关联股票（池先建后验）
→ 核心关联股成片同步上涨 = 归因成立
→ 池内最先发动且最强的才是龙头
→ 最后才做可交易性检查
```

**反噪音三原则**：

- **概念标签 ≠ 归因结论**——"PCB涨停"是标签，"覆铜板涨价+中报兑现"才是催化；每只涨停股只归入一个主驱动方向
- **大叙事反向拆解**——某方向 ≥20 涨停时必须检查跟风股有没有独立催化
- **连板股独立归因**——连续涨停的个股不能因为"大方向在爆发"就归入大方向

**倒计时催化**：即将到期的涨价日/政策日/数据日会打破历史规律，显著提升延续概率——判断延续性看"有没有新出现的独立催化倒计时"，不看历史统计。

---

## 九、系统明确不做的事

- **不预测**：不预判催化会不会出现，只跟随已出现且被资金确认的催化
- **不择时**：大盘判断只提高复核优先级，不构成独立的开/平仓理由（大盘共振只是加分确认）
- **不做估值**：不问贵不贵，只问资金认不认
- **不做对冲**：单向做多，无做空、无对冲工具
- **不抄底摸顶**：只吃确认期到兑现期之间的一段，头尾都让给别人

---

## 十、系统的隐含假设（升级讨论的靶子）

1. **资金投票有效性假设**：增量资金的方向性流入是预期真实性的最终裁判——所以系统跟随资金、不预判资金。若资金行为被操纵（庄股、假联动），系统没有防御层。
2. **短周期假设**：催化定价在数个交易日内完成（确认买点持有约 3-5 天、首板 5-10 天、回调 10-20 天）。系统本质是**短线波段**，慢变量（渗透率提升、季度业绩趋势）在系统时间尺度内不可验证、不可交易。
3. **A股微结构假设**：涨停板制度、T+1、散户情绪使涨停/联动/封单成为信息密度最高的信号载体。市场制度一变，信号体系需重建。
4. **归因质量假设**：归因链条正确是三维确认、龙头、出口全部判断的地基。系统对"归因错误"只有一道事前防线（联动验证），没有内部纠错机制，主要靠事后教训。
5. **纪律一致性假设**：规则全集的效力 = 执行一致性。62 条教训中约半数是**执行偏差**而非规则缺陷（记了数据没做检测、把流程当门槛、快扫退化为盯价格）——规则与执行的分离是当前系统最大的风险源。
