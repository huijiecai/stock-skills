# 预期驱动交易系统 V3：核心逻辑总结

> **目的**：V3 = V1（三维确认规则）+ V2（市场环境层）+ 一轮以真实交易者视角的问题修订。V3 不推翻前两版的规则方向，但修正四个结构性问题：① 出口可执行性假设；② 分歧/撤退的判别；③ "确认即买不到"的逆向选择；④ 成本结构与频率。并诚实标注样本边界。
> **范围**：只讲交易逻辑——怎么理解市场、怎么决策买卖；不讲文件、工具与执行细节。
> **版本关系**：V1 回答"三维确认怎么判定"；V2 追加"资金投票可不可信（环境）"；V3 回答"确认之后，买卖真的执行得了吗"。
> **实绩背景**：2026-03-26 起 10 万虚拟账户运行约 5 个月，96 笔交易，+8.8%（V1 规则期实绩）。V2 环境层与 V3 修订均为新增，待实盘/回测验证。**样本边界：该实绩只覆盖偏多行情，缩量熊市未经历（见第十一章第 8 条）。**

## 一、这套系统是什么

**一句话：预期驱动，三维确认（按类型加权）+ 环境校准 + 出口可执行性纪律，纪律执行。**

**赚的是什么钱**（与 V1 相同）：市场对某个产业预期**重新定价过程**的钱。路径：新催化出现 → 增量资金进场为它定价 → 定价完成（利好落地/数据见顶）。系统不预测价格方向，只做三件事：

```
识别资金正在投票的预期 → 等确认后跟随买入 → 预期兑现或资金撤退时退出（且保证退得掉）
```

三条底层信念（V1 相同 + V3 修正）：

1. **资金认可就是最好的确认力**——有增量资金进场就有承接力；没有资金响应的逻辑再好也是空气。
2. **信号是感知，不是触发**——涨停数、换手、成交额只回答"市场结构在发生什么"，禁止机械阈值。执行验证（竞价量、承接结构、板块同步）看的是**资金行为**，不是价格幅度数字——见第五章。
3. **低频但确定**——不猜、不赌、不扛；条件不齐宁可错过。低频不是日历约束，是预期驱动的自然结果：处于确认期的方向就那么多，没有新预期就不开仓；成本审计负责防止"同一预期反复进出"造成的磨损（见第八章）。

**V3.1 设计红线——数字只允许出现在两个地方**：市场判断（信号感知、买点确认、退出触发）一律回归预期本身，禁止固定数字；数字只允许用于①**账户级风险约束**（仓位上限、批次上限、冷静期、回撤熔断、成本审计——保护账户，不判断市场）与②**执行纪律**（已触发出口的卖出时点与不可延期——保证执行，不判断市场）。判断层的每一条规则都必须能指认到"资金在为什么投票、投票质量如何、依据还在不在被验证"。

**V3 新增两条认知**：

- 确认的有效性受**环境**调节（V2）；确认之后，**退出必须可执行**——任何"卖得出"的假设都必须配应急路径（见第六章）。
- 系统的 edge 假设集中在**归因质量**与**出口纪律**，两者均未被当前样本证实；"不预测"的准确表述是：不预测价格方向，但预测"归因链条成立"与"同类事件模式可参考"（见第十章）。

## 二、六个核心概念

| 概念 | 定义 |
|---|---|
| **预期** | 市场资金正在投票的产业方向或事件催化（不是"我觉得会涨"） |
| **三维确认** | 预期成立的判定：资金投票（广度）× 价格响应（深度）× 可验证依据（锚点）；**确认要求按预期类型加权**（见下） |
| **龙头** | 直接受益池内最先发动、最强、成交最主动的标的 |
| **买点** | 仓位大小的依据：由"预期被资金认可的程度 × 环境系数"决定（执行质量通过买点档位体现，不另设系数） |
| **出口** | 卖出的唯一通道：出口A（预期结束）或出口B（交易确认失败）；**出口必须可执行** |
| **环境** | 资金投票的能力（量能承载力）× 意愿（事件不确定性）的总背景；三维确认可信度的调节器，不是买卖开关 |

**三维确认（按类型加权）**：三维确认回答"资金有没有在投票"。不同类型预期的锚点来源不同、确认强度天然不同，V3 明确各自的确认要求：

| 类型 | 锚点来源 | 确认要求 | 强度 |
|---|---|---|---|
| 持续数据型 | 最新一期数据仍在验证（涨价/销量/订单） | 标准三维全齐 | ~3 维 |
| 事件节点型 | 事件已官宣 + 历史模式可参考 + 倒计时在场（三者齐，见下） | 三维 + 锚点三条件；锚点未齐只许小仓 | ~2.5 维 |
| 实时感知型 | 无外部锚（资金行为即锚） | **广度、深度双强**：同步走强票更多、龙头更硬；锚点维度由广度+深度替代 | ~2 维 |

确认强度的差别是设计事实，不是缺陷：实时感知型没有外部裁判，所以要求盘面证据更强；事件节点型买入时事件未发生，锚点天然薄一档，靠"官宣+历史+倒计时"补。

**事件节点型的入场锚点标准**（V2.1 保留）：三者同时成立，缺一 = 锚点未齐全：

1. **事件已官宣**——日程、规则、标的范围明确（政策发布日、财报披露日、谈判时间表），"传闻中"的事件不算；
2. **历史模式可参考**——同类事件在历史上可查证的市场反应路径（启动-兑现节奏），不是第一次见；
3. **倒计时催化在场**——距事件落地 ≤3 日且盘前可跟踪。

锚点未齐全时，只允许小仓试（首板 1 成 × 环境系数），或直接等事件落地后重新三维确认再进场。

**预期类型三分决定"最终裁判"，不决定日常退出**（V3 修正）：短持仓期（3-5 天）内，月频数据锚不会更新——**日常退出由出口B（价格与广度行为）主导；出口A 是方向级的最终裁判，在持仓期内几乎不触发**。类型三分定义的是"什么算依据被否定"（数据见顶 / 事件兑现 / 龙头A杀），而不是"第几天该卖"。

## 三、市场环境层

**环境 = 能力 × 意愿。**

### 3.1 量能承载力（能力）——市场有没有钱

- **机制**：封板需要持续资金吃掉卖压；个股成交额越大，封板需要的资金越多；全市场成交额是攻击资金的池子。量能充裕时有**增量资金**进场接力，萎缩时是**存量博弈**——钱在板块间轮动而非净流入。
- **现象**（观察基准）：量能约 3 万亿时，足以支撑成交百亿级乃至 200 亿级的个股涨停；约 2 万亿时，成交超 50 亿已很难封住。
- **量化口径（相对量能）**：当日两市成交额 ÷ 近 20 日均量。绝对数随市场扩容漂移，一律用相对数：
  - ≥ 1.2 → 量能充裕（增量资金主导）
  - 0.8–1.2 → 正常（存量为主）
  - < 0.8 → 萎缩（纯存量博弈）
- **对执行的影响**：量能是同步/滞后指标——全天量能盘中才知。竞价买入只能用昨日趋势 + 早盘半小时量能节奏做前置判断；半路/午后买点可用当日量能实时过滤。

### 3.2 事件不确定性（意愿）——资金想不想投

- **机制**：市场等待二元结果事件（美联储会议、财报、谈判落地）时存在两类成本：风险溢价（不确定 → 观望）与相关性风险（**事件结果可能直接否定当前逻辑**——谈判破裂则出口数据再强也没用）。
- **现象**：等待期即使板块数据超强，资金也不进攻；事件落地且符合预期后，压抑资金集中释放 → 广度突然打开。
- **量化口径（事件日历）**：未来 3 日内是否有重大事件（会议/数据/谈判/财报）。有 → 事件等待期。
- **关键认知**：事件等待是**市场级分歧**，不是结束。事件落地日 = 盘前覆盖优先级最高的日子——压抑资金的释放往往就是确认期买点窗口。

### 3.3 环境系数

两因素组合成环境档位，作用于**确认标准**与**仓位系数**（同时满足多档条件时取更低档，即更严的处理）：

| 档位 | 量能 | 事件 | 仓位系数 | 确认标准 |
|---|---|---|---|---|
| 进攻 | ≥ 1.2 | 无 | 1.0 | 标准三维确认 |
| 常态 | 0.8–1.2 | 无 | 1.0 | 标准三维确认 |
| 等待 | 任意 | 有重大事件 | 0.8 | 非事件相关方向暂缓确认；事件相关方向等落地后跟随 |
| 萎缩 | < 0.8 | 任意 | 0.7 | 锚点要求更硬 + 广度更高；龙头默认限中小流通盘 |

**仓位应用**：买点基础仓位 × 环境系数。例：确认买点 3 成 × 0.8 = 2.4 成；首板 1.5 成 × 0.8 = 1.2 成。

**龙头体量上限（V3 修正）**：萎缩档默认只选中小流通盘标的；但加一条**反证条款**——若萎缩期出现大市值龙头**超预期封板**（封单/成交强度异常强），这恰是缺钱环境下最硬的资金投票证据，**视为环境档位上调信号**，该标的按正常流程评估，并作为环境可能转暖的领先观察点。约束不允许丢弃最强证据。

**待验证假设**（可用历史数据验证）：入场日相对量能越低，出口B 触发率越高；事件等待期内建仓的胜率显著低于事件落地后。

## 四、预期的时间结构：五阶段生命周期

```
出现期 → 确认期 → 加速期 → 兑现期 → 结束期
```

| 阶段 | 特征 | 系统动作 |
|---|---|---|
| 出现期 | 新催化首次爆发，尚未验证 | 观察；首板买点 1-1.5 成 |
| 确认期 | 二次走强（经历分歧仍延续） | **主战场**：确认买点 3 成 |
| 加速期 | 主升浪，梯队完整 | 无买点；持仓可持不加 |
| 兑现期 | 利好落地，数据见顶 | 只卖不买（卖事实） |
| 结束期 | 龙头A杀，联动消失 | 空仓等新预期 |

两个关键判断（与 V1 相同）：

- **分歧 ≠ 结束**：预期依据还在被验证 = 分歧（筹码交换，方向观察窗口）；依据被否定 = 结束（资金离场，空仓窗口）。单次炸板、一日大跌、换手升高都只是分歧。
- **加速期才发现 = 盘前覆盖不足**，不追。兑现期/结束期永远没有买点。

**V2 的环境视角**：

- 市场级事件等待 ≈ 市场级分歧窗口：预期依据还在等裁判 → 观察方向、不进攻；事件落地且符合预期 = 压抑资金释放 → 正是确认期买点窗口。
- **加速期对环境最敏感**：量能不足时大市值龙头封不住 → 加速可能夭折。环境档位下调时，加速期持仓可持不加、优先兑现。

**V3 补充**："分歧 ≠ 结束"是方向级认知；落到单笔持仓上，必须用第六章的**判别清单**把"分歧（持有）"和"资金撤退（出口B）"分开——禁止用"方向没结束"强迫持仓。

## 五、买入逻辑链

**前提门槛（顺序不可跳，任一不满足 = 不买）**：

1. **预期已入库**——没有研究文件的方向不能买（逼着先想清楚再动手）。
2. **存在可验证的新催化**——旧故事没有增量信息，不构成新买入理由。
3. **三维确认齐全**——缺一不买，无例外（按第二章的类型加权要求执行）。
4. **锁定三件事**——买前写下：预期是什么 / 兑现标志是什么 / 失效标志是什么。**买前锁定，买后不改**，此后所有持仓决策只对照这三件事评估。
5. **归因四行**——具体事件 → 最短传导链 → 直接受益池 → 联动结论。池必须**先于行情建立**，行情只验证，不反向拼池。
6. **环境检查**（V2）——盘前记录两件事：相对量能（昨日成交额/20日均量）、未来 3 日事件日历。环境档位不构成买卖开关，只决定确认标准与仓位系数。

**选股**（与 V1 相同 + V3 修正一条）：

- 只在**直接受益池**内选：直接销售催化产品者、已验证的销量/订单受益者。相邻题材、成本受压者一律排除。
- 龙头按**领涨性 / 主动性 / 高位性**确认，且必须在归因成立后才可确认。
- **识别与执行隔离**：龙头封死买不到 → 依次评估池内第二、第三名；但执行困难不否定龙头身份。
- **龙头体量上限**（V3 修正）：默认受环境档位约束（3.3）；萎缩期大市值龙头超预期封板视为环境上调信号，不机械否决。

**账户级排序**（与 V1 相同）：比较五维：预期新鲜度 → 资金确认质量 → 龙头质量 → 买点质量（分歧修复优于一致加速）→ 账户风险。同批最多执行前 2 名；排序落后或风险预算满 = 合规放弃（记录放弃代价），不因还有现金而机械买入。

**买点类型决定仓位（V3 新增第 4 种买点）**：

| 买点 | 出现时机 | 基础仓位 | 性格 |
|---|---|---|---|
| 确认买点 | 分歧后资金重新入场（含同日分歧修复） | 3 成 | 最安全 |
| 首板买点 | 新催化首板，本轮没涨过 | 1-1.5 成 | 要快 |
| 回调买点 | 已涨一波 + 首次回调 + 依据未破 | 加至 3 成 | 要准 |
| **炸板回封买点（V3 新增）** | 池内龙头（首板/连板）炸板后快速回封（当日） | 2 成 | 要快、要准 |

**为什么新增炸板回封**：三维确认最标准的场景是龙头封死买不到；"炸板回封"是少数能买到真龙头的时刻——资金炸板后重新夺回控制 = 承接最强、分歧转一致的实时证据。它同时缓解"确认即买不到、实际成交总是二流"的结构性逆向选择。质量看资金行为、不看时钟：**回封越快速**（炸板后短暂换手即重新封死 = 分歧被快速消化）越强，长时间震荡才回封 = 分歧加深、不追；**回封需放量配合**（新资金进场），无量回封视为诱多；**回封后二次开板 = 资金没能守住 = 实时确认失败，放弃**。

**执行质量与降级（V3.1 重写）**——执行环节的验证同样回归预期本身，不设价格数字：

- **竞价买入验证**：竞价买入成立的条件是"竞价反映预期延续，而非兑现"——竞价量能较昨日同期放大（资金在抢而非在出）、竞价承接主动（大单扫货式高开，而非高开低走式出货）、板块竞价同步（方向内多只高开 = 预期延续；孤票高开 = 独立兑现，不买）。三条不齐 → 放弃竞价买，改半路或回封。高开幅度本身不是依据，幅度要结合"资金为什么高开"来读。
- **降级买入**：龙头买不到而执行池内第二、三名时，不设固定折扣，但该标的必须**独立满足归因成立 + 联动验证**（不是"龙头买不到随便买个近的"），且仓位不超过它**自有确认质量**对应的档位——通常低于龙头买点一档。建仓后前 3 个交易日未走出自己的领涨性（转强标准：独立领涨而非跟随龙头）即触发出口B 复核。

**设计哲学**（V1+V2 保留 + V3）：**仓位 = 当前时刻预期被资金认可的程度 × 环境系数**；单主题 3 成上限是为了容纳意外，不是表达信心高低。环境系数只允许下调、不允许上调；执行质量不另设系数，通过买点档位与竞价/回封验证体现。

**执行时机**（与 V1 相同 + V2/V3 补充）：

- 确认完成当下执行——竞价确认就竞价买（须过竞价验证清单），半路确认就当下买，封板（非一字）就排板，一字板放弃。不因主观大盘判断给仓位打折。
- **量能过滤的适用时点**（V2）：竞价买入时量能只做前置参考（昨日趋势 + 早盘半小时节奏）；半路/午后买点可用当日相对量能实时过滤。

## 六、卖出逻辑链：双出口 + 出口可执行性纪律

**系统不设纯价格止损**（与 V1 相同）：跌破某条价格线不能独立构成卖出理由；任何卖出条件必须能回答"它和买入时锁定的预期是什么关系"。

**出口A：预期退出（方向级）**
- 触发：进入兑现期/结束期，或预期依据被否定
- 动作：清仓，预期归档
- 含义：本轮故事讲完了（持仓期日常很少触发，见第二章"最终裁判"）

**出口B：交易确认退出（交易级）——日常退出的主导通道**
- 触发：买入时的资金确认失败——受益池从成片上涨退化为孤票 / 龙头失去领涨性且反抽无承接 / 价格响应失败 / 放量下跌资金撤退——**≥2 个信号 + 资金撤退确认**
- 动作：首日减仓 30-50%；次日未恢复或三维整体消失 → 清仓
- 含义：本次交易失败，但**方向可以继续观察**（预期保留、降级）

**分歧/撤退判别清单（V3 新增）**——同一根放量阴线，按以下条目判别（≥2 条指向"撤退" + 放量确认 → 出口B）：

| 观察项 | 分歧（持有） | 资金撤退（出口B） |
|---|---|---|
| 承接位置 | 回踩不破前低/关键均线 | 高位放量长阴，跌破前低 |
| 分时承接 | 下跌有承接，尾盘回升 | 分时单边下杀，无像样反抽 |
| 板块联动 | 板块缩量分歧，多数未破位 | 板块成片走弱，广度塌缩 |
| 龙头行为 | 龙头仍领涨或横盘 | 龙头率先 A 杀/放量破位 |
| 锚点状态 | 依据仍在被验证 | 出现否定证据 |

**V2 的环境归因**（保留）：环境导致的资金撤退 = 出口B，不是出口A。量能萎缩、事件等待导致封板无承接、广度退化——这是**交易确认失败**，不是预期死亡。方向保留，等环境修复后重新三维确认即可考虑重入（环境修复本身是"重新确认"的触发条件；价格反弹不是买入理由，这条不变）。

**出口可执行性纪律（V3.1 重写）**——这套纪律不回答"该不该卖"（该不该卖由预期与判别清单决定），只回答"决定卖了之后怎么保证卖得掉"。A 股制度（T+1、涨跌停）经常让卖出假设失效，因此：

1. **已触发出口即执行，不因"可能反弹"延期**：出口触发后当日无法卖出（跌停/停牌）→ 记录"不可执行"，**次日开盘无条件卖出**；
2. **一字跌停处理**：立即排队卖出，开板即卖，不幻想反抽；
3. **事件节点型落地日**：出口A（兑现/取消）触发的当天，**抢在竞价或开盘卖出**（"卖事实"必须抢在兑现之前），不等盘中确认；
4. **兑现期卖出节奏**：分批减仓（如 30% + 30% + 清仓）在 1-2 日内完成，不在"卖事实"上恋战。

配套提示（不作为触发规则）：高位板（≥3 连板）失败的典型路径是连续一字跌停、出口在其间不可执行——所以**高位板持仓的判别清单执行要更早、更严**（高位放量长阴优先判为撤退而非分歧），但触发仍只来自判别清单本身。

**配套纪律**（与 V1 相同）：

- 分歧中的持仓仍须检查出口B（不能拿"方向未结束"强迫持仓）。
- 卖出后重入：出口A离场须新催化重新研究；出口B离场须重新完成三维确认（价格反弹本身不是买入理由）。
- 同一证据只消费一次，防重复减仓。

## 七、持仓管理

（与 V1 相同 + V2 环境提示 + V3 补充）

- **建仓**：首次建仓为目标仓位的 50-70%。
- **加仓**：必须独立满足一种买点类型 + 预期依据继续验证 + 风险预算允许；**价格创新高不能独立构成加仓理由**；一致加速阶段不加仓。
- **减仓**：部分兑现减 30-50%，完全兑现清仓。
- **龙头切换**：老龙头断板时，不问"龙头换没换"，**回到买入时锁定的三件事**——龙头是观察预期状态的窗口，不是持仓的理由。
- **多主题并发**：不同主题各自独立（各最多 3 成）；现有持仓没有卖出理由时，不为新机会强行腾仓。
- **环境恶化时**（V2）：环境档位下调 → 不加仓、优先兑现部分利润；但环境不构成强行清仓理由——环境是仓位调节器，不是持仓开关。
- **降级持仓复核**（V3）：降级买入（池内二、三名）的持仓，三日内未转强即按出口B 复核，不享受与龙头同等的"观察窗口"。

## 八、账户级硬约束（风控骨架）

（V1 保留 + V2 市场级因子 + V3 升级）

| 约束 | 规则 |
|---|---|
| 单主题仓位 | 最多 3 成 |
| 共同风险因子 | 同一次风格切换中会同步撤退的主题合并计算，最高 6 成 |
| 同批机会 | 最多执行排序前 2 名 |
| 品种 | 仅沪深主板（300/301/688 排除） |
| 交易规则 | T+1、整手、14:50 后不开新仓 |
| 冷静期（V3 升级） | 当日累计亏损 >5%：禁止开新仓 **+ 强制持仓复核**（对照锁定三件事，无明确持有理由即减仓）——不只冻结开仓，还触发减仓 |
| 账户回撤熔断（V3 新增） | 自阶段高点回撤 >10%：全局仓位系数统一下调至 0.7，暂停开新仓，直至回撤收复或复盘确认原因 |
| 频率与成本（V3.1 重写） | 频率由预期库控制（无日历上限）：每笔开仓必须可指认"已入库预期 + 盘前覆盖"，盘中临时起意不开仓；每笔记录往返成本（佣金+印花税+滑点估算），月度审计成本/毛利比 > 30% 时复盘开仓节奏与执行质量（是否反复进出同一预期），作为覆盖纪律的输入——反思触发器，不是自动禁仓 |
| 复盘标准 | **赚钱违规 = 错误 / 亏钱合规 = 正确**（纪律一致性高于单次盈亏） |

**市场级共同风险因子**（V2 保留）：环境恶化（量能萎缩/事件等待）是**全市场共同的撤退因子**——所有主题的确认质量同步打折、仓位系数统一下调。环境风险天然挂在账户层：环境档位下调时，全部持仓按同档系数处理，不按主题单独判断。

## 九、市场感知：预期从哪里来

（与 V1 相同 + V2 环境感知）

**预期来源**：产业催化（涨价/缺货/扩产/技术突破）、政策事件、资金异动。

**发现顺序**（固定，不可倒置）：

```
全市场发现异动候选（只是候选，不是龙头）
→ 搜索市场正在交易的具体预期（公告/新闻/媒体/雪球）
→ 根据预期列出关联股票（池先建后验）
→ 核心关联股成片同步上涨 = 归因成立
→ 池内最先发动且最强的才是龙头
→ 最后才做可交易性检查
```

**反噪音三原则**（与 V1 相同）：

- **概念标签 ≠ 归因结论**——"PCB涨停"是标签，"覆铜板涨价+中报兑现"才是催化；每只涨停股只归入一个主驱动方向。
- **大叙事反向拆解**——某方向 ≥20 涨停时必须检查跟风股有没有独立催化。
- **连板股独立归因**——连续涨停的个股不能因为"大方向在爆发"就归入大方向。

**倒计时催化**（与 V1 相同 + 市场级扩展）：即将到期的涨价日/政策日/数据日会打破历史规律，显著提升延续概率——判断延续性看"有没有新出现的独立催化倒计时"，不看历史统计。**市场级扩展**：全市场在等的事件（会议/数据/谈判/财报）就是全市场的倒计时催化，落地日盘前覆盖优先级最高。

**环境感知**（V2）：每日盘前记录两市成交额与相对量能（20 日均量口径），标注未来 3 日事件日历；两者构成当日环境档位的输入。环境参数是客观数据，判断标准事先锁定、复盘逐条核对，禁止临时凭感觉调整。

## 十、系统明确不做的事

（V1 保留 + V2 边界 + V3 重写"不预测"）

- **不预测价格方向**——不预判涨跌，只跟随已出现且被资金确认的催化。
- **但系统并非零判断（V3 诚实表述）**：归因四行（传导链判断）、历史模式类比、"符合预期"（结果判断）都是**隐式预测**——系统预测的是"归因链条成立"，只是不直接预测价格。**系统的 edge 假设全部集中在归因质量与出口纪律上，而这两者都未被当前样本证实**（见第十一章）。
- **不择时**：环境只调节确认标准与仓位，不预测方向——"量能低"不等于"指数要跌"，只等于"确认要打折"。
- **不赌事件结果**：环境层只记录"事件未落地 = 等待期"，不预判谈判成不成、财报好不好；落地后跟随市场投票，不提前下注。
- **不做估值**：不问贵不贵，只问资金认不认。
- **不做对冲**：单向做多，无做空、无对冲工具。
- **不抄底摸顶**：只吃确认期到兑现期之间的一段，头尾都让给别人。

## 十一、系统的隐含假设与已知边界

（V1 五条 + V2 一条 + V3 新增两条）

1. **资金投票有效性假设**：增量资金的方向性流入是预期真实性的最终裁判——所以系统跟随资金、不预判资金。若资金行为被操纵（庄股、假联动），系统没有防御层。（V2 补充：资金投票的有效性还受环境调节，见第 6 条。）
2. **短周期假设**：催化定价在数个交易日内完成（确认买点持有约 3-5 天、首板 5-10 天、回调 10-20 天）。系统本质是**短线波段**，慢变量（渗透率提升、季度业绩趋势）在系统时间尺度内不可验证、不可交易。
3. **A股微结构假设**：涨停板制度、T+1、散户情绪使涨停/联动/封单成为信息密度最高的信号载体。市场制度一变，信号体系需重建。（V2 补充：封板所需的资金承载力正是环境层的微观基础。）
4. **归因质量假设**：归因链条正确是三维确认、龙头、出口全部判断的地基。**V3 强调：这是系统 edge 的唯一来源，也是最大的未证实假设**——系统对"归因错误"只有一道事前防线（联动验证），没有内部纠错机制。
5. **纪律一致性假设**：规则全集的效力 = 执行一致性。62 条教训中约半数是**执行偏差**而非规则缺陷——规则与执行的分离是当前系统最大的风险源。
6. **环境承载力假设**（V2）：资金投票的有效性受市场量能与事件不确定性的调节——同一组三维信号在不同环境下可信度不同。环境校准错误（如把存量轮动当增量确认、把事件等待当逻辑否定）是主要新增风险源；防御手段是**客观口径 + 事前锁定 + 逐条复盘**，禁止把环境判断变成主观感觉。
7. **出口可执行性假设**（V3 新增）：任何卖出规则都以"退得掉"为前提；A 股跌停制度使该假设在高位板上经常失效——靠第六章"出口可执行性纪律"防御，但无法完全消除（一字跌停开板前无解）。
8. **熊市未验证假设**（V3 新增）：当前实绩（5 个月、+8.8%）只覆盖偏多行情；缩量恐慌期是"出口不可执行"与"信号混乱"同时爆发的时段，系统行为未被验证——**需以 2022/2024 类缩量熊市回测补足**。
