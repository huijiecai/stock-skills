# 看盘机制方案讨论

> 背景：模拟看盘数据范围太窄（只拉方向内标的），中间数据处理AI自由发挥老是出问题。需要重新梳理看盘的自然路径，把机械操作固化成脚本。

---

## 一、看盘的自然路径

不管真实看盘还是模拟看盘，交易员看盘的路径是一样的：

### 买入方向

```
1. 看指数（机械）
   上证/深证/科创/创业板 当前涨跌幅
   → 大盘什么环境？支持操作吗？

2. 看板块（机械）
   哪些板块强？强的板块概念是什么？
   → 和盘前分析的预期方向对照

3. 思考：板块为什么强？（思考）
   是盘前分析的预期有一定的确定了吗？
   还是盘前没覆盖的新方向？

4. 看领涨个股（机械）
   强的板块里，哪些个股领涨？

5. 思考：领涨的是否是预期内的个股？（思考）
   - 如果是预期内核心个股领涨 → 继续
   - 如果不是，考虑：
     · 是否第一天？（第一天可能还没聚焦到核心标的）
     · 是否主升期？（主升期核心个股不一定每天领涨，但不会很弱）
     · 如果都不是 → 可能不是这个预期，需要重新分析

6. 预期分析（思考）
   领涨个股和板块的表现，是否验证了预期？
   有偏差吗？需要修正预期吗？

7. 三维确认（机械取数 + 思考判断）
   - 资金广度：方向内多只标的同步走强？（机械取数）
   - 价格深度：龙头放量突破？（机械取数）
   - 可验证依据：预期逻辑是否成立？（思考）

8. 三维齐 → 买入（写思考链路 → 执行）
   三维不齐 → 继续快扫
```

### 卖出方向（相反）

```
1. 看持仓个股所在板块表现（机械）
   板块还在走强吗？

2. 看预期相关个股表现（机械）
   同方向其他标的走势如何？

3. 思考：预期是否兑现或失效？（思考）
   - 兑现了 → 卖出
   - 失效了 → 卖出
   - 还在确认中 → 持有

4. §4.4卖出三步（思考）
   预期阶段 → 失效信号 → 资金确认

5. 卖出（写思考链路 → 执行）
```

### 核心原则

- **机械操作**（看指数、看板块、看个股数据）→ 固化成脚本，AI直接调用
- **思考判断**（为什么强、预期分析、三维确认）→ AI完成，不固化
- **路径相同**：真实看盘和模拟看盘走完全相同的路径
- **唯一区别**：数据源——live实时获取 vs 一次性同步后逐分钟模拟

## 二、scripts目录：固化机械操作

### 设计原则

scripts目录只负责"机械取数"——交易员看盘时需要看的数据，用脚本固化取数逻辑，AI调用脚本拿到数据后自己思考。

### 目录结构

```
skills/trading-system-v2/scripts/
├── README.md                        # 操作总览：每个操作怎么用、真实/模拟各调什么
├── op_index.sh                      # 指数概览
├── op_sector_rank.sh                # 板块排名
├── op_holdings.sh                   # 持仓快照
├── op_sector_members.sh             # 板块领涨股
├── op_multi_snapshot.sh             # 多股快照（三维确认用）
├── op_stock_minute.sh               # 个股分钟走势
└── op_limit_list.sh                 # 涨停明细
```

### 操作定义

| # | 操作 | 看什么 | 真实看盘 | 模拟看盘 |
|---|------|--------|---------|---------|
| 1 | op_index | 上证/深证/科创/创业板涨跌幅 | `astock live quote 000001 399001 000688 399006` | `op_index.sh <date> <HH:MM>` |
| 2 | op_sector_rank | 板块涨幅排名前50 | `astock live block rank --limit 50` | `astock query block rank YYYYMMDD --limit 50`（收盘参考） |
| 3 | op_holdings | 持仓N只当前报价+涨跌幅 | `astock live quote <持仓codes>` | `op_holdings.sh <持仓codes> <date> <HH:MM>` |
| 4 | op_sector_members | 板块内领涨股 | `astock live block members <block_code>` | `astock query block members <block_code> YYYYMMDD` |
| 5 | op_multi_snapshot | 多股指定时间点快照 | `astock live quote <codes>` | `op_multi_snapshot.sh <codes> <date> <HH:MM>` |
| 6 | op_stock_minute | 个股分钟K线详情 | `astock live minute <code>` | `astock query kline <code> --freq 1m --date YYYYMMDD` |
| 7 | op_limit_list | 涨停明细 | （盘中从live推导） | `astock query limit YYYYMMDD --exclude-st` |

### 需要写shell脚本的操作（3个）

只有模拟看盘特有的、需要从历史分钟K线提取指定时间点数据的操作才写脚本：

**op_index.sh** — 指数概览（模拟看盘）
```
输入: date=20260709  time=10:04
输出:
  === 2026-07-09 10:04 指数概览 ===
  指数        前收      当前      涨跌幅
  上证指数    2950.12   2968.35   +0.62%
  深证成指    9120.50   9185.22   +0.71%
  科创50      756.80    762.45    +0.75%
  创业板指    1820.30   1835.60   +0.84%
```

**op_holdings.sh** — 持仓快照（模拟看盘）
```
输入: codes=002185,600584  date=20260709  time=10:04
输出:
  === 2026-07-09 10:04 持仓快照 ===
  代码    名称        前收    收盘    涨幅%    成交量
  002185  华天科技    21.57   23.28   +7.92%   199208
  600584  长电科技    94.11   96.24   +2.27%   45200
```

**op_multi_snapshot.sh** — 多股快照（模拟看盘）
```
输入: codes=002185,600584,002156  date=20260709  time=10:04
输出: 同op_holdings格式，支持任意多只股票
用途: 三维确认时看方向内多只标的的涨跌幅对比
```

### 不需要写脚本的操作（4个）

直接调用astock命令，不需要数据处理：
- op_sector_rank → `astock query/live block rank`
- op_sector_members → `astock query/live block members`
- op_stock_minute → `astock query/live kline --freq 1m`
- op_limit_list → `astock query limit`

## 三、执行顺序

### 真实看盘

```
▼ 启动
  读取 state.md → 持仓+预期
  读取 盘前分析.md → 催化清单+预案
  读取 核心框架.md + 买卖规则.md → 规则

▼ 快扫循环（连续运行，扫完立即下一轮）
  ┌──────────────────────────────────────────┐
  │ 1. op_index（机械）                       │
  │    astock live quote 000001 399001 ...    │
  │    → 指数异动？→ 信号                     │
  │                                           │
  │ 2. op_sector_rank（机械）                  │
  │    astock live block rank --limit 50      │
  │    → 前50板块过一遍，哪个方向走强？        │
  │    → 盘前预期方向走强？新方向？→ 信号      │
  │    （概念细分多，TOP3太窄会漏）             │
  │                                           │
  │ 3. op_holdings（机械）                     │
  │    astock live quote 持仓N只               │
  │    → 持仓涨跌幅>2%？→ 信号                │
  │                                           │
  │ 4. 无信号 → 立即下一轮                     │
  │    有信号 → 进入深析 ↓                     │
  └──────────────────────────────────────────┘

▼ 深析（信号触发）
  ┌──────────────────────────────────────────┐
  │ 思考：板块为什么强？                       │
  │   对照盘前分析，预期确定了吗？              │
  │   还是新方向？                             │
  │                                           │
  │ op_sector_members（机械）                  │
  │   astock live block members <板块>         │
  │   → 看领涨个股                             │
  │                                           │
  │ 思考：领涨的是预期内核心个股吗？            │
  │   是 → 继续                               │
  │   不是 → 第一天？主升期？重新分析预期？     │
  │                                           │
  │ op_multi_snapshot（机械）                  │
  │   astock live quote <方向内标的>           │
  │   → 资金广度：多只同步走强？               │
  │                                           │
  │ op_stock_minute（机械）                    │
  │   astock live minute <龙头>                │
  │   → 价格深度：放量突破？                   │
  │                                           │
  │ 思考：三维确认                             │
  │   资金广度✓ + 价格深度✓ + 预期依据✓？     │
  │                                           │
  │ 三维齐 → 写思考链路 → 买入                 │
  │ 预期变化 → 写思考链路 → 卖出               │
  │ 三维不齐 → 记录放弃理由 → 返回快扫         │
  └──────────────────────────────────────────┘

▼ 收盘归档
  op_limit_list → 逐只归因
  预期研究更新 → state.md更新 → 复盘
```

## 四、数据范围修正

### 原来的问题

模拟看盘启动时只拉"持仓股+方向内标的"的分钟K线 → 提前定义了看哪些个股，不符合真实看盘逻辑。

### 修正方案

模拟看盘启动时一次性同步：
- **涨停明细**（全天涨停列表+概念标签）→ 知道今天哪些方向强
- **概念排名**（收盘板块排名）→ 参考用
- **持仓股分钟K线** → 持仓巡检

快扫逐分钟推进时动态发现：
- **指数** → `op_index.sh`逐分钟看指数变化
- **持仓** → `op_holdings.sh`逐分钟看持仓涨跌幅
- **涨停进程** → 从已同步的涨停明细+分钟K线推断，当前时间点哪些已涨停

信号触发后动态拉取：
- **领涨个股** → `op_sector_members`看板块内领涨
- **多股对比** → `op_multi_snapshot.sh`看方向内标的涨跌幅
- **个股走势** → `op_stock_minute`看龙头详细走势

**不再提前定义"方向内标的"**——而是在思考"板块为什么强"之后，动态确定需要看哪些个股。

## 六、待讨论

1. 涨停进程：模拟看盘启动时一次性算好涨停时间线（从分钟K线推断封板时间），快扫时只查表，不每分钟调脚本？
2. shell脚本的实现：用`--json`输出+`jq`解析，还是用文本输出+`awk`解析？
3. 是否需要同时给astock加`query snapshot`命令？还是先只做scripts目录？
4. op_sector_members在模拟看盘用的是收盘数据（`query block members`），只能看到收盘涨幅榜，看不到盘中某个时间点的涨幅榜。这个局限怎么处理？是否够用？
5. 信号触发条件：不能用"≥2涨停"做门槛——龙头涨停封死了再进深析就晚了，买不进。信号应该在板块排名靠前或龙头放量拉升时就触发，涨停只是确认信号之一，不是触发门槛。
