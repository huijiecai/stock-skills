# 预期驱动交易系统 V2：核心逻辑总结

> **目的**：在 V1（`预期驱动交易系统-逻辑总结.md`）基础上，把"市场环境层"纳入系统，形成 V2 完整逻辑。V2 **不推翻 V1 任何规则**，只新增一层"环境校准"。
> **范围**：只讲交易逻辑——怎么理解市场、怎么决策买卖；不讲文件、工具与执行细节。
> **与 V1 的关系**：V1 回答"三维确认怎么判定"；V2 追加回答"这笔资金投票本身可不可信"。V1 是 V2 的严格子集。
> **实绩背景**：2026-03-26 起 10 万虚拟账户运行约 5 个月，96 笔交易，+8.8%（V1 规则期实绩）。环境层为新增逻辑，待实盘验证。

---

## 一、这套系统是什么

**一句话：预期驱动，三维确认 + 环境校准决定买卖，纪律执行。**

**赚的是什么钱**（与 V1 相同）：市场对某个产业预期**重新定价过程**的钱。路径：新催化出现 → 增量资金进场为它定价 → 定价完成（利好落地/数据见顶）。系统不预测预期会不会出现，只做三件事：

```
识别资金正在投票的预期 → 等三维确认后跟随买入 → 预期兑现或资金撤退时退出
```

三条底层信念（与 V1 相同）：

1. **资金认可就是最好的确认力**——有增量资金进场就有承接力；没有资金响应的逻辑再好也是空气。
2. **信号是感知，不是触发**——涨停数、换手、成交额只回答"市场结构在发生什么"，禁止机械阈值。
3. **低频但确定**——不猜、不赌、不扛；条件不齐宁可错过。

**V2 新增的一条认知**：资金投票的有效性受**环境**调节——同样的三维信号，在量能充裕、事件明朗的环境下可信，在量能萎缩、事件悬而未决的环境下要打折。环境不是第四维确认信号，而是三维确认共同的"信噪比"。

---

## 二、六个核心概念

| 概念 | 定义 |
|---|---|
| **预期** | 市场资金正在投票的产业方向或事件催化（不是"我觉得会涨"） |
| **三维确认** | 预期成立的判定：资金投票（广度）× 价格响应（深度）× 可验证依据（锚点），缺一 = 未确认 |
| **龙头** | 直接受益池内最先发动、最强、成交最主动的标的 |
| **买点** | 仓位大小的依据：由"预期被资金认可的程度 × 环境系数"决定 |
| **出口** | 卖出的唯一通道：出口A（预期结束）或出口B（交易确认失败） |
| **环境** | 资金投票的能力（量能承载力）× 意愿（事件不确定性）的总背景；三维确认可信度的调节器，不是买卖开关 |

**三维确认**是全系统的心脏（与 V1 相同）：

| 维度 | 问题 | 典型信号 |
|---|---|---|
| 资金投票（广度） | 有多少在涨？ | 方向内多只同步走强 |
| 价格响应（深度） | 领涨的走出来了吗？ | 龙头涨停/放量突破/回踩企稳 |
| 可验证依据（锚点） | 逻辑被数据验证了吗？ | 期货涨价、业绩超预期、政策落地 |

三者缺一的诊断（与 V1 相同）：

- 只有逻辑没有资金 = **空气**
- 只有异动没有锚点 = **噪音**
- 只有资金没有价格响应 = **未兑现**

**V2 新增的第四种诊断**：

- 三维齐全但环境不支持 = **打折的确认**——锚点强、有异动、有同步走强，但市场没钱（量能萎缩）或不想投（事件等待）。只能小仓试或等环境修复，不能按标准仓位执行。

**预期类型三分**（与 V1 相同，决定退出信号怎么定义）：

| 类型 | 特征 | 入场锚点（V2.1 新增列） | 退出信号 |
|---|---|---|---|
| 持续数据型 | 有月频以上可追踪的数据锚 | 最新一期数据仍在验证（涨价/销量/订单） | 数据见顶/破位 |
| 事件节点型 | 明确的一次性事件 | **事件已官宣 + 历史模式可参考 + 倒计时在场** | 事件兑现/取消 |
| 实时感知型 | 无外部数据，纯资金行为 | 无外部锚；资金行为本身即锚（广度+深度替代锚点） | 龙头A杀/联动消失 |

**事件节点型的入场锚点标准（V2.1 新增）**：事件节点型买入时刻事件尚未发生，"锚点齐全"定义为三者同时成立，缺一 = 锚点未齐全：

1. **事件已官宣**——日程、规则、标的范围明确（政策发布日、财报披露日、谈判时间表），"传闻中"的事件不算；
2. **历史模式可参考**——同类事件在历史上可查证的市场反应路径（启动-兑现节奏），不是第一次见；
3. **倒计时催化在场**——距事件落地 ≤3 日且盘前可跟踪（呼应第九章"倒计时催化"）。

锚点未齐全时，该预期在三维确认上属于"半残疾"通过：只允许小仓试（首板 1 成 × 环境系数），或直接等事件落地后重新三维确认再进场。

环境层与事件节点型的连接：**市场等待的重大事件 = 市场级的事件节点型预期**——全市场都在等一个二元结果，等待期所有主题的确认质量同步打折。

## 三、市场环境层（V2 核心新增）

**环境 = 能力 × 意愿。**

### 3.1 量能承载力（能力）——市场有没有钱

- **机制**：封板需要持续资金吃掉卖压；个股成交额越大，封板需要的资金越多；全市场成交额是攻击资金的池子。量能充裕时有**增量资金**进场接力，萎缩时是**存量博弈**——钱在板块间轮动而非净流入。
- **现象**（V2 的观察基准）：量能约 3 万亿时，足以支撑成交百亿级乃至 200 亿级的个股涨停；约 2 万亿时，成交超 50 亿已很难封住。
- **量化口径（相对量能）**：当日两市成交额 ÷ 近 20 日均量。绝对数随市场扩容漂移，一律用相对数：
  - ≥ 1.2 → 量能充裕（增量资金主导）
  - 0.8–1.2 → 正常（存量为主）
  - < 0.8 → 萎缩（纯存量博弈）
- **对选股的影响——龙头体量上限**：量能充裕时可打大市值龙头（成交百亿级）；萎缩时龙头只能是中小流通盘（成交 30–50 亿以下），大市值主导行情打不出来。
- **对执行的影响**：量能是同步/滞后指标——全天量能盘中才知。竞价买入只能用昨日趋势 + 早盘半小时量能节奏做前置判断；半路/午后买点可用当日量能实时过滤。

### 3.2 事件不确定性（意愿）——资金想不想投

- **机制**：市场等待二元结果事件（美联储会议、财报、谈判落地）时存在两类成本：风险溢价（不确定 → 观望）与相关性风险（**事件结果可能直接否定当前逻辑**——谈判破裂则出口数据再强也没用）。
- **现象**：等待期即使板块数据超强，资金也不进攻；事件落地且符合预期后，压抑资金集中释放 → 广度突然打开。
- **量化口径（事件日历）**：未来 3 日内是否有重大事件（会议/数据/谈判/财报）。有 → 事件等待期。
- **关键认知**：事件等待是**市场级分歧**，不是结束。事件落地日 = 盘前覆盖优先级最高的日子——压抑资金的释放往往就是确认期买点窗口。

### 3.3 环境系数

两因素组合成环境档位，作用于**确认标准**与**仓位系数**（同时满足多档条件时取更低档，即更严的处理）：

| 档位 | 量能 | 事件 | 仓位系数 | 确认标准 |
|---|---|---|---|---|
| 进攻 | ≥ 1.2 | 无 | 1.0 | 标准三维确认 |
| 常态 | 0.8–1.2 | 无 | 1.0 | 标准三维确认 |
| 等待 | 任意 | 有重大事件 | 0.8 | 非事件相关方向暂缓确认；事件相关方向等落地后跟随 |
| 萎缩 | < 0.8 | 任意 | 0.7 | 锚点要求更硬 + 广度更高；龙头限中小流通盘 |

**仓位应用**：买点基础仓位 × 环境系数。例：确认买点 3 成 × 0.8 = 2.4 成；首板 1.5 成 × 0.8 = 1.2 成。

**待验证假设**（可用 96 笔历史数据验证）：入场日相对量能越低，出口B 触发率越高；事件等待期内建仓的胜率显著低于事件落地后。

## 四、预期的时间结构：五阶段生命周期

```
出现期 → 确认期 → 加速期 → 兑现期 → 结束期
```

| 阶段 | 特征 | 系统动作 |
|---|---|---|
| 出现期 | 新催化首次爆发，尚未验证 | 观察；首板买点 1-1.5 成 |
| 确认期 | 二次走强（经历分歧仍延续） | **主战场**：确认买点 3 成 |
| 加速期 | 主升浪，梯队完整 | 无买点；持仓可持不加 |
| 兑现期 | 利好落地，数据见顶 | 只卖不买（卖事实） |
| 结束期 | 龙头A杀，联动消失 | 空仓等新预期 |

两个关键判断（与 V1 相同）：

- **分歧 ≠ 结束**：预期依据还在被验证 = 分歧（筹码交换，方向观察窗口）；依据被否定 = 结束（资金离场，空仓窗口）。单次炸板、一日大跌、换手升高都只是分歧。
- **加速期才发现 = 盘前覆盖不足**，不追。兑现期/结束期永远没有买点。

**V2 的环境视角**：

- 市场级事件等待 ≈ 市场级分歧窗口：预期依据还在等裁判 → 观察方向、不进攻；事件落地且符合预期 = 压抑资金释放 → 正是确认期买点窗口。
- **加速期对环境最敏感**：量能不足时大市值龙头封不住 → 加速可能夭折。环境档位下调时，加速期持仓可持不加、优先兑现。

## 五、买入逻辑链

**前提门槛（顺序不可跳，任一不满足 = 不买）**：

1. **预期已入库**——没有研究文件的方向不能买（逼着先想清楚再动手）。
2. **存在可验证的新催化**——旧故事没有增量信息，不构成新买入理由。
3. **三维确认齐全**——缺一不买，无例外。
4. **锁定三件事**——买前写下：预期是什么 / 兑现标志是什么 / 失效标志是什么。**买前锁定，买后不改**，此后所有持仓决策只对照这三件事评估。
5. **归因四行**——具体事件 → 最短传导链 → 直接受益池 → 联动结论。池必须**先于行情建立**，行情只验证，不反向拼池。
6. **环境检查（V2 新增）**——盘前记录两件事：相对量能（昨日成交额/20日均量）、未来 3 日事件日历。环境档位不构成买卖开关，只决定确认标准与仓位系数（见第三章）。

**选股**（与 V1 相同 + 一条环境约束）：

- 只在**直接受益池**内选：直接销售催化产品者、已验证的销量/订单受益者。相邻题材、成本受压者一律排除。
- 龙头按**领涨性 / 主动性 / 高位性**确认，且必须在归因成立后才可确认。
- **识别与执行隔离**：龙头封死买不到 → 依次评估池内第二、第三名；但执行困难不否定龙头身份。
- **龙头体量上限（V2 新增）**：环境萎缩档时，池内只选中小流通盘标的；大市值标的需要量能充裕环境才可作候选。

**账户级排序**（与 V1 相同）：比较五维：预期新鲜度 → 资金确认质量 → 龙头质量 → 买点质量（分歧修复优于一致加速）→ 账户风险。同批最多执行前 2 名；排序落后或风险预算满 = 合规放弃（记录放弃代价），不因还有现金而机械买入。

**买点类型决定仓位**（与 V1 相同 + 环境系数）：

| 买点 | 出现时机 | 基础仓位 | 性格 |
|---|---|---|---|
| 确认买点 | 分歧后资金重新入场（含同日分歧修复） | 3 成 | 最安全 |
| 首板买点 | 新催化首板，本轮没涨过 | 1-1.5 成 | 要快 |
| 回调买点 | 已涨一波 + 首次回调 + 依据未破 | 加至 3 成 | 要准 |

设计哲学（与 V1 相同 + V2 补充）：**仓位 = 当前时刻预期被资金认可的程度 × 环境系数**；单主题 3 成上限是为了容纳意外，不是表达信心高低。环境系数只允许下调、不允许上调——环境是折扣，不是加杠杆。

**执行时机**（与 V1 相同 + 一条补充）：

- 确认完成当下执行——竞价确认就竞价买，半路确认就当下买，封板（非一字）就排板，一字板放弃。不因主观大盘判断给仓位打折。
- **量能过滤的适用时点（V2 补充）**：竞价买入时量能只做前置参考（昨日趋势 + 早盘半小时节奏）；半路/午后买点可用当日相对量能实时过滤。

## 六、卖出逻辑链：双出口

**系统不设纯价格止损**（与 V1 相同）：跌破某条价格线不能独立构成卖出理由；任何卖出条件必须能回答"它和买入时锁定的预期是什么关系"。

**出口A：预期退出（方向级）**
- 触发：进入兑现期/结束期，或预期依据被否定
- 动作：清仓，预期归档
- 含义：本轮故事讲完了

**出口B：交易确认退出（交易级）**
- 触发：买入时的资金确认失败——受益池从成片上涨退化为孤票 / 龙头失去领涨性且反抽无承接 / 价格响应失败 / 放量下跌资金撤退——**≥2 个信号 + 资金撤退确认**
- 动作：首日减仓 30-50%；次日未恢复或三维整体消失 → 清仓
- 含义：本次交易失败，但**方向可以继续观察**（预期保留、降级）

**V2 的环境归因（新增）**：

- **环境导致的资金撤退 = 出口B，不是出口A**：量能萎缩、事件等待导致封板无承接、广度退化、放量阴跌——这是**交易确认失败**，不是预期死亡。方向保留，等环境修复。
- 环境修复后重新三维确认即可考虑重入——**环境修复本身是"重新确认"的触发条件**（价格反弹不是买入理由，这条不变）。
- 出口A 仍是唯一的"方向死亡"出口：环境不直接触发出口A。不能因为"环境不好"清掉一个依据仍然成立的持仓。

**配套纪律**（与 V1 相同）：

- 分歧中的持仓仍须检查出口B（不能拿"方向未结束"强迫持仓）。
- 卖出后重入：出口A离场须新催化重新研究；出口B离场须重新完成三维确认（价格反弹本身不是买入理由）。
- 同一证据只消费一次，防重复减仓。

## 七、持仓管理

（与 V1 相同 + 环境提示）

- **建仓**：首次建仓为目标仓位的 50-70%。
- **加仓**：必须独立满足一种买点类型 + 预期依据继续验证 + 风险预算允许；**价格创新高不能独立构成加仓理由**；一致加速阶段不加仓。
- **减仓**：部分兑现减 30-50%，完全兑现清仓。
- **龙头切换**：老龙头断板时，不问"龙头换没换"，**回到买入时锁定的三件事**——龙头是观察预期状态的窗口，不是持仓的理由。
- **多主题并发**：不同主题各自独立（各最多 3 成）；现有持仓没有卖出理由时，不为新机会强行腾仓。
- **环境恶化时（V2 新增）**：环境档位下调 → 不加仓、优先兑现部分利润；但环境不构成强行清仓理由——环境是仓位调节器，不是持仓开关。

## 八、账户级硬约束（风控骨架）

（与 V1 相同 + 市场级共同风险因子）

| 约束 | 规则 |
|---|---|
| 单主题仓位 | 最多 3 成 |
| 共同风险因子 | 同一次风格切换中会同步撤退的主题合并计算，最高 6 成 |
| 同批机会 | 最多执行排序前 2 名 |
| 品种 | 仅沪深主板（300/301/688 排除） |
| 交易规则 | T+1、整手、14:50 后不开新仓 |
| 冷静期 | 当日累计亏损 >5% 禁止开新仓 |
| 复盘标准 | **赚钱违规 = 错误 / 亏钱合规 = 正确**（纪律一致性高于单次盈亏） |

**市场级共同风险因子（V2 新增）**：环境恶化（量能萎缩/事件等待）是**全市场共同的撤退因子**——所有主题的确认质量同步打折、仓位系数统一下调。环境风险天然挂在账户层：环境档位下调时，全部持仓按同档系数处理，不按主题单独判断。共同风险因子的判断标准仍是"资金是否会在同一次撤退中同步离场"，环境档位就是最粗粒度的那个因子。

## 九、市场感知：预期从哪里来

（与 V1 相同 + 环境感知）

**预期来源**：产业催化（涨价/缺货/扩产/技术突破）、政策事件、资金异动。

**发现顺序**（固定，不可倒置）：

```
全市场发现异动候选（只是候选，不是龙头）
→ 搜索市场正在交易的具体预期（公告/新闻/媒体/雪球）
→ 根据预期列出关联股票（池先建后验）
→ 核心关联股成片同步上涨 = 归因成立
→ 池内最先发动且最强的才是龙头
→ 最后才做可交易性检查
```

**反噪音三原则**（与 V1 相同）：

- **概念标签 ≠ 归因结论**——"PCB涨停"是标签，"覆铜板涨价+中报兑现"才是催化；每只涨停股只归入一个主驱动方向。
- **大叙事反向拆解**——某方向 ≥20 涨停时必须检查跟风股有没有独立催化。
- **连板股独立归因**——连续涨停的个股不能因为"大方向在爆发"就归入大方向。

**倒计时催化**（与 V1 相同 + 市场级扩展）：即将到期的涨价日/政策日/数据日会打破历史规律，显著提升延续概率——判断延续性看"有没有新出现的独立催化倒计时"，不看历史统计。**V2 扩展：市场级事件日历同理**——全市场在等的事件（会议/数据/谈判/财报）就是全市场的倒计时催化，落地日盘前覆盖优先级最高。

**环境感知（V2 新增）**：每日盘前记录两市成交额与相对量能（20 日均量口径），标注未来 3 日事件日历；两者构成当日环境档位的输入。环境参数是客观数据，判断标准事先锁定、复盘逐条核对，禁止临时凭感觉调整。

## 十、系统明确不做的事

（与 V1 相同 + 环境层边界）

- **不预测**：不预判催化会不会出现，只跟随已出现且被资金确认的催化。
- **不择时**：大盘判断只提高复核优先级，不构成独立的开/平仓理由（大盘共振只是加分确认）。**环境层边界（V2）：环境只调节确认标准与仓位，不预测方向——"量能低"不等于"指数要跌"，只等于"确认要打折"。**
- **不赌事件结果（V2 新增）**：环境层只记录"事件未落地 = 等待期"，不预判谈判成不成、财报好不好；落地后跟随市场投票，不提前下注。
- **不做估值**：不问贵不贵，只问资金认不认。
- **不做对冲**：单向做多，无做空、无对冲工具。
- **不抄底摸顶**：只吃确认期到兑现期之间的一段，头尾都让给别人。

## 十一、系统的隐含假设（升级讨论的靶子）

（V1 的 5 条 + V2 新增 1 条）

1. **资金投票有效性假设**：增量资金的方向性流入是预期真实性的最终裁判——所以系统跟随资金、不预判资金。若资金行为被操纵（庄股、假联动），系统没有防御层。（V2 补充：资金投票的有效性还受环境调节，见第 6 条。）
2. **短周期假设**：催化定价在数个交易日内完成（确认买点持有约 3-5 天、首板 5-10 天、回调 10-20 天）。系统本质是**短线波段**，慢变量（渗透率提升、季度业绩趋势）在系统时间尺度内不可验证、不可交易。
3. **A股微结构假设**：涨停板制度、T+1、散户情绪使涨停/联动/封单成为信息密度最高的信号载体。市场制度一变，信号体系需重建。（V2 补充：封板所需的资金承载力正是环境层的微观基础。）
4. **归因质量假设**：归因链条正确是三维确认、龙头、出口全部判断的地基。系统对"归因错误"只有一道事前防线（联动验证），没有内部纠错机制。
5. **纪律一致性假设**：规则全集的效力 = 执行一致性。62 条教训中约半数是**执行偏差**而非规则缺陷——规则与执行的分离是当前系统最大的风险源。
6. **环境承载力假设（V2 新增）**：资金投票的有效性受市场量能与事件不确定性的调节——同一组三维信号在不同环境下可信度不同。环境校准错误（如把存量轮动当增量确认、把事件等待当逻辑否定）是 V2 的主要新增风险源；防御手段是**客观口径 + 事前锁定 + 逐条复盘**，禁止把环境判断变成主观感觉（否则它就是纪律一致性的新威胁）。
